## 1. 이 제품은 무엇인가

**하나의 포털에서 제조 IT 솔루션들을 각각 독립된 전문 솔루션으로 보여주는 제조 업무 플랫폼이다.** 지금은 여섯 개가 운영 중이고, 2026-09-30 결정으로 레퍼런스 카탈로그의 17개를 모두 만든다.

각 솔루션은 자기 대시보드·메뉴·업무 흐름을 갖는 완결된 제품이고, 포털은 로그인과 진입만 담당한다. 솔루션이 어떻게 이어지는지는 정적 흐름 맵(P-03)과 도움말로 설명한다.

공개 전시의 목적은 이직용 포트폴리오다. **GW는 실제 회사 도입까지 목표를 확장했다(2026-10-05).** 운영 준비와 공개 체험을 분리한다.

| 함의 | 내용 |
|---|---|
| 평가자 | 채용 담당자·기술 면접관. 3~5분 안에 판단한다 |
| 회원가입 | 요구하면 안 된다. 게스트 즉시 체험이 필수다(게스트 별칭만 입력, FS-027) |
| 잘 만든 결과 | 한 솔루션이 대시보드부터 업무 완결까지 동작하고 설계 근거를 설명할 수 있는 것 |
| 치명적 실패 | "준비 중" 남발, 빈 화면, 가입 강제 |

현재 공개 전시 환경은 합성 데이터만 사용한다. 2026-10-05 사용자가 GW의 실제 회사 도입 목표를 확정했다. 별도 운영 환경·운영 요건을 다루는 [GW 확장 초안](GW확장_협업플랫폼_결정초안_GW-EXT-01.md)의 범위가 승인됐고 상세 설계 확인 중이며, 현재 실데이터 반입을 허용한 상태는 아니다.
