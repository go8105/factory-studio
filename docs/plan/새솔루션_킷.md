## 막히기 쉬운 곳

- 게스트 상한은 만료 공간도 센다. 로컬은 `.claude/launch.json`의 `GUEST_LIMIT=1000`으로 띄운다.
- 같은 폴더를 다른 Claude 세션이 쓴다. `git add`에는 파일을 지정한다. 스모크 도중 frontend 파일을 고치지 않는다.
- 전역 CSS 클래스(`.excluded` 등)와 이름이 겹친다. 새 화면 클래스에는 솔루션 접두어를 붙인다.
- 연·월·주차는 문자열(`'YYYY-MM'`, `'YYYY-Www'`)로 저장하고 CHECK로 형식을 강제한다. 게스트 복사는 일수 이동이라 달력 파생 컬럼을 다시 계산해야 한다.
