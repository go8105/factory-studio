# FS-028 SPC 도입과 관리도·공정능력 결정서

작성일: 2026-09-30 (Claude Code)
상태: **초안 — 6장 승인 요청.** 승인 뒤 모듈 설계(`docs/modules/spc/SPC_모듈설계_FS-028.md`)와 화면 설계(`docs/ui/화면설계_SPC_FS-028.md`)를 쓰고, 전체 설계 확인 뒤 FS-028a(DB)부터 시작한다.
성격: [17개 시스템 로드맵](로드맵_17개시스템_ROADMAP-01.md) 1번. [FS-023](QMS도입_교차조회_결정_FS-023.md) D8이 1차 범위에서 뺀 SPC를 **별도 솔루션 `spc`**로 만든다. 교차 조회 규칙(FS-023 D9·X1~X6·R6)은 그대로 따른다. 절차는 [새 솔루션 킷](새솔루션_킷.md).

---

## 1. 배경

| 지금 | 상태 |
|---|---|
| 측정값 | 없다. MES는 공정 실행의 시작·종료·설비와 양품·불량 수량만 기록한다 |
| QMS | 출하 전 **최종검사**만 한다(LOT당 1회, 합격/불합격). 공정 중 추세는 보지 않는다 |
| MES 공정 실행 | 시드 기준 LOT 24개, 공정 실행 64건(완료 62). 공정 INJ(사출)·ASM(조립)·INS(검사), 설비 INJ-01~03·ASM-01~02·INS-01~02. 완제품 FG-C100·FG-C200·FG-T300 |
| QMS 검사 기준 | 치수 항목이 이미 있다. 예: FG-C100 하우징 높이 8.90~9.10 mm, 핀 피치 2.49~2.59 mm, FG-T300 단자 간격 4.95~5.05 mm |

QMS는 "이 LOT가 합격인가"를 답하고, SPC는 **"공정이 불량을 만들기 전에 흔들리고 있는가"**를 답한다. 최종검사에서 합격했더라도 관리도가 추세를 보이면 다음 LOT가 불량이 될 수 있다. 이 차이가 SPC를 보여 주는 핵심이다.

## 2. 결정

| # | 항목 | 결정 |
|---|---|---|
| **D37** | SPC 범위 | **SPC를 구현 솔루션에 넣는다(스키마 `spc`, 모듈 키 `spc`, 화면 접두어 `S`).** 1차는 ① 관리 특성(품목·공정·특성·규격) ② 측정 부분군 입력 ③ **X̄-R 관리도** ④ 관리 한계 게시(버전) ⑤ 이상 판정·조치 ⑥ 공정능력 Cp·Cpk |
| **D38** | 측정값 소유 | **측정값·관리 특성·규격은 SPC가 소유한다**(로드맵 §6-2). MES에는 측정 테이블을 만들지 않는다. LOT·공정·설비·품목은 MES 코드 **스냅샷**으로 저장한다. 규격 수치가 QMS 검사 기준과 같아도 복사하지 않고 SPC가 따로 가진다(FS-013 D1 — 중복은 정상) |
| **D39** | 부분군 | **부분군 = 한 공정 실행 안에서 한 시각에 연속 측정한 n=5개.** 측정 간격은 **6시간**. 공정 실행 1건(LOT×공정)에서 부분군 여러 개가 나온다. 이유: LOT당 1개로는 특성별 점이 8개뿐이라 관리도가 성립하지 않는다(보통 20~25개 이상 필요). 측정 시각은 그 공정 실행의 시작~종료(진행 중이면 현재) 안이어야 한다 |
| **D40** | 관리 한계 | 특성별 **처음 20개 부분군**으로 X̄·R의 중심선·한계를 산정해 **게시**한다(n=5: A2=0.577, D3=0, D4=2.114). 게시한 한계는 바꾸지 않는다. 재산정은 **새 버전**을 적용 시작 시각과 함께 게시한다. 부분군은 **측정 시각에 유효한 버전**으로 판정한다 |
| **D41** | 이상 판정 | 부분군을 기록할 때 서비스가 규칙 3개로 판정한다. **규칙 1** 한계 밖 1점 · **규칙 2** 중심선 한쪽 연속 9점 · **규칙 3** 연속 6점 증가 또는 감소(Western Electric·Nelson 규칙의 일부). X̄와 R 모두 규칙 1을, X̄는 규칙 2·3도 본다. 판정 결과는 **이상 기록**으로 남기고 바꾸지 않는다 |
| **D42** | 조치 | 이상 기록은 **발생 → 조치 완료** 두 상태다. 조치 완료에는 원인 분류(설비·자재·작업자·방법·측정·환경 — 4M1E+측정)·조치 내용이 필수다. 측정 입력 실수는 부분군을 **무효 처리**(사유 필수)하고, 그 부분군으로 생긴 이상 기록은 "무효"가 된다. 무효 부분군은 관리도·공정능력 계산에서 뺀다 |
| **D43** | 공정능력 | **Cp = (USL−LSL) / 6σ̂, Cpk = min(USL−μ, μ−LSL) / 3σ̂, σ̂ = R̄/d2(d2=2.326).** 저장하지 않고 조회할 때 계산한다(선택한 기간·유효 부분군). 한쪽 규격만 있으면 Cpk만 계산한다. 판정 기준: 1.33 이상 충분 · 1.00~1.33 주의 · 1.00 미만 부족 |
| **D44** | QMS 연계 | SPC는 미조치 이상이 있는 LOT 번호를 **조회로만** 내놓는다. QMS 검사 대기·결과 화면에 **"SPC 이상" 배지**만 표시하고, 판정·보류를 막거나 바꾸지 않는다(D10과 같은 방식). QMS는 동결 상태지만 이 배지는 로드맵이 정한 이웃 변경이다 |

### D39·D40 보충 — 시드 규모

특성 6개(품목 3 × 사출 치수 1 + 조립 치수 1). 사출 실행은 약 2~3일, 조립은 약 1~2일이므로 6시간 간격이면 LOT당 사출 약 10개·조립 약 6개 부분군이 나온다. **부분군 약 380개, 측정값 약 1,900개, 합계 약 2,300행**이다. 템플릿이 11,910행에서 약 14,200행(+19%)으로 늘어난다. 게스트 복사 시간은 FS-028c에서 다시 잰다(지금 중앙값 0.509초).

시드 이야기(정해진 결과):
- **FG-C200 사출 하우징 높이(INJ-02)**: 최근 LOT에서 연속 상승(규칙 3) 뒤 한계 초과(규칙 1). **미조치 이상**이 남아 있어 QMS 검사 대기에 "SPC 이상" 배지가 보인다. 최종검사 값은 규격 안이다. "합격했지만 공정은 흔들린다"는 장면이다.
- **FG-C100 조립 핀 피치**: 과거 이상 1건을 조치 완료했다(원인: 설비 — 지그 마모, 조치: 지그 교체). 조치 뒤 한계를 새 버전으로 다시 게시했다.
- 공정능력: 충분 4개 · 주의 1개 · 부족 1개가 되게 만든다.

## 3. 교차 조회 인터페이스 (D9 규칙 그대로)

| 제공 | 함수 | 용도 |
|---|---|---|
| MES `fs/mes/interface.py` **(추가)** | `operation_runs(date_from, date_to)` → `[{lotNo, itemCode, processCode, equipmentCode, startedAt, endedAt}]` (진행 중이면 `endedAt=None`) | 측정 입력 때 공정 실행 선택, 측정 시각 검사, 스냅샷 |
| SPC `fs/spc/interface.py` **(신규)** | `enabled()` · `open_signal_lot_nos(lot_nos)` → 미조치 이상이 있는 LOT 번호 집합 | QMS "SPC 이상" 배지 |

MES는 동결 상태지만 조회 함수 추가는 허용한다(로드맵 §3). MES·QMS는 SPC 테이블을 읽지 않고, SPC는 QMS를 읽지 않는다. SPC가 꺼져 있으면 QMS 배지 자리는 비어 있고 QMS는 그대로 동작한다.

## 5. 하지 않는 것

- 계수형 관리도(p·np·c·u), X̄-s·I-MR·EWMA·CUSUM 관리도, 다변량 관리도.
- Western Electric·Nelson 규칙의 나머지(2/3 영역 규칙 등), 사용자 정의 규칙.
- Pp·Ppk(장기 성능), 정규성 검정, 측정 시스템 분석(Gage R&R), 실험계획(DOE).
- 계측기·설비에서 측정값 자동 수집(실제라면 이 자리가 PLC·CMM 연동이다). 측정값은 화면 입력과 시드뿐이다.
- 이상 발생 때 MES 설비·LOT 정지, QMS 자동 보류. 알림 발송.
- QMS 검사 기준에서 규격 가져오기(D38 — 필요하면 살 붙이기 단계에서 `qms.interface`로).

## 6. 승인 요청 사항

1. D37~D44를 확정해도 되는가.
2. **부분군 간격 6시간·n=5**(D39)와 그에 따른 **템플릿 약 +2,300행**(D39 보충)이 괜찮은가. 줄이려면 간격을 8시간으로 늘린다(약 −25%).
3. **QMS "SPC 이상" 배지**(D44)를 SPC 사이클 안에서 넣어도 되는가(QMS는 동결 상태).
4. **SPC 운영 반영 때 홈을 분야별 묶음으로 바꾸는 것**(4장 포털)을 이 사이클에 포함해도 되는가.
