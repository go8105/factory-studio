## 1. 배경

설계 초기부터 에너지 분해 식이 있었지만 구현된 적이 없다.

> **사업장 전체 = 제조 + 공용 + 미계측 잔여** (예: 450 = 288 + 132 + 30 kWh — `docs/모듈형플랫폼_설계결정.md`)

| 지금 | 상태 |
|---|---|
| FEMS 계측기 | 수전(M-MAIN)·설비 8·가스·용수. `scope_kind`는 factory/site_total뿐('common'은 FS-008c에서 삭제) |
| 공용 부하 | 시드에서 수전 값에 **숨겨져** 있다(주간 25·야간 15 kWh/h). 따로 재는 계측기가 없다 |
| 분해 화면 | 없다. F-01·F-07은 사업장 합계와 설비 배분을 따로 보일 뿐 빼지 않는다 |
| BEMS | FS-013에서 예약 2테이블 삭제, 격리 검사 R4가 `bems` 스키마를 금지. 설명 카드만 |

## 2. 결정

| # | 항목 | 결정 |
|---|---|---|
| **D18** | BEMS 범위 | **BEMS를 구현 솔루션에 넣는다.** 1차는 ① 공용 에너지 계측(조명·공조·사무동) ② 환경 관측(온도·습도·CO₂) ③ **공조 운전: 운전 스케줄·설정값·제어 명령** ④ **경보: 규칙·발생·확인·해제** ⑤ 사업장 에너지 분해. R4를 해제하고 설명 카드는 SCM 1종으로 줄인다 |
| **D19** | 계측 소유 | **공용 계측기·환경 센서·공조기는 BEMS가 소유한다**(FS-013 D1). FEMS 계측기·데이터는 바꾸지 않는다. BEMS는 FEMS의 사업장 합계·설비 배분을 **새 `fs/fems/interface.py`로 읽기만** 한다 |
| **D20** | 분해 식 | 전력만 분해한다(가스·용수는 1차 제외). **미계측 잔여 = FEMS 사업장 전력 합계(최상위 계측) − FEMS 제조(설비 직접 계측 배분) − BEMS 공용 계측 합.** 저장하지 않고 조회할 때 계산한다. **잔여가 음수면 숨기지 않고 "불일치"로 표시**한다(FS-005 ERD 규칙) |
| **D21** | 제어는 모의 설비에 | 실제 장비는 없다. 제어 명령은 BEMS 안의 **모의 공조기 상태**를 바꾸고 명령 이력을 남긴다. 명령·설정값·스케줄의 효과는 **"운전 시뮬레이션 1시간 진행"**으로 다음 시간의 환경·공조 전력 관측값을 결정적 모델로 만들어 보인다. 실제 연계라면 이 자리가 BACnet·Modbus 게이트웨이다 |
| **D22** | 경보 | 규칙(센서 항목·상/하한·지속 시간)으로 관측값을 평가해 경보를 **발생 → 확인 → 해제** 상태로 기록한다. 발생·해제는 관측값으로만, 확인은 사람만 한다. 경보 이력은 바꾸지 않는다 |
| **D23** | 데이터 해상도 | 관측은 **1시간 간격**. 공용 전력은 FEMS 계측과 같은 기간(T−30~T−1, 30일), 환경 관측은 **최근 14일**(센서 6개 × 24 × 14 = 약 2,000행. 30일이면 약 4,300행 — 템플릿 크기·게스트 복사 시간 때문) |

D12(독립 동작)도 적용한다. FEMS를 꺼도 BEMS는 공용 계측·환경·공조·경보가 동작하고 분해 화면만 "FEMS 꺼짐 · 계산 불가"로 보인다. BEMS를 꺼도 FEMS는 그대로다.

### D21 보충 — 왜 시뮬레이션 진행인가

제어가 "기록만" 남으면 설정값을 바꿔도 아무 일도 일어나지 않아 BEMS를 보여 줄 수 없다. 반대로 실시간으로 움직이는 모의 장비는 백그라운드 작업·시계가 필요하고 게스트 공간마다 상태가 흘러간다. 사용자가 누르는 **1시간 진행**은 명령·설정값·스케줄 → 공조 운전 → 온도·CO₂·공조 전력 변화 → 경보 발생의 인과를 한 번에 보여 주고, 결정적이라 테스트할 수 있다.

## 3. 교차 조회 인터페이스 (D9 규칙 그대로)

| 제공 | 함수(새 파일) | 용도 |
|---|---|---|
| FEMS `fs/fems/interface.py` | `site_electricity(scope, start, end)` · `manufacturing_electricity(scope, start, end)` · `enabled` | 분해의 사업장 합계·제조 배분(일·월) |

FEMS가 조회 인터페이스를 공개하는 것은 처음이다. FEMS는 BEMS를 읽지 않는다. 격리 검사 R1·R5에 `bems` 추가, **R4에서 `bems` 삭제**, R6 그대로.

## 5. 하지 않는 것

- 실제 장비 연계(BACnet·Modbus·OPC UA), 외기 온도·날씨 데이터, 재실 감지.
- 가스·용수의 공용 분해, 공용 에너지 요금·배출량(FEMS 영역과 겹침).
- 자동 최적 제어(모델 예측 제어), 수요 반응(DR), 피크 제어.
- 경보 알림 발송(메일·문자).
