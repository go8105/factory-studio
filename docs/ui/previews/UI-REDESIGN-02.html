UI-REDESIGN-02 — 화면 구도 시안

2026-11-08 · 현재 화면 구도를 확인하고 바뀔 모습을 먼저 본다. 제품 코드는 아직 바꾸지 않았다.

이 페이지는 구도만 보는 축소 모형이다. 실제 화면·실제 데이터가 아니고, 글자는 읽을 수 없게 줄여 두었다. 보려는 것은 “무엇이 어디에, 얼마나 크게 놓이는가”다. 색·글꼴·아이콘은 기존 기준(백자·먹색·쪽빛)을 그대로 쓴다.

0. 지금 무엇이 문제인가 — 실제 화면에서 잰 것

1440×900에서 솔루션 8곳의 대시보드를 열어 본문 아래쪽 빈 공간의 비율을 눈으로 쟀다.

화면 본문 구성 아래쪽 빈 공간
SPC S-01 KPI 5개뿐. 아래 아무것도 없음 약 85%
HR 인사 현황 KPI 4 + 표 3개(모두 머리글만, 내용 1줄) 약 60%
MES M-01 KPI 4 + 2열 카드 5장(대부분 빈 상태) 약 45%
WMS W-01 KPI 4 + 2열 카드 3장 약 40%
QMS Q-01 KPI 4 + 2열(왼쪽 3장·오른쪽 2장, 높이 어긋남) 약 35%
FEMS F-01 KPI 4 + 차트 + 2열 카드 4장 거의 없음 — 가장 잘 된 화면
  • 세로를 못 쓴다. 카드가 내용만큼만 높아지고 남은 높이를 아무도 가져가지 않는다. 데이터가 적은 솔루션일수록 화면이 비어 보인다.
  • 가로를 못 쓴다. 본문 폭 제한이 없어 1440px에서 카드 한 장이 1,100px인데 담긴 내용은 “0건” 한 줄이다.
  • 카드 높이가 어긋나 계단이 된다 — 틀린 진단이었다. 2026-11-08에 1440×900에서 실제로 재 보니 같은 행의 카드는 229/229, 151/151로 이미 맞고 있었다. 앞서 2열로 보이지 않는 좁은 폭에서 본 것을 계단으로 착각했다.
  • 규격이 솔루션마다 다르다. KPI가 SPC만 5개, 나머지는 4개다.
  • 빈 상태가 큰 면적을 먹는다. “이달 불량이 없습니다” 한 줄에 카드 한 장(약 160px)을 쓴다.

1. 대시보드 — KPI 줄 + 주요 차트 + 처리할 일

고치는 것: 남은 높이를 본문이 흡수한다 · 빈 카드는 카드를 없애고 한 줄로 접는다 · KPI는 어느 솔루션이든 4개 한 줄.

  • 왼쪽 주요 카드가 남은 높이를 흡수한다. 데이터가 적어도 화면이 비지 않는다.
  • KPI 타일 높이를 줄여(현재 약 110px → 88px) 본문에 세로를 돌려준다.
  • SPC는 KPI 5개 → 4개로 맞추고 다섯째 값은 주요 카드 안으로 내린다.

4. 이 시안에 없는 것

  • 색·글꼴·아이콘을 바꾸지 않는다. 백자·먹색·쪽빛과 단색 선 아이콘, 그림자 4% 기준은 그대로다. 바꾸는 것은 배치와 밀도뿐이다.
  • 새 라이브러리를 넣지 않는다. 차트는 지금 쓰는 방식 그대로다.
  • 업무 규칙·계산·DB를 건드리지 않는다. 화면에 무엇을 보여 줄지만 바꾼다.
  • flow·3D 공장·CAD·CAM·GW 셸은 이번 범위 밖이다(각각 다른 셸이고 GW는 다른 담당이다).
