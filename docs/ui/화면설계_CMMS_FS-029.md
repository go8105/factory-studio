## 1. 메뉴 (7화면)

```
CMMS 설비보전
├─ 보전 현황
│   ├─ C-01  대시보드
│   └─ C-07  보전 지표
├─ 보전 작업
│   ├─ C-02  전환 대기 신호
│   ├─ C-03  작업지시
│   └─ C-04  예방보전 계획
└─ 기준정보
    ├─ C-05  설비 대장
    └─ C-06  예비품
```

- 라우트 `/cmms/*`, 레이아웃 `CmmsLayout` = `SolutionLayout` + `cmmsScreens`. 메뉴 묶음 이름은 화면 제목과 겹치지 않게 한다.
- 다른 앱 링크: 다른 솔루션 `*Layout`의 전환 목록에 "CMMS 설비보전" 1줄.
- 홈: "생산·품질" 묶음에 CMMS 타일(MES · QMS · SPC · CMMS 순, 아이콘 = 렌치·톱니 라인). 솔루션 수 문구는 자동.

## 2. 화면별 설계

### C-01 대시보드 — 패턴 D

```
보전 개요 C-01                                               [? 도움말]
┌ 진행 중 작업지시 ┐┌ 전환 대기 신호 ┐┌ 주기 도래 PM ┐┌ 최근 30일 MTTR ┐
│ 1 · 고장 1       ││ 3 · BEMS 1 SPC 2 ││ 1            ││ 2.4 h           │
└──────────────────┘└─────────────────┘└──────────────┘└─────────────────┘
┌ 진행 중 작업지시(3fr) ─ 번호·설비·제목·상태·경과 ┐┌ 주기 도래 PM(2fr) ─ 계획·설비·예정일·[작업지시 생성] ┐
```

- 전환 대기 KPI는 C-02로, 주기 도래 KPI는 C-04로 링크. MES·BEMS·SPC가 꺼져 있으면 그 출처는 "꺼짐"으로 적고 수에서 뺀다.

### C-02 전환 대기 신호 — 패턴 L + FormPanel · **교차 조회 시연 화면**

```
전환 대기 신호 C-02                                          [? 도움말]
(role=note) BEMS 경보와 SPC 이상을 읽어 옵니다. 전환해도 원래 경보·이상의 상태는 바뀌지 않습니다.
[출처: 전체 ▾]
┌ 발생 시각 │ 출처 │ 내용 │ 설비(추정) │ 상태 │ 관리 ┐
│ 09-28 11:00 │ BEMS │ 사무동 CO₂ 1,180 ppm(경고) │ AHU-OFF │ 확인 대기 │ 작업지시로 전환 │
│ 09-11 15:00 │ SPC  │ FG-C200 사출 하우징 높이 · 규칙 1 · LT-0017 │ INJ-02 │ 미조치 │ 작업지시로 전환 │
└──────────────────────────────────────────────┘
[이미 전환한 신호 ▸] (접기) — 신호 · 작업지시 번호 · 상태
      ┌ 고장 작업지시로 전환 (FormPanel) ─────────────┐
      │ 신호: SPC 규칙 1 · LT-0017 · 09-11 15:00       │
      │ 설비 [INJ-02 사출기 2 ▾]  (대장에 없으면 C-05 안내) │
      │ 제목 [INJ-02 냉각수 유량 점검]                   │
      │ 정지 시작 [2026-09-11 15:00] (기본 = 신호 발생) │
      │ 설명 [ ... ]                         [전환]    │
      └────────────────────────────────────────────┘
```

- 설비 기본값: SPC는 이상의 설비 코드와 원천 코드가 같은 대장 설비, BEMS는 경보 구역의 공조기(13장 2). 대장에 없으면 선택 목록 위에 "설비 대장에서 가져오기 →" 안내.
- 전환 후 `role=status` "작업지시 WO-…를 만들었습니다 [작업지시 →]". 409 `ALREADY_CONVERTED`는 "이미 WO-…로 전환한 신호입니다".
- 원천 링크: BEMS B-06 경보 상세, SPC S-05 이상 상세(경로만, 상태는 거기서 확인·조치).

### C-03 작업지시 — 패턴 L + DetailPanel wide · **CMMS 시연 화면**

```
작업지시 C-03                                     [고장 접수] [? 도움말]
[상태: 진행 중 ▾] [종류: 전체 ▾] [설비 ▾]
┌ 번호 │ 관리 │ 설비 │ 종류 │ 제목 │ 출처 │ 접수 │ 상태 ┐
│ WO-20260930-002 │ 상세 │ ASM-03 │ 고장 │ 공압 실린더 누설 │ 수동 │ 09-30 08:10 │ 진행 중 │
└────────────────────────────────────────────────┘
      ┌ WO-20260930-002 (DetailPanel wide) ──────────────────────────────┐
      │ ASM-03 조립기 3 · 고장 · 정지 시작 09-30 08:00 · 경과 26h          │
      │ 출처: 수동 접수 (SPC·BEMS 출처면 원천 요약과 링크)                  │
      │ [작업 기록] 시각 · 분 · 내용 ……  (+ 작업 기록 추가: 분 [ ] 내용 [ ]) │
      │ [부품 사용] 예비품 · 수량 ……    (+ 부품 추가: [예비품 ▾] 수량 [ ])   │
      │ [완료] 원인 [마모 ▾] 조치 [ ] 복구 시각 [ ]   [완료]  [취소…]        │
      └──────────────────────────────────────────────────────────────┘
```

- 상태별 버튼: 접수 → [시작], 진행 중 → 작업 기록·부품 추가·[완료], 접수/진행 중 → [취소…](사유). 완료·취소는 읽기 전용(배지 "완료"/"취소").
- 고장 접수(수동) `FormPanel`: 설비·제목·정지 시작(기본 지금)·설명.
- MES 연결 안내(BM 진행 중, MES 출처 설비): `role=note` "MES 공정 실행·설비 화면에 '보전 중' 배지로 보입니다. MES 작업은 막지 않습니다."
- 미저장 보호: 작업 기록·부품·완료 입력 중 닫기/이동 확인(UI-04).

### C-04 예방보전 계획 — 패턴 L + FormPanel

- 열: 코드 · 설비 · 제목 · 주기(일) · 마지막 수행 · 다음 예정 · 상태(주기 도래 `warning` / 예정) · 관리([작업지시 생성] — 주기 도래일 때만, 이미 만들었으면 번호 링크).
- 등록·수정 `FormPanel`: 설비·코드·제목·점검 항목(여러 줄)·주기·시작일·사용. 마지막 수행일은 PM 완료로만 바뀐다(입력 칸 없음).

### C-05 설비 대장 — 패턴 S

- 열: 코드 · 이름 · 종류 · 위치 · 출처(MES/BEMS/CMMS 배지) · 원천 코드 · 열린 작업지시 수 · 사용.
- 상단 [MES에서 가져오기] [BEMS 공조기 가져오기]: 결과 `role=status` "새로 3 · 이미 있음 8". 출처가 꺼져 있으면 버튼 비활성 + 안내.
- 직접 등록 `FormPanel`(출처 CMMS): 코드·이름·종류·위치.

### C-06 예비품 — 패턴 S

- 열: 코드 · 이름 · 단위 · 안전 재고 · 최근 30일 사용 · 누적 사용 · 표시("주의 — 최근 사용이 안전 재고 이상").
- `role=note`: "재고 수량은 CMMS가 관리하지 않습니다(WMS 영역). 사용 기록만 남깁니다."

### C-07 보전 지표 — 패턴 D

```
보전 지표 C-07                                    [기간 from] [to] [조회]
┌ 고장 건수 ┐┌ 평균 MTTR ┐┌ 평균 MTBF ┐┌ PM 준수율 ┐
┌ 설비별 정지 시간 가로 막대(값 표 함께) ┐
┌ 표: 설비 · 고장 · 정지 시간 · MTTR · MTBF(고장 없음이면 "고장 없음") ┐
<details> 계산식: MTTR = Σ정지 ÷ 고장 · MTBF = (기간 − 정지) ÷ 고장 · PM 준수 = 예정일까지 완료 ÷ 예정 PM(유예 0일)
```

## 3. 다른 솔루션 화면 변경

| 화면 | 변경 |

| MES M-05 공정 실행 · M-11 설비 | 설비 코드 옆 `Badge tone="warning"` **"보전 중"**(`maintenance=true`일 때만). 안내 "진행 중인 고장 작업지시가 있습니다(CMMS). 실행은 막지 않습니다." CMMS 꺼짐이면 표시 없음(D52) |

## 4. 도움말·흐름 맵

- 도움말 `content/help/cmms/c-01.md`~`c-07.md`(체험 순서 포함). 개념 문서 2편: "MTBF와 MTTR", "예방보전과 사후보전".
- 흐름 맵: 업무 노드 `maintenance`(CMMS 작업지시, 도움말 `cmms/c-03`). 연결 `process_control → maintenance` "설비 원인 이상을 작업지시로 전환한다", `building_energy → maintenance` "공조 경보를 작업지시로 전환한다", `maintenance → operation_run` "보전 중 설비는 MES에 배지로 보인다". 노드·연결 18·21 → 19·24.

## 5. 검증 계획 (FS-029b·c)

- 단위(vitest): C-02 출처 꺼짐 표시·이미 전환 안내, C-03 상태별 버튼·완료 필수 칸·BM 복구 시각, C-04 주기 도래 버튼, C-05 가져오기 결과, C-07 고장 없음 표시, MES 배지 true/false/null, 홈 묶음 CMMS.
- e2e: C-02 SPC LT-0017 이상 → 전환 → C-03 시작·작업 기록·부품·완료 → MES M-05 INJ-02 배지 진행 중 보이고 완료 뒤 사라짐 / 주기 도래 PM → 작업지시 생성 → 완료 → 다음 예정일 갱신 / SPC 끔 → C-02 SPC 출처 꺼짐.
- `layout.spec`: C-02·C-03·C-04 1440×900 목록 채움, C-03 넓은 패널 640px 가로 넘침 없음. portal 360px 경로 목록에 `/cmms/*`.
