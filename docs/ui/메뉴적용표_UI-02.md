공통 변경(앱 틀·바닥글 제거·표 머리글 고정·KPI 2×2/한 줄·대시보드 2열·긴 값 포커스 펼침)은 **모든 화면에 이미 적용**되어 있다. 아래 "대기"는 화면 구조 교체 작업이다.
