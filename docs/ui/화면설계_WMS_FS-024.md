## 1. 메뉴 (7화면)

```
WMS 창고관리
├─ 재고 현황
│   ├─ W-01  대시보드
│   └─ W-02  재고 현황
├─ 입출고
│   ├─ W-03  원천 반영
│   ├─ W-04  재고 전표
│   └─ W-05  재고 원장
└─ 기준정보
    ├─ W-06  창고·위치
    └─ W-07  품목·단위
```

- 라우트 `/wms/*`, 레이아웃 `WmsLayout` = `SolutionLayout`에 `wmsScreens` 배열만 넘긴다(UI-01 규칙).
- 포털 런처에 **WMS 창고관리** 5번째 타일(단색 라인 아이콘 — 선반/상자). 홈 격자는 5개가 한 줄에 들어가지 않으므로 **3·2 배치**(넓은 화면 `repeat(auto-fit, minmax(0,168px))`, 좁은 화면 2열 유지). 제목은 "제조 현장의 다섯 시스템"으로 바꾼다(FS-024c).
- 홈 하단 "아직 만들지 않은 것"은 **BEMS·SCM** 2개. 흐름 맵 `inventory_move` 노드는 업무 노드(도움말 `wms/w-03`).
- 다른 앱 링크: MES · ERP · FEMS · QMS · 포털 홈.

## 2. 화면별 설계

### W-01 대시보드 — 패턴 D (F-01)

```
재고 개요 W-01                                   [조회 월 ▾] [? 도움말]
┌ 원자재 품목 ┐┌ 완제품 LOT ─┐┌ 음수 재고 ─┐┌ 미반영 원천 ┐
│ 2 품목      ││ 11 LOT      ││ 0 건       ││ 9 건        │   ← KPI 4개(좁으면 2×2)
└────────────┘└─────────────┘└───────────┘└─────────────┘
┌ 품목별 현재고·가용 (3fr) ─────────────┐┌ 원천별 미반영 (2fr) ────┐   ← dashboard-grid has-lead
│ 품목 │ 현재고 │ 가용 │ 단위 │ 상태      ││ MES 입고 1 · MES 투입 6 │
└──────────────────────────────────────┘│ ERP 출하 1 · ERP 매입 1 │
┌ 월 입출고 (입고 합 · 출고 합, 품목별) ┐└──────────────────────────┘
└──────────────────────────────────────┘
```

- 음수 재고 KPI가 1 이상이면 `Badge tone="issue"` "확인 필요", 누르면 W-02 `negativeOnly`.
- 미반영 원천은 원천 솔루션이 꺼져 있으면 그 종류만 "꺼짐"(값 대신). 전부 꺼져 있으면 KPI에 "조회 불가".
- 가용 = 현재고 − ERP 미출하 지시(D17). ERP 꺼짐이면 가용 열에 "계산 불가".
- 조회 월 기본값: 확정 전표가 있는 가장 최근 월(QMS Q-01과 같은 방식).

### W-02 재고 현황 — 패턴 L (F-02)

```
재고 현황 W-02                                                  [? 도움말]
[창고 ▾] [품목 ▾] [LOT 번호] [☐ 음수만] [☐ LOT 미지정만] [조회]
표 · 총 14건 · CSV
┌ 창고 │ 위치 │ 품목 │ LOT │ 현재고 │ 가용 │ 단위 │ 상태 ┐
│ WH-FG │ F-A01 │ FG-C200 │ LT-0005 │ 1,921 │ — │ EA │ │

│ WH-RAW│ R-A01 │ RM-PIN  │ — │ 82,340 │ — │ EA │ │

```

- `.page-fill` — 표만 스크롤, 머리글 고정. 현재고 0인 행은 기본 숨김(`☐ 0 포함`은 두지 않는다 — 원장 W-05에서 본다).
- 가용은 **완제품 품목 합계 행**에만 둔다(LOT별 가용은 계산하지 않는다). 표 아래 품목별 합계 줄 `FG-C100 합계 현재고 · 미출하 지시 · 가용`.
- 행의 "원장" 링크 → W-05(품목·LOT 조건을 채워 연다).
- 상태 배지는 색만으로 구분하지 않고 문구를 쓴다: "음수"(`issue`), "LOT 미지정"(`warning`).

### W-03 원천 반영 — 패턴 L (F-02) · **교차 조회 시연 화면**

```
원천 반영 W-03                                                   [? 도움말]
(role=note) MES·ERP에서 확정된 기록을 읽어 재고 원장에 반영합니다. WMS는 MES·ERP 데이터를 바꾸지 않습니다.
[MES 완제품 입고] [MES 자재 투입] [ERP 출하] [ERP 매입]      ← tabs(F-13과 같은 탭)
[상태: 미반영 ▾]                              [미반영 N건 모두 반영]
표 · 총 1건
┌ 원천 번호 │ 관리 │ 원천 시각 │ 품목·수량 요약 │ 상태 ┐
│ PL-0006 │ 반영 │ 08-24 15:00 │ FG-T300 1,964 EA (LOT 2) │ 미반영 │
│ PI-0006 │ 취소 반영 │ 08-24 │ RM-PBT 100 KG · RM-PIN 3 BOX │ 취소 미반영 │
│ (예시) PI-… │ — │ … │ 미등록 품목 5 KG │ 반영 불가 · 품목 미등록 [W-07] │
└──────────────────────────────────────────────────────┘
```

- 상태 필터: 미반영(기본) · 반영됨 · 전체. "반영됨" 행의 관리 열은 전표 번호 링크(W-04 상세).
- **행 "반영"** → `POST /sources/sync` 1건 → 행이 "반영됨 · WD-…"로 바뀌고 `role=status` 안내. **"미반영 N건 모두 반영"** → 확인 대화 없이 실행(되돌릴 필요가 생기면 조정 전표 — 원천 반영은 되돌리지 않는다, 모듈 설계 13장 3). 결과는 표 위 요약 "반영 7 · 반영 불가 1(품목 미등록)".
- 반영 불가 행은 버튼 대신 사유 배지 + 해결 화면 링크(품목 미등록·단위 환산 없음 → W-07).
- ERP 출하 탭은 "LOT 요약" 열에 팔레트 번호와 매칭 결과를 미리 보여 준다: "PL-0004 → LOT 2" 또는 "LOT 미지정으로 차감".
- 원천 솔루션이 꺼져 있으면 그 탭은 `EmptyState` "MES를 사용하지 않도록 설정했습니다. 수동 전표(W-04)로 재고를 관리할 수 있습니다" + 행동 "재고 전표로".
- MES 자재 투입 탭 안내(role=note): "완료된 공정 실행의 투입만 보입니다. 실행 중에는 MES에서 투입을 고칠 수 있기 때문입니다."

### W-04 재고 전표 — 패턴 W (E-04 넓은 행 편집)

```
재고 전표 W-04                              [전표 만들기 ▾ 기초·조정·이동] [? 도움말]
[유형 ▾] [상태 ▾] [월]
┌ 전표번호 │ 관리 │ 유형 │ 원천 │ 줄 │ 상태 │ 업무일 ┐
│ WD-…-003 │ 상세 │ ERP 출하 │ SH-0003 │ 2 │ 확정 │ … │
│ WD-…-011 │ 편집 · 삭제 │ 이동 │ — │ 2 │ 작성 중 │ … │
└──────────────────────────────────────────────────┘
          ┌ WD-…-011 창고 간 이동 (FormPanel wide) ──────────────────┐
          │ 업무일 [ … ]  메모 [            ]                          │
          │ 품목      LOT      보낼 위치     받을 위치     수량     단위   │  ← 이동은 한 줄 = 보낼·받을 한 쌍
          │ [FG-C100▾] [LT-0004▾] [F-A01▾]  [F-A02▾]   [ 500 ]   EA  [삭제] │
          │ [줄 추가]                                                  │
          ├──────────────────────────────────────────────────────────┤
          │ [임시 저장] [확정] [닫기]      확정하면 수정할 수 없습니다       │
          └──────────────────────────────────────────────────────────┘
```

- 전표 만들기: 유형 셋 중 하나를 고르면 같은 자리의 `FormPanel wide`.
  - **기초재고**: 줄 = 품목·위치·LOT(완제품만)·수량(+).
  - **조정**: 사유 select(`RETURN` 반품 입고·`SCRAP` 폐기·`COUNT` 실물 차이·`OTHER` 기타 — 기타는 메모 필수). 줄 = 품목·위치·LOT·**증감**(+/−, 0 불가).
  - **이동**: 줄 = 품목·LOT·보낼 위치·받을 위치·수량. 저장 시 서버가 −/+ 두 이동 줄로 만든다(모듈 설계 4.6 — 합 0). 같은 위치, 완제품 LOT 미지정은 필드 오류.
- 확정 전표(원천 반영 포함)는 `DetailPanel wide` 읽기: 줄 표(품목·위치·LOT·수량·원천 수량·단위) + 원천 번호. 되돌림 전표는 원 전표 링크.
- LOT select는 그 위치에 현재고가 있는 LOT만 보여 준다(선택 편의 — 음수 허용이므로 수량은 막지 않는다, D15). 확정 시 음수가 생기면 확정은 되고 `role=status`에 "FG-C100 F-A01 재고가 음수가 됩니다" 안내.
- 미저장 보호: 줄·메모·사유 draft 비교(`useDiscardGuard`). 줄 편집은 E-04 `LineEditor` 구조를 쓴다.

### W-05 재고 원장 — 패턴 L (F-02)

```
재고 원장 W-05                                                   [? 도움말]
[기간 from] [to] [품목 ▾] [LOT] [창고 ▾] [전표 유형 ▾] [조회]
표 · 총 55건 · CSV
┌ 일시 │ 전표 │ 유형 │ 원천 │ 품목 │ 위치 │ LOT │ 증감 │ 누계 │ 단위 ┐
│ 08-03 15:00 │ WD-…-004 │ MES 입고 │ PL-0001 │ FG-C100 │ F-A01 │ LT-0001 │ +1,940 │ 1,940 │ EA │
│ 08-10 10:00 │ WD-…-009 │ ERP 출하 │ SH-0001 │ FG-C100 │ F-A01 │ LT-0001 │ −1,940 │ 0 │ EA │
└────────────────────────────────────────────────────────────────┘
```

- 누계 열은 **품목(+LOT) 조건을 줬을 때만** 계산해 보인다(여러 품목이 섞이면 의미가 없다) — 조건 없으면 열 숨김.
- 전표 번호 → W-04 상세, 원천 번호는 텍스트(다른 솔루션 화면으로 링크하지 않는다 — 번호는 스냅샷이고 원천 화면 id를 모른다, D11).
- 원천 수량·단위가 다르면(핀 BOX) 증감 옆에 작게 "10 BOX".

### W-06 창고·위치 — 패턴 P (F-12 부모-자식)

```
창고·위치 W-06                                         [창고 등록] [? 도움말]
┌ 코드 │ 관리 │ 이름 │ 용도 │ 위치 │ 사용 ┐
│ WH-RAW │ 위치 2 · 수정 │ 원자재 창고 │ 원자재 │ 2 │ 사용 │
│ WH-FG  │ 위치 2 · 수정 │ 완제품 창고 │ 완제품 │ 2 │ 사용 │
└────────────────────────────────────────┘
                       ┌ WH-FG 위치 (DetailPanel wide) ───────────┐
                       │ 코드 │ 이름 │ 기본 │ 사용 │ 관리            │
                       │ F-A01 │ 기본 보관 │ ● 기본 │ 사용 │ 수정     │
                       │ [위치 추가]                                │
                       └────────────────────────────────────────────┘
```

- "위치 N" → 위치 상세, 추가·수정은 같은 자리 `FormPanel`(닫으면 위치 상세로) — F-12와 같은 흐름.
- 용도(원자재·완제품)는 활성 창고당 1개. 같은 용도 두 번째 창고를 사용으로 바꾸면 필드 오류 "원천 반영 창고가 겹칩니다".
- 기본 위치 변경은 라디오. 기본 위치는 사용 안 함 불가. 이동이 있는 위치는 삭제 409 → 패널 안 참조 건수, 사용 안 함 안내.

### W-07 품목·단위 — 패턴 S (F-05)

```
품목·단위 W-07                        [MES 품목 가져오기] [품목 등록] [? 도움말]
┌ 코드 │ 관리 │ 이름 │ 분류 │ 기본 단위 │ LOT 추적 │ 환산 │ 사용 ┐
│ RM-PIN │ 수정 │ 단자 핀 │ 원자재 │ EA │ — │ 1 BOX = 10,000 EA │ 사용 │
└──────────────────────────────────────────────────────────────┘
```

- 목록 + `FormPanel`(코드·이름·분류·기본 단위·사용). LOT 추적은 분류에서 정해진다(완제품 = 추적, 표시만).
- 환산은 같은 패널 아래 작은 표(단위·계수) — 행 추가·삭제. 쓰인 단위의 환산 삭제는 막지 않는다(원장에 원천 수량이 남아 있다).
- **MES 품목 가져오기**: MES 품목 중 WMS에 없는 원자재·완제품 목록을 `FormPanel`에 체크 목록으로 보여 주고(폼 안 체크박스는 기존 `.inline-check`), 고른 것을 등록. 코드·이름·단위는 스냅샷. MES 꺼짐이면 버튼 비활성 + "MES 꺼짐" 안내.
- 쓰인 품목은 삭제 대신 사용 안 함(409 참조 건수).
