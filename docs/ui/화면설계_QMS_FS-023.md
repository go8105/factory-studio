원칙: **새 화면 패턴을 만들지 않는다.** 6화면 모두 UI-02·03에서 확정한 D·L·S·P·V·W 패턴과 공통 컴포넌트로 만든다.

## 1. 메뉴 (6화면)

```
QMS 품질관리
├─ 품질 현황
│   └─ Q-01  대시보드
├─ 검사
│   ├─ Q-03  검사 대기
│   ├─ Q-04  검사
│   └─ Q-05  품질 보류
└─ 기준정보
    ├─ Q-02  검사 기준
    └─ Q-06  불량 유형
```

- 라우트 `/qms/*`, 레이아웃 `QmsLayout` = `SolutionLayout`에 `qmsScreens` 배열만 넘긴다(UI-01 규칙).
- 포털 런처에 QMS 앱 타일 추가(단색 라인 아이콘), 설명 카드는 WMS·BEMS·SCM 3종.
- 다른 앱 링크: MES · ERP · FEMS · 포털 홈.

## 2. 화면별 설계

### Q-01 대시보드 — 패턴 D (F-01)

```
품질 개요 Q-01                                   [조회 월 ▾] [? 도움말]
┌ 검사 ─────┐┌ 합격률 ───┐┌ 활성 보류 ─┐┌ 검사 대기 ─┐
│ 15 건      ││ 86.7 %    ││ 1 LOT      ││ 3 LOT      │   ← KPI 4개(한 줄 / 좁으면 2×2)
└───────────┘└───────────┘└───────────┘└───────────┘
┌ 일자별 검사·불합격 (3fr) ────────────┐┌ 불량 유형 상위 5 (2fr) ┐   ← dashboard-grid has-lead
└─────────────────────────────────────┘└─────────────────────────┘
┌ 활성 보류 LOT ───────────────────────┐┌ 최근 불합격 검사 ──────┐
└─────────────────────────────────────┘└─────────────────────────┘
```

- 검사 대기 KPI는 MES 조회 결과. MES가 꺼져 있으면 "MES 꺼짐 · 조회 불가" 배지(값 대신).
- 합격률 = 확정 검사 중 PASS ÷ 확정 검사. 검사 0건이면 "계산 불가"(0% 오표시 금지).

### Q-02 검사 기준 — 패턴 P (F-12 부모-자식)

```
검사 기준 Q-02                                   [기준 만들기] [? 도움말]
┌ 품목 │ 관리              │ 버전 │ 상태    │ 항목 │ 게시일 ┐
│ FG-C100 │ 항목 5 · 개정 · 폐기 │ v1 │ 게시    │ 5 │ …   │
│ FG-C100 │ 항목 5 · 게시 · 삭제 │ v2 │ 초안    │ 5 │ -   │
└──────────────────────────────────────────────────────────┘
                          ┌ FG-C100 v2 검사 항목 (DetailPanel wide) ┐
                          │ 순서 │ 항목 │ 방식 │ 하한 │ 상한 │ 단위 │ 필수 │ 관리 │
                          │ [항목 추가]            (게시본은 관리 없음) │
                          └─────────────────────────────────────────────┘
```

- "기준 만들기" → FormPanel(품목: MES 조회 목록 select, MES 꺼짐이면 코드·이름 직접 입력).
- "항목 N" → 항목 상세 `DetailPanel wide`, 항목 추가·수정은 같은 자리의 `FormPanel`(닫으면 항목 상세로) — F-12와 같은 흐름.
- 방식 `RANGE` 선택 시 하한·상한·단위 입력(`.field-row`), `PASS_FAIL`이면 숨긴다.
- 게시·폐기·개정은 행 버튼. 게시본은 "게시한 기준은 바꿀 수 없습니다. 개정하세요" 안내(M-14와 같은 문구 체계).

### Q-03 검사 대기 — 패턴 L (F-02 조회 목록) · **교차 조회 시연 화면**

```
검사 대기 Q-03                                                   [? 도움말]
(role=note) MES에서 실적 확정이 끝난 LOT을 읽어 옵니다. QMS는 MES 데이터를 바꾸지 않습니다.
[완료일 from] [to] [품목 ▾] [작성 중 포함 ☐] [조회]
표 · 총 3건 · CSV
┌ LOT │ 관리 │ 품목 │ 최종 양품 │ 단위 │ 완료 시각 │ 상태 ┐
│ LT-0016 │ 검사 시작 │ FG-C100 │ 1,940 │ EA │ 09-24 16:10 │ 대기 │
│ LT-0017 │ 이어서 입력 │ FG-C200 │ 1,921 │ EA │ … │ 작성 중 │
└──────────────────────────────────────────────────────────┘
```

- `.page-fill` — 표만 스크롤, 머리글 고정.
- "검사 시작" → POST /inspections(source MES) → Q-04로 이동해 그 검사의 입력 패널을 연다(`/qms/inspections?open=<id>`).
- 게시 기준이 없는 품목은 "검사 시작" 대신 "기준 없음" 배지 + Q-02 링크.
- MES 꺼짐(409 `SOURCE_MODULE_DISABLED`): EmptyState "MES를 사용하지 않도록 설정했습니다. LOT 코드를 직접 입력해 검사할 수 있습니다" + 행동 "직접 입력으로 검사"(Q-04 직접 입력 패널).

### Q-04 검사 — 패턴 W (E-04 넓은 행 편집)

```
검사 Q-04                                        [직접 입력으로 검사] [? 도움말]
[상태 ▾] [판정 ▾] [월]
┌ 검사번호 │ 관리 │ LOT │ 품목 │ 표본 │ 판정 │ 상태 │ 검사일 ┐
└──────────────────────────────────────────────────────────┘
          ┌ QI-20260924-003 · LT-0016 검사 (FormPanel wide) ────────────┐
          │ 품목 FG-C100 · 기준 v1 · LOT 수량 1,940 EA · 표본 [ 32 ]      │
          │ 항목         기준            측정값      판정    불량 유형     │
          │ 외관         합·부           (●합 ○부)   합격                  │
          │ 핀 피치      2.48~2.52 mm    [2.53]     불합격  [DIMENSION▾]  │  ← 입력 즉시 판정 미리보기
          │ 절연 저항    ≥ 100 MΩ        [180 ]     합격                  │
          │ 메모 [                ]                                     │
          ├───────────────────────────────────────────────────────────┤
          │ [임시 저장] [확정] [닫기]     확정하면 수정할 수 없습니다        │
          └───────────────────────────────────────────────────────────┘
```

- 확정 검사는 `DetailPanel wide`(읽기) + foot "재검사"(같은 LOT 새 draft).
- 판정 미리보기는 화면 계산, **최종 판정은 서버 응답**으로 덮는다(모듈 설계 3장).
- 필수 항목 누락 확정 → 각 행 아래 `small` 오류(`details.fields.values.<seq>`).
- 불합격 확정 → 페이지 위 `role=status` "불합격 확정 · LT-0016 품질 보류 QH-… 생성" + Q-05 링크.
- 측정값 표는 `DataTable`이 아닌 입력 표(LineEditor와 같은 구조) — 열: 항목·기준·입력·판정 배지·불량 유형. 640px에서 가로 스크롤 없이 들어가도록 기준 열은 `.date-range`와 같은 두 줄 허용.
- 미저장 보호: 측정값·표본·메모 draft 비교(`useDiscardGuard`).

### Q-05 품질 보류 — 패턴 V (M-04) + FormPanel

```
품질 보류 Q-05                                                   [? 도움말]
[상태: 보류 중 ▾]
┌ 보류번호 │ 관리 │ LOT │ 품목 │ 원인 검사 │ 보류일 │ 상태/처분 ┐
│ QH-…-001 │ 상세 · 해제 │ LT-0012 │ FG-T300 │ QI-…-007 │ 09-20 │ 보류 중 │
└──────────────────────────────────────────────────────────┘
          ┌ LT-0012 보류 (DetailPanel wide) ──────────────┐
          │ 원인 검사 불합격 항목 표 · 재검사 이력 표          │
          │ foot: [해제 처분]                                 │
          └──────────────────────────────────────────────────┘
          ┌ 보류 해제 (FormPanel) ─────┐
          │ 처분 (●재검사 합격 ○특채 ○폐기 판정) │
          │ 재검사: [합격 검사 선택 ▾]          │
          │ 사유: [          ] (특채·폐기 필수)  │
          │ [해제] [취소]                       │
          └─────────────────────────────────────┘
```

- "해제"는 상세 패널에서 같은 자리의 FormPanel로(닫으면 상세로 — F-12 흐름).
- 재검사 합격이 없으면 "재검사 합격"을 비활성하고 "Q-04에서 재검사하세요" 안내.
- 안내(role=note): "보류는 QMS 기록입니다. MES 패킹을 막지 않으며, MES 패킹 화면에 보류 배지로 표시됩니다."

### Q-06 불량 유형 — 패턴 S (F-05)

- 목록 + FormPanel(코드·이름·사용 여부). 쓰인 유형 삭제 409 → 패널 안 참조 건수. 사용 안 함으로 바꾸면 새 검사 선택지에서 빠진다.

## 3. MES 화면 변경 (읽기만)

| 화면 | 변경 |
|---|---|
| M-08 패킹 — "담을 수 있는 LOT" | LOT 옆 `Badge tone="issue"` **"QMS 보류"**. 패킹 버튼은 그대로(D10). 표 위 안내 "QMS 보류는 표시만 하며 패킹을 막지 않습니다" |
| M-04 LOT — 목록·상세 | 목록 상태 열 옆 "QMS 보류" 배지, 상세 요약에 "품질 판정: 합격/불합격/미검사" |
| QMS 꺼짐 | 배지·판정 표시 없음(`qualityHold = null`) |

## 4. 도움말·흐름 맵

- 도움말 `content/help/qms/q-01.md`~`q-06.md` + 공통 안내에 "솔루션 간 읽기 전용 조회" 절.
- 흐름 맵: "품질검사" 노드 `MAP_ONLY → IMPLEMENTED`, 연결 `실적 확정 → 품질검사 → 패킹`. 기존 "(QMS 미구현 시 현재 경로)" 직결선은 **"QMS를 끄면 이 경로"** 점선으로 바꾼다. 노드 설명에 "보류는 표시만 한다(D10)".
- 포털 설명 카드 `content/cards/qms.md`는 도움말로 옮기고, 카드 목록에서 제외.

## 5. 검증 계획 (FS-023b·c)

- 단위: 판정 계산(RANGE 경계값·한쪽 한계·PASS_FAIL), 기준 게시 불변, 확정 불변, 보류 해제 조건.
- e2e: 검사 대기(MES 조회) → 검사 시작 → 불합격 확정 → 보류 → M-08에 배지 → 재검사 합격 → 해제. MES 끔 → 직접 입력 검사.
- `e2e/layout.spec.ts`: Q-03·Q-04·Q-05 1440×900 한 화면, Q-04 넓은 패널 640px·가로 넘침 없음.
- 공식 스모크, 360px 가로 스크롤 없음(portal.spec 경로 목록에 `/qms/*` 추가).
