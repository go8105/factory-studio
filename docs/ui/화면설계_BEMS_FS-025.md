- 홈 하단 "아직 만들지 않은 것"은 **SCM 1개**. 흐름 맵 `building_energy` 노드는 업무 노드(도움말 `bems/b-02`).
- 다른 앱 링크: MES · ERP · FEMS · QMS · WMS · 포털 홈. FEMS 화면은 바꾸지 않는다(D19).

## 2. 화면별 설계

### B-01 건물 대시보드 — 패턴 D (F-01)

```
건물 개요 B-01                          시뮬레이션 09-27 14:00 [1시간 진행] [? 도움말]
┌ 어제 사업장 전력 ┐┌ 공용 비율 ─┐┌ 활성 경보 ──────┐┌ 미계측 잔여 ─┐
│ 4,812 kWh        ││ 11.2 %     ││ 1 · 확인 대기 1  ││ 1.9 % 정상   │   ← KPI 4개(좁으면 2×2)
└──────────────────┘└────────────┘└──────────────────┘└──────────────┘
┌ 최근 7일 분해 (3fr) — 제조 · 공용 · 잔여 누적 막대 ┐┌ 활성 경보 (2fr) ────────┐
└──────────────────────────────────────────────────┘└──────────────────────────┘
┌ 구역 카드: 사무동 24.8℃ · CO₂ 1,040 ppm · 냉방 26℃ · AHU-OFF COOL(스케줄) ┐
└──────────────────────────────────────────────────────────────────────────────┘
```

- 1시간 진행 버튼은 B-01·B-04 두 곳(같은 API). 진행 결과는 `role=status` 요약.
- FEMS 꺼짐이면 사업장 전력·공용 비율·잔여 KPI는 "FEMS 꺼짐 · 계산 불가".
- 잔여가 음수인 날이 있으면 잔여 KPI에 `Badge tone="issue"` "불일치".

### B-02 에너지 분해 — 패턴 L (F-02) · **FEMS 교차 조회 시연 화면**

```
에너지 분해 B-02                                                  [? 도움말]
(role=note) 사업장 전력과 제조 전력은 FEMS에서 읽어 옵니다. BEMS는 FEMS 데이터를 바꾸지 않습니다.
[단위: 일 ▾] [기간 from] [to] [조회]
표 · 총 30건 · CSV
┌ 기간 │ 사업장 전체 │ 제조(FEMS) │ 공용 합 │ 조명 │ 공조 │ 사무동 │ 잔여 │ 상태 ┐
│ 09-26 │ 4,812 │ 4,208 │ 511 │ 132 │ 262 │ 117 │ 93 │ 정상 │
│ 09-11 │ 4,650 │ 4,590 │ 498 │ … │ … │ … │ −438 │ 불일치 │
└──────────────────────────────────────────────────────────────┘
```

- `.page-fill`. 표 위에 선택 기간 합계 막대 1개(제조·공용·잔여 비율).
- 불일치 행: 상태 배지 + 행 펼침 안내 "공용 계측이 수전보다 크거나 설비 배분이 빠졌을 수 있습니다(FEMS F-03 설비별 배분 확인)". FEMS 화면 링크는 경로만 연결한다(데이터는 잇지 않는다).
- 관측이 빠진 시간은 셈하지 않고 "계측 누락 N시간"을 적는다.
- FEMS 꺼짐(409 `SOURCE_MODULE_DISABLED`): `EmptyState` "FEMS를 사용하지 않도록 설정했습니다. 공용 계측(B-03)과 공조 운전은 그대로 쓸 수 있습니다".

### B-03 환경 모니터링 — 패턴 D (차트 + 값 표)

```
환경 모니터링 B-03                                                [? 도움말]
[사무동] [생산동]                         ← tabs(구역)
[기간: 최근 48시간 ▾]
┌ 실내 온도 ℃ — 관측선 + 냉방 설정값 점선 + 난방 설정값 점선 ┐
┌ CO₂ ppm — 관측선 + CO₂ 상한 점선 + 경보 구간 음영           ┐
┌ 습도 %                                                       ┐
[값 표 보기] → 시간 · 온도 · 습도 · CO₂ · 공조 상태 (CSV)
```

- 차트마다 figcaption·aria-label·값 표(색만으로 읽지 않게, UI-01). 시뮬레이션으로 만든 시간은 점 모양을 다르게 하고 범례에 "진행으로 생성"을 적는다.
- 기간 선택: 최근 24·48시간·7일·14일.

### B-04 공조 운전 — 패턴 V (M-04) + FormPanel · **제어 시연 화면**

```
공조 운전 B-04                          시뮬레이션 09-27 14:00 [1시간 진행 ▾ 1·3·6] [? 도움말]
┌ 공조기 │ 관리 │ 구역 │ 상태 │ 운전 출처 │ 실내 온도 │ 냉방 설정 │ CO₂ │ 전력(최근 1h) ┐
│ AHU-OFF │ 상세 │ 사무동 │ COOL │ 스케줄 │ 24.8 │ 26 │ 1,040 │ 9.8 kWh │
│ AHU-PRD │ 상세 │ 생산동 │ OFF │ 수동 │ 27.1 │ 27 │ 610 │ 0 kWh │
└──────────────────────────────────────────────────────────────┘
      ┌ AHU-OFF 사무동 공조기 (DetailPanel wide) ─────────────────┐
      │ 상태 COOL · 스케줄 운전(평일 08~19) · 정격 12 kW            │
      │ 설정값  냉방 26℃ · 난방 20℃ · CO₂ 상한 1,000 ppm           │
      │ [전원 끄기] [모드: 냉방 ▾ 적용] [설정값 변경]              │
      │ 최근 명령 표: 시각 · 명령 · 값 · 출처 · 결과(적용/거부 사유) │
      └────────────────────────────────────────────────────────────┘
            ┌ 설정값 변경 (FormPanel) ┐
            │ 항목 (●냉방 ○난방 ○CO₂) │
            │ 값 [ 23 ] ℃ (허용 20~30) │
            │ 메모 [      ]            │
            │ [적용] [취소]            │
            └──────────────────────────┘
```

- 명령은 즉시 결과를 보인다: 적용이면 상태·설정값 갱신, **거부도 이력으로 남고** 사유를 `role=status`로 알린다(범위 밖·이미 같은 상태).
- 수동 명령을 내리면 "다음 스케줄 경계(19:00)까지 수동 운전, 이후 스케줄로 돌아갑니다" 안내.
- 1시간 진행 결과 요약: "관측 12건 생성 · 스케줄 전환 1 · 경보 발생 1(사무동 CO₂) · 해제 0". 한도(업무 기준일 다음 날) 도달 시 버튼 비활성 + 이유.
- 설정값 폼을 닫으면 공조기 상세로 돌아간다(F-12 흐름).

### B-05 운전 스케줄 — 패턴 W (E-04 넓은 행 편집)

```
운전 스케줄 B-05                                                  [? 도움말]
┌ 공조기 │ 관리 │ 평일 │ 주말 ┐
│ AHU-OFF │ 편집 │ 08–19 냉방 │ 10–16 송풍 │
└──────────────────────────────┘
      ┌ AHU-OFF 운전 스케줄 (FormPanel wide) ───────────────────┐
      │ 평일  [08]시 ~ [19]시  [냉방 ▾] [삭제]                    │
      │ 주말  [10]시 ~ [16]시  [송풍 ▾] [삭제]                    │
      │ [시간대 추가]                                             │
      │ 24시간 막대 미리보기(평일·주말 두 줄, 모드별 무늬)          │
      │ [저장] [닫기]    저장하면 다음 경계부터 적용됩니다          │
      └──────────────────────────────────────────────────────────┘
```

- 겹치는 시간대는 행 아래 필드 오류(400 `fields.slots.<i>`). 시각 선택은 0~23 / 1~24 select(자유 입력 없음).
- 미저장 보호(`useDiscardGuard`). 행 편집 구조는 E-04 `LineEditor`.

### B-06 경보 — 패턴 L + DetailPanel · 규칙은 S

```
경보 B-06                                          [? 도움말]
[경보] [규칙]                        ← tabs
[상태: 확인 대기 ▾]
┌ 발생 시각 │ 관리 │ 구역 │ 항목 │ 규칙 │ 최고값 │ 등급 │ 상태 ┐
│ 09-27 11:00 │ 상세 · 확인 │ 사무동 │ CO₂ │ > 1,000 ppm 2h │ 1,180 │ 경고 │ 확인 대기 │
└────────────────────────────────────────────────────────────┘
      ┌ 경보 상세 (DetailPanel wide): 규칙 · 발생~현재 값 작은 차트 · 확인 메모 [확인] ┐
```

- 상태 필터: 확인 대기(`raised`) 기본 · 확인됨 · 해제됨 · 전체. 등급·상태는 문구 배지(`CRITICAL`=issue, `WARNING`=warning).
- "확인"은 메모(선택)와 함께 TX-B3. 해제는 관측으로만 일어난다는 안내("환기·설정값 변경 후 1시간 진행으로 해제를 확인하세요", B-04 링크).
- 규칙 탭: 목록 + FormPanel(구역·항목·비교·한계값·지속 시간·등급·사용).

### B-07 구역·계측 — 패턴 P (F-12)

- 구역 목록 → 구역 상세(`DetailPanel wide`)에 계측기·센서·공조기 세 표 → 각 추가·수정 `FormPanel`(닫으면 구역 상세로).
- 계측기 용도·센서 항목은 등록 뒤 바꾸지 않는다. 쓰인 행은 삭제 대신 사용 안 함(409 참조 건수).
- 공조기 폼의 "공조 전력 계측기"는 용도 = 공조 계측기만 고를 수 있다.
