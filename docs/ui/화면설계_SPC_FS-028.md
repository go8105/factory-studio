## 1. 메뉴 (7화면)

```
SPC 공정관리
├─ 공정 현황
│   ├─ S-01  대시보드
│   ├─ S-02  관리도
│   └─ S-03  공정능력
├─ 측정·이상
│   ├─ S-04  측정 입력
│   ├─ S-05  이상·조치
│   └─ S-06  부분군 기록
└─ 기준정보
    └─ S-07  관리 특성·한계
```

- 라우트 `/spc/*`, 레이아웃 `SpcLayout` = `SolutionLayout` + `spcScreens`. 메뉴 묶음 이름은 화면 제목과 겹치지 않게 한다.
- 다른 앱 링크: MES · ERP · FEMS · QMS · WMS · BEMS · 포털 홈(다른 솔루션 `*Layout`에도 SPC 1줄).
- 관리도·공정능력은 **특성 선택**(`select`, 품목 · 공정 · 특성명)과 **기간**을 공유한다. 선택은 URL 쿼리(`?c=CH-…&from=&to=`)로 남겨 화면 사이를 옮겨도 유지한다.

## 2. 화면별 설계

### S-01 대시보드 — 패턴 D (F-01)

```
SPC 대시보드 S-01                                            [? 도움말]
┌ 관리 특성 ┐┌ 미조치 이상 ──┐┌ 공정능력 ─────────────┐┌ 최근 7일 부분군 ┐
│ 6         ││ 2 · 1개 특성  ││ 충분 4 · 주의 1 · 부족 1 ││ 38              │   ← KPI 4개(좁으면 2×2)
└───────────┘└───────────────┘└───────────────────────┘└─────────────────┘
┌ 특성 카드(3열, 좁으면 1열) ─────────────────────────────────────────────┐
│ FG-C200 · 사출 · 하우징 높이      [미조치 2] [Cpk 1.12 주의]             │
│ ▁▂▂▃▃▄▅▆█  최근 20점 X̄ (UCL·CL·LCL 가는 선)          관리도 보기 →      │
└─────────────────────────────────────────────────────────────────────────┘
```

- 카드 순서: 미조치 이상 있는 것 → Cpk 낮은 순. 카드를 누르면 S-02(해당 특성).
- 한계가 없는 특성은 "한계 미게시" 배지 + S-07 링크. Cpk 표본 부족은 "표본 부족".

### S-02 관리도 — 패턴 D · **SPC 시연 화면**

```
관리도 S-02                                                  [? 도움말]
[특성: FG-C200 · 사출 · 하우징 높이 ▾] [기간 from] [to] [조회]   한계 v1 · 게시 09-02
┌ X̄ 관리도 ─────────────────────────────────────────────────────────────┐
│ UCL 12.046 ─────────────────────────────────────────────── ●(규칙 1)   │
│ CL  12.001 ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ↗↗↗↗↗(규칙 3) │
│ LCL 11.956 ─────────────────────────────────────────────────────────── │
│        LT-0002      LT-0005   …   LT-0014        LT-0017   LT-0023      │ ← LOT 경계 눈금
└────────────────────────────────────────────────────────────────────────┘
┌ R 관리도 (높이 절반) ─ UCL · CL (LCL 0) ────────────────────────────────┐
└────────────────────────────────────────────────────────────────────────┘
표 · 총 84건 · CSV
┌ 측정 시각 │ LOT │ 설비 │ X̄ │ R │ 판정 ┐
│ 09-11 15:00 │ LT-0017 │ INJ-02 │ 12.051 │ 0.031 │ 규칙 1 · 미조치 │
└──────────────────────────────────────┘
```

- 점: 정상 `●`, 이상 `◆`(`Badge tone="issue"` 색), 무효 `○`(흐림, 계산 제외). 점에 초점·호버 → 측정 시각·LOT·설비·X̄·R·규칙. 키보드로 점을 이동할 수 있고 값 표가 같은 정보를 준다(차트만으로 정보를 전하지 않는다).
- 한계 버전이 바뀌는 지점은 세로 점선 + "v2 게시". 한계선은 버전 구간마다 따로 그린다.
- 한계 미게시 구간은 점만 찍고 "한계 미게시" 안내 + S-07 "한계 게시" 링크.
- 이상 점을 누르면 S-05의 해당 이상 상세로 간다. 표의 판정 칸도 같은 링크.
- 규격선(LSL·USL)은 X̄ 관리도에 **그리지 않는다**(관리 한계와 혼동 — 규격은 S-03에서 본다). 도움말에 이유를 적는다.

### S-03 공정능력 — 패턴 D

```
공정능력 S-03                                               [? 도움말]
[특성 ▾] [기간 from] [to] [조회]
┌ Cp ──┐┌ Cpk ─────────┐┌ 평균 μ ┐┌ σ̂ (R̄/d2) ┐┌ 부분군 ┐
│ 1.48 ││ 1.12  주의    ││ 12.021 ││ 0.0225     ││ 84     │
└──────┘└──────────────┘└────────┘└────────────┘└────────┘
┌ 히스토그램(개별 측정값 10칸) + LSL·USL 세로선 + 목표값 점선 ┐   ┌ 값 표(구간·빈도) ┐
└────────────────────────────────────────────────────────┘   └──────────────────┘
(role=note) 이 기간에 미조치 이상이 2건 있습니다. 관리 상태가 아니면 공정능력 해석에 주의하세요. [이상·조치 →]
```

- 판정 배지: 충분(normal) · 주의(warning) · 부족(issue). 한쪽 규격이면 Cp 칸 "한쪽 규격 — 계산 안 함".
- 표본 부족(20 미만): `EmptyState` "유효 부분군이 20개 이상이어야 계산합니다(현재 N개)".
- 식은 화면 아래 접힌 안내(`details`)로 보인다: Cp = (USL−LSL)/6σ̂, Cpk = min(USL−μ, μ−LSL)/3σ̂.

### S-04 측정 입력 — 패턴 V (M-04) + FormPanel · **MES 교차 조회 시연 화면**

```
측정 입력 S-04                                              [? 도움말]
(role=note) 공정 실행 목록은 MES에서 읽어 옵니다. SPC는 MES 데이터를 바꾸지 않습니다.
[특성 ▾]
┌ LOT │ 설비 │ 시작 │ 종료 │ 기록된 부분군 │ 관리 ┐
│ LT-0023 │ ASM-03 │ 09-29 09:00 │ 진행 중 │ 4 │ 측정 입력 │
│ LT-0020 │ INJ-02 │ 09-27 09:00 │ 09-29 23:00 │ 10 │ 측정 입력 │
└──────────────────────────────────────────────┘
      ┌ 측정 입력 (FormPanel) ─────────────────────┐
      │ LOT LT-0023 · ASM-03 · 규격 2.49~2.59 mm     │
      │ 측정 시각 [2026-09-30 15:00]                 │
      │ 값 1 [2.541] 2 [2.538] 3 [2.544] 4 [ ] 5 [ ] │  ← 숫자 입력 5칸, 규격 밖이면 칸 옆 "규격 밖"(입력은 허용)
      │ X̄ 2.541 · R 0.006 (입력 중 계산)             │
      │ 메모 [          ]            [기록]          │
      └──────────────────────────────────────────────┘
```

- 기록 뒤 결과를 `role=status`로: "부분군을 기록했습니다. X̄ 2.541 — 이상 없음" 또는 "규칙 1 이상이 생겼습니다 [이상·조치 →]". 관리도 링크.
- 측정 시각 오류(400 `fields.measuredAt`)는 칸 아래에: "공정 실행 기간(시작~종료) 안이어야 합니다" / "이 특성의 마지막 부분군(09-30 09:00)보다 늦어야 합니다".
- MES 꺼짐(409): `EmptyState` "MES를 사용하지 않도록 설정했습니다. 관리도·공정능력·이상 조치는 그대로 쓸 수 있습니다".
- 미저장 보호(UI-04): 값이 하나라도 있으면 앱 안 링크 이동 전 확인.

### S-05 이상·조치 — 패턴 L + DetailPanel

```
이상·조치 S-05                                              [? 도움말]
[상태: 미조치 ▾] [특성 ▾]
┌ 발생 시각 │ 관리 │ 특성 │ LOT │ 설비 │ 관리도 │ 규칙 │ 값 │ 상태 ┐
│ 09-11 15:00 │ 상세 · 조치 │ FG-C200 사출 하우징 높이 │ LT-0017 │ INJ-02 │ X̄ │ 1 한계 밖 │ 12.051 │ 미조치 │
└────────────────────────────────────────────────────────┘
      ┌ 이상 상세 (DetailPanel wide) ─────────────────────────────┐
      │ 규칙 3 — X̄가 연속 6점 증가했습니다(09-10 03:00 ~ 09-11 09:00) │
      │ 주변 점 작은 관리도(앞뒤 10점)                                 │
      │ 원인 분류 [설비 ▾]  조치 내용 [금형 온도 조정 …]  [조치 완료]    │
      └────────────────────────────────────────────────────────────┘
```

- 상태 필터: 미조치(`open`) 기본 · 조치 완료 · 무효 · 전체. 상태 배지: 미조치 issue, 조치 완료 normal, 무효 흐림.
- 규칙 설명 문구는 규칙마다 고정(도움말과 같은 문장). 원인 분류 6개는 "설비 · 자재 · 작업자 · 방법 · 측정 · 환경".
- QMS 연결 안내(`role=note`): "미조치 이상이 있는 LOT는 QMS 검사 대기·검사 화면에 'SPC 이상' 배지로 보입니다. QMS 판정은 바꾸지 않습니다." QMS 화면 링크(경로만).

### S-06 부분군 기록 — 패턴 L

- 필터: 특성 · LOT · 상태(유효/무효). 열: 측정 시각 · LOT · 설비 · 값 5개 · X̄ · R · 출처(시드/입력) · 상태 · 관리("무효 처리").
- 무효 처리: 확인 대화 + 사유(필수). 안내 "무효로 하면 이 부분군에서 생긴 이상 기록도 무효가 됩니다. 뒤 부분군의 판정 결과는 그대로 남습니다."

### S-07 관리 특성·한계 — 패턴 P (F-12)

- 특성 목록(코드 · 품목 · 공정 · 특성명 · 규격 · 한계 버전 · 부분군 수) → 특성 상세(`DetailPanel wide`)에 한계 버전 표(버전 · 적용 시작 · 기준 구간 · 부분군 수 · X̄ CL/UCL/LCL · R CL/UCL · 사유) → **한계 게시** `FormPanel`.
- 한계 게시 폼: 기준 구간(시작·종료) → **미리 계산**(`GET …/limits/preview`) 결과 표 → 사유(필수) → [게시]. 20개 미만이면 게시 버튼 비활성 + "유효 부분군 N개 — 20개 이상 필요".
- 특성 등록·수정 `FormPanel`: 품목은 MES 완제품 목록에서 선택(MES 꺼짐이면 코드 직접 입력 불가 — 등록만 막고 안내), 공정 코드, 특성명, 단위, LSL·USL·목표값, 소수 자릿수. 부분군이 있으면 규격·품목·공정 칸 읽기 전용 + 안내(409 방지).

```

하나의 공간에서 만나는 일곱 가지 독립 솔루션                  [게스트 공간 ↗] [런처 도움말]

```

- 묶음 순서: 생산·품질 → 공급망·물류 → 에너지 → 영업·제품 → 경영·협업. **운영 중인 솔루션만 타일**, 비어 있는 묶음(지금은 영업·제품)은 제목도 숨긴다.
- 넓은 화면(≥ 960px) 묶음 2열, 좁으면 1열. 타일 크기·아이콘·호버/`i` 안내는 지금 것을 그대로 쓴다. 묶음 제목은 `h2`, 타일 제목은 `h3`로 내린다(제목 순서 유지).
- 묶음 정의는 `content/systems.json`의 `layer`에서 가져온다(분야 5개 ↔ 계층 6개 대응표를 한 곳에 둔다: 경영/전략·현장단말은 각각 경영·협업·생산·품질로).
- 문구 "여섯" → "일곱"은 **솔루션 수를 목록 길이에서 만든다**(다음 솔루션 때 문구를 또 고치지 않게).
- 하단 "아직 만들지 않은 것 — 의도적으로 제외"는 사실과 달라졌으므로 **"앞으로 만들 것 — 로드맵"** 한 줄 링크(P-03 `?view=arch`)로 바꾼다. SCM 설명 카드 링크는 P-03 카탈로그 안에서 그대로 연결된다.
