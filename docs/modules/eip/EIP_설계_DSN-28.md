# DSN-28 EIP 통합 정보 포털 설계 (신규)

작성: 2026-10-05 (Claude Code) · 상태: **설계 완료(2026-10-05) — 사용자 확인 대기.** 1단계(기준표·Q1~Q7 확정) + 2단계(3장 기능 규칙 · 4장 DB eip 8 + 사람 연결 · 5장 화면 8 · 6장 교차 조회).
양식: [DSN-00](../../plan/기능기준표_DSN-00.md) · 방침: [ROADMAP-02](../../plan/전체설계우선_전환_ROADMAP-02.md) · 로드맵: [ROADMAP-01 §6-3](../../plan/로드맵_17개시스템_ROADMAP-01.md)(EIP = 전사 요약 대시보드·공지, GW = 전자결재·게시판, 포털 = 인증·앱 런처)
입력: 각 솔루션 설계 6장의 **`monthly_summary(month)`**(ERP·FEMS·BEMS·SPC·CMMS·POP·TMS·PLM·CRM·SCM·ELB 등).

## 0. EIP의 자리 — 포털·GW와 무엇이 다른가

| 영역 | 소유 | EIP와의 관계 |
|---|---|---|
| 로그인·앱 런처·흐름 맵·휴일 달력 | **포털(core)** | **Q8: 포털 첫 화면 = EIP.** 로그인하면 EIP 대시보드(EI-01)가 바로 보이고 런처는 그 안에 있다. EIP 타일·모듈 키는 없다(끌 수 없음). 데이터는 core가 아니라 `eip` 스키마(FS-013) |
| 전자결재·게시판(**공지 포함**, 운영 중) | **GW** | 공지를 EIP가 다시 만들면 두 벌 → **GW 공지를 읽어 표시**(Q1) |
| 전사 요약·KPI·목표 대비·할 일 모음·경영 보고 | **EIP** | 이 문서 |
| 각 지표의 원천 값 | 각 솔루션 | EIP는 `monthly_summary` 등 조회로만 읽는다(저장은 확정 보고서 스냅샷만) |

로드맵 §6-3의 "EIP 공지"는 GW 공지 게시판이 이미 운영 중이라 **표시로 바꾸는 것**을 Q1에서 묻는다.

## 3. 기능 규칙 (범위 13)

공통: **EIP는 다른 솔루션 값을 저장하지 않는다** — 요약·KPI 실적·할 일·검색은 조회, 확정 경영 보고서만 스냅샷. 공지는 GW(Q1), 로그인·런처는 포털(core).

| 묶음 | 기능 ID | 규칙 |
|---|---|---|
| 대시보드 (Q5) | F01~F04 | 요약 카드(각 솔루션 `monthly_summary`), 솔루션 상태(꺼짐·조회 실패), 12개월 추이. 위젯(요약 카드·KPI·할 일·공지·추이)은 사용자별 선택·순서, 없으면 기본 배치 — 배치는 eip에 저장(core에는 두지 않음, FS-008b) |
| KPI (Q2) | F11~F13 | KPI 정의(출처 솔루션·요약 지표 키·단위·좋은 방향, 시드 16개)·월 목표. 실적은 조회, 달성률 = 실적 ÷ 목표(낮을수록 좋음이면 목표 ÷ 실적), 미달 경고 |
| 할 일 (Q3·Q3-1) | F21 | **사람별** — 로그인 회원(관리자가 연결) 또는 게스트가 고른 체험 사람 ↔ HR 사원 코드. 각 솔루션 `pending_tasks(hr_employee_code)`가 건수·바로가기를 돌려준다(GW 결재 대기, ELB 승인 대기, CMMS 작업지시, QMS CAPA 기한, CRM 할 일, POP 호출 등). HR이 사람의 원천, 각 솔루션 사람 마스터는 HR 사원 코드 스냅샷 |
| 공지 (Q1) | F22 | GW 게시 공지 최근 N건 표시(읽기 전용, 클릭 시 GW 화면) |
| 경영 보고 (Q4) | F31·F32 | 월간 보고서 = 켜진 솔루션 요약 + KPI 실적·목표 스냅샷, 총평, 지표별 의견·조치·기한. 확정 후 불변, 재작성은 새 버전, 인쇄 |
| 검색·바로가기 (Q6) | F41·F42 | 번호 하나를 모든 켜진 솔루션 `lookup(code)`에 물어 대상 종류·화면 경로 목록. 즐겨찾는 화면(사용자별) |

## 6. 교차 조회

**EIP가 읽는 것** — 모든 솔루션 공통 3종(각 솔루션에 추가, 개발 때 함께)

| 함수 | 돌려주는 것 | 비고 |
|---|---|---|

| `pending_tasks(hr_employee_code)` | 종류별 대기 건수·화면 경로 | Q3 — 사람 마스터의 HR 사원 코드로 찾음 |

| HR `employees()` | 사원 코드·이름 | 사람 연결(HR 신규 설계에서 확정) |

**EIP가 제공하는 것**: 없음(최종 소비자).
