# DSN-21 CMMS 재점검·보강 설계

작성: 2026-10-05 (Claude Code) · 상태: **1단계 — 기준표·갭 요약·결정 질문(범위 확인 대기)**. 3~6장은 범위 확정 뒤.
양식: [DSN-00](../../plan/기능기준표_DSN-00.md) · 방침: [ROADMAP-02](../../plan/전체설계우선_전환_ROADMAP-02.md) · 기존 설계: [결정서 FS-029](../../plan/CMMS도입_설비보전_결정_FS-029.md)(D45~D52) · [모듈 설계 FS-029](CMMS_모듈설계_FS-029.md)
상태 배경: FS-029a로 **DB 6테이블만 실제 DB에 있고 API·화면은 없다**(D76 — 일괄 개발 때). 그래서 이 재점검은 "설계 → 목표 DB" 보강이다.
넘겨받은 것: MES(DSN-12 Q6) 금형 보전 · FEMS(DSN-15 F34) 에너지 경보 신호 · BEMS(DSN-16) 설비 경보 신호·시설 일상 점검표 · ERP(DSN-11 F21) 구매 요청 출처 CMMS.

## 0. 지금 CMMS와 경계

**지금(설계 6테이블·화면 7 설계, 미구현)**: 설비 대장(MES 설비·BEMS 공조기 가져오기 + 직접) · 예방보전 계획(일 주기, 점검 항목은 글 한 칸) · 작업지시(고장 BM·예방 PM, 접수 → 진행 → 완료/취소, 신호 전환: BEMS 경보·SPC 이상) · 작업 기록(분) · 예비품 목록·사용 기록(재고 없음) · MTBF·MTTR·PM 준수율 · MES "보전 중" 배지.

FS-029 "하지 않는 것"(D45 보충): 작업자 배정·외주 보전 비용·예비품 재고·WMS 조회. 이번 재점검에서 **Q5·Q6으로 다시 묻는다**(전체 구성 방침, D75).

| 영역 | 소유 | CMMS와의 관계 |
|---|---|---|
| 설비 대장·보전 계획·작업지시·예비품 사용 | **CMMS** | 이 문서 |
| 금형 마스터·타수 | **MES**(DSN-12 Q6) | CMMS가 가져와 보전 |
| 예비품 재고 수량 | **WMS**(SUPPLY 품목) | CMMS는 조회만(Q6) |
| 예비품 구매 | **ERP**(구매 요청 출처 CMMS) | CMMS가 부족분 제공 |
| 정비 작업자 인사 정보 | **HR** | CMMS 정비원 코드는 자체, 사원 코드 스냅샷 |

| 영역 | 기능 | ✓ | △ | ✗ | 범위 ○ | Q | ✕ |

**요지**: FS-029는 "고장 → 수리"의 한 줄을 잘 정했다. 다른 솔루션 설계에서 넘어온 **금형·에너지/설비 경보·시설 점검**을 받고, FS-029에서 뺐던 **정비원·외주·비용·예비품 재고**를 이번에 넣을지가 핵심이다. 테이블은 6 → 대략 **12~16** 추정.

## 7. 결정 질문 (하나씩)

| # | 질문 | 제안 |
|---|---|---|
| Q1 | **금형 보전** — MES `molds()`로 금형을 대장에 가져온다(출처 MES_MOLD, 종류 MOLD). 금형 작업지시가 진행 중이면 CMMS `equipment_in_maintenance`에 금형 코드도 포함, MES가 읽어 금형 상태·배지에 반영(CMMS가 MES를 바꾸지 않음) | 그대로 |
| Q2 | **사용량 기준 PM** — 운전 시간(MES 공정 실행 시간 합)·금형 타수(MES) 기준 PM 계획. 기준 도래 시 사람이 작업지시 생성(D49와 같은 방식) | 포함 |
| Q3 | **점검표 구조화** — PM 계획의 점검 항목을 표(항목·기준·측정 단위)로, 작업지시 완료 때 항목별 결과(OK/NG·값). 시설 일상 점검(BEMS에서 넘어옴)은 일 주기 점검표로 | 포함 |
| Q4 | **신호 전환 확장** — FEMS 에너지 경보·BEMS 설비 경보를 전환 대기 신호에 추가(출처 2종 추가, 신호 1건당 작업지시 1건 규칙 그대로) | 포함 |
| Q5 | **FS-029에서 뺀 것 다시** — 정비원 배정·작업자별 시간, 외주 수리(업체·비용), 보전 비용 집계·분석 | 포함(전체 구성 방침). 비용 회계 처리는 ERP(외주 수리는 ERP 직접 매입) |
| Q6 | **예비품 재고·구매** — WMS SUPPLY 품목 재고를 조회해 안전 재고 미만이면 부족 표시, 부족분을 ERP 구매 요청 원천으로 제공. CMMS 사용 기록은 WMS 출고로 반영(WMS가 읽음) | 포함 |
| Q7 | **설비 상세·계층**(제조사·모델·설치일·중요도, 라인 > 설비 > 구성품) 포함, 범위 확정(제외 3: 문서 첨부·예지보전·LOTO) | 제안대로 |
