# DSN-21 CMMS 재점검·보강 설계

작성: 2026-10-05 (Claude Code) · 상태: **설계 완료(2026-10-05) — 사용자 확인 대기.** 1단계(기준표·Q1~Q7 확정) + 2단계(3장 기능 규칙 · 4장 DB 12테이블 · 5장 화면 10 · 6장 교차 조회).
양식: [DSN-00](../../plan/기능기준표_DSN-00.md) · 방침: [ROADMAP-02](../../plan/전체설계우선_전환_ROADMAP-02.md) · 기존 설계: [결정서 FS-029](../../plan/CMMS도입_설비보전_결정_FS-029.md)(D45~D52) · [모듈 설계 FS-029](CMMS_모듈설계_FS-029.md)
상태 배경: FS-029a로 **DB 6테이블만 실제 DB에 있고 API·화면은 없다**(D76 — 일괄 개발 때). 그래서 이 재점검은 "설계 → 목표 DB" 보강이다.
넘겨받은 것: MES(DSN-12 Q6) 금형 보전 · FEMS(DSN-15 F34) 에너지 경보 신호 · BEMS(DSN-16) 설비 경보 신호·시설 일상 점검표 · ERP(DSN-11 F21) 구매 요청 출처 CMMS.

## 0. 지금 CMMS와 경계

**지금(설계 6테이블·화면 7 설계, 미구현)**: 설비 대장(MES 설비·BEMS 공조기 가져오기 + 직접) · 예방보전 계획(일 주기, 점검 항목은 글 한 칸) · 작업지시(고장 BM·예방 PM, 접수 → 진행 → 완료/취소, 신호 전환: BEMS 경보·SPC 이상) · 작업 기록(분) · 예비품 목록·사용 기록(재고 없음) · MTBF·MTTR·PM 준수율 · MES "보전 중" 배지.

FS-029 "하지 않는 것"(D45 보충): 작업자 배정·외주 보전 비용·예비품 재고·WMS 조회. 이번 재점검에서 **Q5·Q6으로 다시 묻는다**(전체 구성 방침, D75).

| 영역 | 소유 | CMMS와의 관계 |
|---|---|---|
| 설비 대장·보전 계획·작업지시·예비품 사용 | **CMMS** | 이 문서 |
| 금형 마스터·타수 | **MES**(DSN-12 Q6) | CMMS가 가져와 보전 |
| 예비품 재고 수량 | **WMS**(SUPPLY 품목) | CMMS는 조회만(Q6) |
| 예비품 구매 | **ERP**(구매 요청 출처 CMMS) | CMMS가 부족분 제공 |
| 정비 작업자 인사 정보 | **HR** | CMMS 정비원 코드는 자체, 사원 코드 스냅샷 |

## 6. 교차 조회

**CMMS가 읽는 것**

| 제공 | 함수 | CMMS 용도 |
|---|---|---|
| MES | `equipment()`(FS-029) · `molds()`(DSN-12) · `operation_runs`(있음, 운전 시간) | 대장 가져오기, Q2 사용량 |
| BEMS | `hvac_units()`·`active_alarms()`(**환경 경보만**, Q4) | 대장, 전환 대기 |
| SPC | `equipment_signals()` | 전환 대기 |
| WMS | `stock_on_hand(item_codes)` | Q6 예비품 재고 |
| ERP | `partners()` | 외주 업체 거래처 코드 |
| HR | `employees()` | 정비원 사원 코드(선택) |

**CMMS가 제공하는 것**

| 함수 | 돌려주는 것 | 쓰는 곳 |
|---|---|---|
| `enabled()` · `equipment_in_maintenance(codes)` | 진행 고장 작업지시 설비·**금형** 코드 | MES 배지·금형 상태(Q1) |
| `part_requests()` | 안전 재고 미만 예비품 부족분 | ERP 구매 요청(출처 CMMS) |
| `part_usages(since)` | 완료 작업지시의 부품 사용 | WMS 출고 반영 |
| `monthly_summary(month)` | MTBF·MTTR·PM 준수율·비용 | EIP 경영 요약 |

> Q4 결과: FEMS `open_alarms`(DSN-15 F34)와 BEMS 설비 경보(DSN-16 F33)는 CMMS 신호로 쓰지 않는다 — 두 문서에 반영함. FEMS `open_alarms`는 BEMS 피크 감축에는 그대로 쓴다.

> RWS DSN-29 반영(2026-10-05): 작업지시 출처에 `RWS_REQUEST` 추가(목표 DB 반영) — RWS "현장 출동 필요" 완료 요청을 `fs.rws.interface.field_visit_requests()`로 읽어 "RWS에서 가져오기"로 작업지시를 만든다(요청당 진행 1건). CMMS는 `work_order(no)`·`failure_codes()`를 제공한다.
