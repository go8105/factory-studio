# WMS — 창고 관리

- 상태: **구현 완료(FS-024a~c, 로컬) — DB·API·W-01~07·시드 107행·도움말·흐름 맵. 운영 배포 전**
- 업무 범위: 창고 위치, 재고 이동 원장, 예약, 비계획 입출고
- 이 폴더의 문서: [WMS 모듈 설계서 FS-024](WMS_모듈설계_FS-024.md) · 결정서 [FS-024](../../plan/WMS도입_재고원장_결정_FS-024.md)

## 메모

- **구현 완료. `wms` 6테이블(schema.json v0.11.0, 마이그레이션 `fs024a_wms`·`fs024b_wms_module`), `/api/v1/wms`, `frontend/src/wms/`.**
- 현재 재고 근거는 완제품 입고 이력과 출하 이력의 대사다.
- QMS(FS-023) 다음 후보. MES 자재 투입(차감 없음)·ERP 출하·매입과 재고 경계를 함께 다시 정해야 한다.
- 도입 시 재고 원장 소유가 MES에서 WMS로 이관된다.

## 규칙

이 폴더에 모듈 공통 설계서가 없으면 해당 모듈은 개발 착수 대상이 아니다.
설계를 먼저 확정하고 사용자 확인을 받은 뒤 구현에 들어간다.

기준정보(품목·창고 위치 등)는 각 솔루션이 독립 소유한다(FS-013 D1). 다른 솔루션 데이터는 FS-023 D9의 읽기 전용 조회 인터페이스로만 읽는다.

전체 현황은 [현재 기획과 진행 현황](../../plan/현재기획_진행현황.md)을 본다.
