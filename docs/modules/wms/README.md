- **FS-024 운영 구현:** 기존 6테이블, W-01~07, 원천 반영·재고 원장·조정/이동·시드·도움말.

현재고는 WMS 확정 stock_move 합계이며 MES에서 원장을 이관하는 작업이 아니다. 업무 마스터는 WMS 자체 소유, 교차 조회는 해당 솔루션 interface.py만, 업무 스키마 간 FK는 금지한다. 공유 개발/운영 DB는 미적용이며 상세 검증은 FS-026a 인계를 참조한다.

전체 현황은 [현재 기획과 진행 현황](../../plan/현재기획_진행현황.md)을 따른다.
