# DSN-29 RWS 원격 작업 지원 설계 (신규)

작성: 2026-10-05 (Claude Code) · 상태: **1단계 — 기준표·결정 질문(범위 확인 대기)**. 3~6장은 범위 확정 뒤.
양식: [DSN-00](../../plan/기능기준표_DSN-00.md) · 방침: [ROADMAP-02](../../plan/전체설계우선_전환_ROADMAP-02.md) · 로드맵: [ROADMAP-01 §6-5](../../plan/로드맵_17개시스템_ROADMAP-01.md)(확정: 원격 지원 요청 → 전문가 배정 → 단계별 작업 안내(텍스트·체크리스트) → 완료 기록, 영상·AR 없음)

## 0. RWS의 자리 — CMMS·POP 호출과 무엇이 다른가

| 상황 | 소유 | RWS와의 관계 |
|---|---|---|
| 라인에서 지금 사람을 부른다(자재·품질·보전·관리자) | **POP 호출**(DSN-22 Q4, POP 안에서만) | 겹치지 않게 둔다 — Q2 |
| 설비를 고친다·예방보전한다(작업지시·부품·비용) | **CMMS** | 원격으로 못 고치면 "현장 출동 필요" → CMMS가 가져가 작업지시 — Q3 |
| 현장 사람이 **혼자 해결할 수 없어 원격 전문가의 안내를 받는다** | **RWS** | 이 문서. 전문가가 텍스트·단계 체크리스트로 안내하고, 현장이 결과·측정값을 입력 |
| 사람(사원) 원천 | **HR**(D79) | 전문가·요청자는 HR 사원 코드 스냅샷(EIP Q3-1과 같은 방식) |

## 7. 결정 질문 (하나씩)

| # | 질문 | 제안 |
|---|---|---|
| Q1 | **RWS의 정의** — "현장이 혼자 해결 못할 때 원격 전문가가 텍스트·단계 체크리스트로 안내하고 결과를 기록"으로 한정한다. 영상·AR·사진 첨부는 없다(ROADMAP-01 §6-5 재확인) | 그대로 |
| Q2 | **요청 출처** — 직접 등록 + CMMS 작업지시·QMS 부적합에서 "원격 지원 요청"(RWS가 출처 솔루션 조회로 채우고 코드 스냅샷, 교차 쓰기 없음). **POP 호출은 가져오지 않는다**(POP Q4 "호출은 POP 안에서만"을 유지) | 그대로 |
| Q3 | **원격 해결 실패** — RWS는 "현장 출동 필요"로 닫고, CMMS가 `field_visit_requests()`를 읽어 "RWS에서 가져오기"로 작업지시를 만든다(RWS가 CMMS에 직접 쓰지 않음) | 그대로 |
| Q4 | **고객 현장 원격 A/S** — CRM 고객사·출하 LOT 대상 요청 포함(요청은 사내 담당자가 대신 등록, 고객사 코드 스냅샷). CRM 고객 문의와는 별개 | 포함 |
| Q5 | **작업 가이드 소유** — RWS가 가이드(단계·주의·확인 항목, 게시 후 불변·새 버전)를 소유한다. CMMS 점검표(PM 정기 점검)·PLM 문서(도면 메타데이터)와는 별개 | 그대로 |
| Q6 | **지식화** — 완료한 요청을 지식 문서로 남기고, 새 요청 때 같은 설비·증상의 해결 사례를 추천 | 포함 |
| Q7 | **운영 관리** — 응답·해결 목표 시간(긴급도별)·단계 상향·만족도 | 모두 포함 |
| Q8 | 범위 확정 — 포함 8 + Q 결과, 제외: 사진·영상 첨부, 실시간 영상·AR | 제안대로 |
