## 0. 먼저 정할 것 — 이카운트와 우리 구조의 차이

이카운트 ERP는 **한 제품 안에** 재고·생산·품질·WMS·그룹웨어·인사까지 담는다. 우리는 **독립 솔루션**(FS-013 D1)이라 같은 메뉴가 다른 솔루션에 있다. 그래서 이카운트 메뉴를 ERP 하나에 다 넣지 않고 **소유 솔루션**을 먼저 나눈다.

| 이카운트 메뉴 | 우리 소유 | ERP가 하는 일 |
|---|---|---|
| 재고 I — 영업관리·구매관리, 회계 I·II, 세무(부가세) | **ERP** | 이 문서의 대상 |
| 재고 I — 기타이동(창고이동·재고조정·불량·자가사용), 재고II — WMS | **WMS** (FS-024 D13 재고 소유) | 재고 조회·재고자산 평가에 **읽기만** |
| 재고 I — 생산/외주(BOM·공정·작업지시·불출·생산입고) | **MES** | 원가 계산에 생산·투입 실적 **읽기만**. 외주 가공은 DSN-12(MES)에서 |
| 재고 II — 품질관리 | **QMS** | — |
| 재고 II — 계획관리(MRP) | **MES**·**SCM** | — |
| 재고 II — A/S관리 | **CRM**(신규 설계 때) | — |
| 그룹웨어 — 전자결재·게시판 | **GW** | 지출결의·전표 결재 상태 **읽기만**(이미 매입 배지가 있다) |
| 관리 — 인사·근태·급여 | **HR(18번째 솔루션, Q2 확정)** | 급여 결과를 **읽어** 급여 전표만 만든다 |
| Self-Customizing — 사용자·권한그룹·보안이력·메뉴 | **core**(모든 솔루션 공통) | DSN-90 통합 설계에서 따로 다룬다(부록 A) |
| 재고 I — 쇼핑몰관리, 회계 II — 전자계약, 데이터센터 | 제외 제안 | 외부 연동 전용 |

**요지**: 지금 ERP는 "영업 → 출하 → 매출 → 채권·수금"까지만 깊다. **구매(발주)·회계(전표·장부·결산)·자금이 비어 있다.** 이카운트 기준 ERP라고 부르려면 회계 41·51 영역(전표 → 장부 → 시산표 → 재무제표)이 핵심이다. 확정 범위는 기능 58개(급여 전표 F94 포함)이고 그중 신규·보강이 47개다. 테이블은 지금 27개에서 대략 **55~65개**로 늘 것으로 추정한다(3·4장 작성 때 확정).

## 6. 교차 조회

**ERP가 읽는 것** (모두 읽기 전용, 제공 솔루션이 꺼져 있으면 해당 기능만 "조회 불가")

| 제공 | 함수(신규는 해당 DSN에서 계약) | ERP 용도 |
|---|---|---|
| WMS | `receipts(period)` 입고 확정 명세 · `stock_moves(month)` 수불 · `stock_on_hand()` 재고 | F23 발주 입고 매입, F35 재고자산 평가, F31 재고 현황 |
| MES | `production_results(month)` 제품별 생산 수량 · `subcontract_results()` 외주 실적 | F36 배부, F34 외주비 |
| HR | `payroll_runs(month)` 확정 급여 결과(부서·항목별 합계) | F94 급여 전표 |
| GW | `approvals(doc_ref)` (있음) | E-11·E-29 결재 배지 |
| CMMS·ELB | `part_requests()` | F21 구매 요청 원천 |

**ERP가 제공하는 것** (지금 6개 + 추가)

| 함수 | 돌려주는 것 | 쓰는 곳 |
|---|---|---|
| `purchase_orders(open=True)` | 확정 발주 명세(입고 예정) | WMS 입고 예정 |
| `journal_summary(month)` | 확정 전표 계정별 합계 | EIP 경영 요약 |
| `sales_summary(period)` | 기간 매출·채권 요약 | EIP·CRM |
| 기존 `confirmed_shipments`·`purchase_receipts`·`open_shipment_qty`·`approval_*` | 그대로 | WMS·GW |

> 이 표의 신규 함수 이름은 설계 초안이다. 제공 솔루션의 DSN(WMS 13·MES 12·HR)에서 계약을 확정한다.

> TMS DSN-23 반영(2026-10-05): ERP는 TMS `loaded_shipments`(출하 확정 대기)·`deliveries`(납품 확인·반품 후보)·`carrier_settlements`(운송비 직접 매입)를 읽는다.

> PLM DSN-24 반영(2026-10-05): ERP 품목은 "PLM에서 가져오기" 가능(자동 동기화 없음). `standard_costs(item_codes)`·`plm_imports`를 제공한다.

> CRM DSN-25 반영(2026-10-05): ERP는 "CRM에서 가져오기"로 거래처(CRM 고객사)와 견적 초안(CRM 견적 요청)을 만든다. `crm_imports`·`sales_orders_for_crm`·`partner_summary`를 제공한다.
