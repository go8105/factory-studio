# CORE — 공통 기반

## 현재 기준 (2026-10-05)

- 소유: 인증·계정·세션·플랫폼 권한·공간/세대·모듈 사용 설정·운영 감사/요청 영수증. 품목·설비·직원 조직 등의 업무 마스터는 소유하지 않는다([FS-013](../../plan/독립솔루션_전환결정_FS-013.md)).
- 구현은 기존 개인 MEMBER/게스트 공간 기준이다. [공유 공간 상세 설계 GW-EXT-A](CORE_공유공간_상세설계_GW-EXT-A.md)는 전체 확인 대상이며 미구현이다.
- 기존 [FS-005f](CORE_모듈설계_FS-005f.md)는 역사적 설계이며 FS-013과 현재 코드/현황을 함께 확인한다. 예전 공통 마스터 독점 설명은 현재 기준이 아니다.
- 공유 확장: 멤버십/초대·세션 공간전환·권한 재검사. GW와 교차 업무쓰기/FK를 추가하지 않는다. 공급할 core.interface 조회 계약도 아직 설계 단계다.
- [P0 실운영 요건](../../operations/GW_실운영준비_상세설계_GW-EXT-P0.md)·[인수 계획](../../plan/GW확장_상세설계검증_GW-EXT-A.md). 전체 설계 확인 후에만 제품/DB 구현.

최신 수치는 [현재 기획과 진행 현황](../../plan/현재기획_진행현황.md)을 따른다.
