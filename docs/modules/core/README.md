# CORE — 공통 기반

- 상태: **구현 대상**
- 업무 범위: 계정·권한, 체험 공간과 세대, 사업장·작업장·설비, 품목·단위환산, 계측기·계측 채널, 감사·요청 결과
- 이 폴더의 문서: 없음

## 메모

- 공통 기준정보를 소유한다. MES·ERP·FEMS가 이 테이블을 참조하며 모듈마다 복제하지 않는다.
- 모듈 설계서 없음. 공통 ERD(`../../architecture/공통ERD_데이터관계_FS-005.md`)가 그 역할을 한다.

## 규칙

이 폴더에 모듈 공통 설계서가 없으면 해당 모듈은 개발 착수 대상이 아니다.
설계를 먼저 확정하고 사용자 확인을 받은 뒤 구현에 들어간다.

공통 기준정보(품목·설비·작업장 등)는 core가 소유한다. 모듈별로 복제하지 않는다.

전체 현황은 [현재 기획과 진행 현황](../../plan/현재기획_진행현황.md)을 본다.
