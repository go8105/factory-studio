## 0. ELB/MRO의 자리 — 사내 간접자재 "쇼핑"과 승인

**ELB/MRO = 사무용품·소모품·공구·안전용품 같은 간접자재를 직원이 카탈로그에서 골라 신청하고, 승인받아 구매로 넘기고, 받았는지 확인하는 솔루션.** 발주·매입·회계는 ERP, 재고로 두는 품목의 입고는 WMS가 한다(Q1).

| 영역 | 소유 | ELB와의 관계 |
|---|---|---|
| 간접자재 카탈로그·계약 단가·사내 신청·승인·수령 확인 | **ELB** | 이 문서 |
| 구매 요청 → 발주 → 매입 → 전표 | **ERP** | 승인된 신청을 ERP가 구매 요청(출처 ELB)으로 가져감 |
| 재고 품목(SUPPLY) 입고·재고 | **WMS** | 재고 품목은 WMS 입고, ELB는 상태만 조회 |
| 부서 예산 | **ERP**(DSN-11 F84) | ELB가 조회해 초과 경고(Q3) |
| 설비 예비품 구매 | **CMMS → ERP**(DSN-21) | ELB를 거치지 않는다 |

## 7. 결정 질문 (하나씩)

| # | 질문 | 제안 |
|---|---|---|
| Q1 | **ELB 경계** — ELB는 카탈로그·신청·승인·수령 확인까지. 발주·매입·전표는 ERP(승인 신청 → ERP 구매 요청 출처 ELB), 재고 품목 입고는 WMS. ELB 자체 발주 없음 | 그대로 |
| Q2 | **승인 방식** — ELB 안에서 금액 기준 단계(기본: 부서장 1단계, 50만 원 초과 시 관리부서 2단계 — 금액·단계는 설정). GW 결재와 따로(GW는 문서 결재, ELB는 신청 승인) | 그대로 |
| Q3 | **부서 예산 확인** — ERP 부서·계정 월 예산 대비 실적 + 이번 신청 금액을 신청·승인 화면에 표시, 초과 시 경고(차단 아님) | 포함 |
| Q4 | **비재고 품목 수령 확인** — 신청 부서가 ELB에서 수령(수량·이상)·부분 수령 확인 → ERP가 읽어 매입 근거로(재고 품목은 WMS 입고 그대로). 반품은 요청만, 처리는 ERP | 포함 |
| Q5 | **공급처 계약 단가·표준 세트·단가 비교** 포함 | 포함 |
| Q6 | **긴급 구매(법인카드 사후 등록)** — 카드로 먼저 산 간접자재를 신청서로 사후 등록, ERP 카드 사용 내역과 연결 | 포함 |
| Q7 | 범위 확정 — 포함 11 + Q 7, 제외 1(이미지·외부 B2B 몰) | 제안대로 |
