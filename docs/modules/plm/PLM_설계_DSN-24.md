작성: 2026-10-05 (Claude Code) · 상태: **설계 완료(2026-10-05) — 사용자 확인 대기.** 1단계(기준표·Q1~Q7 확정) + 2단계(3장 기능 규칙 · 4장 DB 16테이블 · 5장 화면 11 · 6장 교차 조회).
양식: [DSN-00](../../plan/기능기준표_DSN-00.md) · 방침: [ROADMAP-02](../../plan/전체설계우선_전환_ROADMAP-02.md) · 로드맵: [ROADMAP-01](../../plan/로드맵_17개시스템_ROADMAP-01.md) 5번(PLM은 원천 — `released_boms()`·`item_revisions()`를 MES가 가져오기)

## 0. PLM의 자리

**PLM = 설계 단계의 품목·도면·BOM과 그 변경을 관리하는 원천 솔루션.** 설계가 승인(배포)한 리비전을 MES·ERP·WMS·QMS가 **가져가 자기 마스터에 반영**한다(독립 솔루션 — 각자 마스터, 스냅샷 가져오기, FS-013 D1).

| 영역 | 소유 | PLM과의 관계 |
|---|---|---|
| 설계 품목·리비전·도면·E-BOM·설계 변경 | **PLM** | 이 문서 |
| 제조 BOM·공정 경로 | **MES** | PLM 배포 E-BOM을 가져와 제조 BOM으로(Q4) |
| 판매·구매·재고 품목 | **ERP·WMS** | PLM 배포 품목을 가져오기(Q1) |
| 4M 변경 신고·초품 검사 | **QMS** | 설계 변경(ECO) 적용 → QMS 4M 신고 후보(Q3) |
| 결재 | **GW** | ECO 결재 상태 배지(선택, Q3) |
| 품목 단가 | **ERP** | 설계 원가 롤업(Q6) |

## 3. 기능 규칙 (범위 20)

공통: **배포(RELEASED)는 ECO로만**, 배포 리비전·그 E-BOM·문서 연결은 불변, 변경은 새 리비전. 품목당 현재 배포 리비전 1개. 다른 솔루션은 배포 리비전을 **가져오기**로 받는다(Q1) — PLM은 다른 스키마에 쓰지 않는다.

| 묶음 | 기능 ID | 규칙 |
|---|---|---|
| 품목 | F01~F03·F05 | 부품 번호(다른 솔루션 품목 코드의 원천)·분류(대·중·소). 리비전 A→B→…, 작업 중 → 검토 → 배포 → 폐기. 사양 속성(재질·단위 중량·치수·색상·표면 처리)은 리비전에 |
| 문서 (Q2) | F04 | 도면·사양서·표준 문서 대장과 문서 리비전(메타데이터만, 파일 없음). 품목 리비전 ↔ 문서 리비전 연결 |
| E-BOM | F11~F14 | 상위 품목 리비전의 하위 품목·수량(하위는 품목 — 전개 시 현재 배포 리비전). 순환 금지. 다단계 전개·역전개(어디에 쓰이는가)·리비전 비교(추가·삭제·수량 변경)는 조회 계산. 대체 부품(우선순위) |
| 설계 변경 (Q3) | F21~F26 | ECR(요청) → 수락 → ECO(대상 리비전 묶음·적용일) → 검토 → 승인(검토자) → 배포(대상 일괄 RELEASED, 이전 OBSOLETE). 리비전은 ECO 1건에만. 영향 분석 = 역전개 상위 품목 + MES 진행 작업지시 수(조회 스냅샷). 배포를 QMS가 읽어 4M 변경 신고 후보. GW 결재 상태는 배지만 |
| 개발 (Q5) | F31·F32 | 개발 프로젝트(대상 품목·담당·일정) → 게이트 4단계(기획·설계·시작·양산 승인). 통과 = 필수 산출물 완료 + 앞 게이트 통과, 불합격 게이트는 재판정 |
| 원가 (Q6) | F43 | 리비전 E-BOM을 말단까지 전개 × ERP 표준 단가(조회 스냅샷). 단가 없는 부품은 개수만 표시. 확정 1건 + 새 버전, 리비전 간 비교 |
| 연계 (Q1) | F41·F42 | 배포 리비전 제공(품목 속성·E-BOM·대체 부품). 각 솔루션의 "PLM에서 가져오기"(리비전 1건 1회, 멱등). 가져가기 현황 = 각 솔루션이 반영한 리비전 조회 |

## 6. 교차 조회

**PLM이 읽는 것**

| 제공 | 함수 | PLM 용도 |
|---|---|---|
| ERP | `standard_costs(item_codes)`(신규) | F43 원가 |
| MES | `open_work_orders_by_item(item_codes)`(신규) · `plm_imports()`(신규) | F24 영향 분석, F42 |
| ERP·WMS·QMS | `plm_imports()`(신규) | F42 가져가기 현황 |
| GW | `approvals(doc_ref)` | ECO 결재 배지 |

**PLM이 제공하는 것**

| 함수 | 돌려주는 것 | 쓰는 곳 |
|---|---|---|
| `released_parts(since)` | 배포 품목 리비전(부품 번호·리비전·사양 속성) | MES·ERP·WMS·QMS 품목 가져오기(Q1) |
| `released_bom(part_no, rev)` | 배포 E-BOM(하위·수량·대체 부품) | MES BOM 가져오기 → 제조 BOM(Q4) |
| `eco_releases(since)` | 배포 ECO(대상 품목·변경 내용·적용일) | QMS 4M 변경 신고 후보(Q3) |
| `monthly_summary(month)` | 배포·ECO·프로젝트 진행 | EIP |

> 넘길 것: **MES** PLM 품목·BOM 가져오기(품목 상세 칸·BOM 버전·대체 자재), `open_work_orders_by_item` · **ERP·WMS·QMS** PLM 품목 가져오기 버튼과 `plm_imports` · **ERP** `standard_costs` · **QMS** `eco_releases` → 4M 후보.

| Q3 | **설계 변경** — ECR → ECO → 검토자 승인 → 배포. ECO 배포 시 QMS가 읽어 4M 변경 신고 후보로(QMS 4M과 경계: PLM = 설계 변경, QMS = 현장 변경 신고·초품 검사). GW 결재는 배지만(ERP 매입 E-11과 같은 방식) | 그대로 |
| Q4 | **M-BOM** — PLM은 E-BOM까지, MES가 가져와 공정 투입·대체 자재를 붙여 제조 BOM으로 | 그대로 |
| Q5 | **개발 프로젝트·단계 게이트**(기획 → 설계 → 시작 → 양산 승인, 단계별 산출물 체크리스트) 포함 여부 | 포함 |
| Q6 | **설계 원가 롤업**(E-BOM 전개 × ERP 표준 단가 조회, 리비전별 비교) 포함 여부 | 포함 |
| Q7 | 범위 확정 — 포함 15 + Q, 제외 2(PPAP·CAD 연동) | 제안대로 |
