## 0. PLM의 자리

**PLM = 설계 단계의 품목·도면·BOM과 그 변경을 관리하는 원천 솔루션.** 설계가 승인(배포)한 리비전을 MES·ERP·WMS·QMS가 **가져가 자기 마스터에 반영**한다(독립 솔루션 — 각자 마스터, 스냅샷 가져오기, FS-013 D1).

| 영역 | 소유 | PLM과의 관계 |
|---|---|---|
| 설계 품목·리비전·도면·E-BOM·설계 변경 | **PLM** | 이 문서 |
| 제조 BOM·공정 경로 | **MES** | PLM 배포 E-BOM을 가져와 제조 BOM으로(Q4) |
| 판매·구매·재고 품목 | **ERP·WMS** | PLM 배포 품목을 가져오기(Q1) |
| 4M 변경 신고·초품 검사 | **QMS** | 설계 변경(ECO) 적용 → QMS 4M 신고 후보(Q3) |
| 결재 | **GW** | ECO 결재 상태 배지(선택, Q3) |
| 품목 단가 | **ERP** | 설계 원가 롤업(Q6) |

## 7. 결정 질문 (하나씩)

| # | 질문 | 제안 |
|---|---|---|
| Q1 | **PLM 배포 리비전을 누가 가져가는가** — MES(품목 상세·BOM)·ERP·WMS·QMS(품목) 모두 "PLM에서 가져오기" 버튼으로 반영(자동 동기화 없음, 각 솔루션 마스터는 그대로 독립). 가져오기 1건 = 리비전 1건, 멱등 | 그대로 |
| Q2 | **도면 파일** — (a) 메타데이터만(문서 번호·리비전·상태·설명), 파일 첨부 제외 (b) 파일 올리기(저장소 필요) | **(a)**. 다른 솔루션들도 첨부 제외로 정했다 |
| Q3 | **설계 변경** — ECR → ECO → 검토자 승인 → 배포. ECO 배포 시 QMS가 읽어 4M 변경 신고 후보로(QMS 4M과 경계: PLM = 설계 변경, QMS = 현장 변경 신고·초품 검사). GW 결재는 배지만(ERP 매입 E-11과 같은 방식) | 그대로 |
| Q4 | **M-BOM** — PLM은 E-BOM까지, MES가 가져와 공정 투입·대체 자재를 붙여 제조 BOM으로 | 그대로 |
| Q5 | **개발 프로젝트·단계 게이트**(기획 → 설계 → 시작 → 양산 승인, 단계별 산출물 체크리스트) 포함 여부 | 포함 |
| Q6 | **설계 원가 롤업**(E-BOM 전개 × ERP 표준 단가 조회, 리비전별 비교) 포함 여부 | 포함 |
| Q7 | 범위 확정 — 포함 15 + Q, 제외 2(PPAP·CAD 연동) | 제안대로 |
