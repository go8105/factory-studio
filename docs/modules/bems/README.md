# BEMS — 건물 에너지

- 상태: **설계 초안(FS-025) — 사용자 승인 대기**
- 업무 범위: 공용 계측, 환경 관측, 공용 에너지 집계
- 이 폴더의 문서: [BEMS 모듈 설계서 FS-025(초안)](BEMS_모듈설계_FS-025.md) · 결정서 [FS-025](../../plan/BEMS도입_공용에너지_결정_FS-025.md)

## 메모

- 설계서 초안. 승인 전에는 테이블·코드를 만들지 않는다. (옛 예약 2테이블은 FS-013에서 삭제됐고 R4가 `bems` 스키마를 금지한다 — FS-025가 해제 예정)
- FEMS와 계측 소유·집계 범위를 분리한다. 사업장 전체 = 제조 + 공용 + 미계측 잔여.
- 공용/미계측 분해 예시는 BEMS 설명 카드에 기재한다.

## 규칙

이 폴더에 모듈 공통 설계서가 없으면 해당 모듈은 개발 착수 대상이 아니다.
설계를 먼저 확정하고 사용자 확인을 받은 뒤 구현에 들어간다.

기준정보(구역·계측기·센서·공조기)는 BEMS가 독립 소유한다(FS-013 D1). FEMS 값은 FS-023 D9의 읽기 전용 조회 인터페이스로만 읽는다.

전체 현황은 [현재 기획과 진행 현황](../../plan/현재기획_진행현황.md)을 본다.
