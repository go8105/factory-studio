## 0. 지금 BEMS와 경계

**지금(10테이블·7화면)**: 구역(사무·생산·유틸리티, 면적) · 공용 계측(조명·공조·사무·기타) · 환경 센서(온도·습도·CO₂) · 1시간 관측(시드·시뮬레이션) · 공조기(냉방·난방·송풍·정지) · 운전 스케줄(평일·주말) · 제어 명령(전원·모드·설정값) · 경보 규칙·경보(발생·확인·해제) · FEMS 전력 조회로 에너지 분해.

| 영역 | 소유 | BEMS와의 관계 |
|---|---|---|
| 건물 공용 에너지·환경·공조/조명 제어 | **BEMS** | 이 문서 |
| 공장 수전·피크·요금 | **FEMS** | BEMS는 FEMS 전력·피크 경보를 읽는다 |

## 3. 기능 규칙 (범위 21 중 신규·보강 14)

공통: 관측은 1시간 단위(시드·시뮬레이션). 제어는 모두 제어 명령 1건으로 남는다(FS-025 D21). 월간 보고서·공용 비용 배분은 "확정 1건 + 새 버전".

| 묶음 | 기능 ID | 규칙 |
|---|---|---|
| 휴일 (Q1) | F05·F22 | core 공통 휴일 달력(공휴일·회사 휴무). 요일 구분 = 휴일 > 토·일 > 평일. 스케줄은 평일·주말·휴일 3종. FEMS TOU·MES 근무조·HR 근태도 같은 달력을 날짜로 읽는다 |
| 공간 | F04 | 건물(층수·연면적) > 구역(층 표기·사용 부서) |
| 조명 (Q3) | F06·F23 | 조명 회로(구역·정격·조명 계측기), 켜기·끄기 명령과 스케줄(모드 ON). 상태 = 마지막 적용 명령 |
| 피크 (Q2) | F24 | FEMS 진행 피크 경보 1건당 감축안 1건: 감축 우선순위 낮은 번호부터 송풍 전환·설정 온도 상향(0.5~5℃)·끄기, 예상 감축 합 ≥ 목표까지. **담당자 승인 후** 단계별 제어 명령(출처 PEAK). FEMS 경보 해제 → 복귀안 승인 → 원래 상태로 |
| 환경·쾌적 (Q4) | F13·F14 | 지표 6종(온도·습도·CO₂·미세먼지·조도·재실). 쾌적 기준 = 구역 용도 × 지표의 범위, 근무 시간만 여부. 쾌적 시간 비율 = 범위 안 관측 시간 ÷ 관측 시간(조회) |
| 설비 경보 | F32·F33 | 공조기 명령 거부 연속 N회·연속 운전 N시간 → 설비 경보(규칙·설비당 진행 1건). 환경 경보와 함께 CMMS 전환 대기 신호로 제공 |
| 에너지 관리 (Q6) | F41~F44 | 원단위(EUI) = 공용 kWh ÷ 연면적(건물) 또는 구역 면적. 월 목표(구역 또는 건물 전체). 공용 비용 = 시간별 공용 사용량 × FEMS TOU 요율(조회) → 부서 면적 비율 배분. 월간 보고서: 사용·EUI·목표 달성·비용·쾌적 시간 비율·이슈, 확정 스냅샷(인쇄) |
