## 0. 지금 BEMS와 경계

**지금(10테이블·7화면)**: 구역(사무·생산·유틸리티, 면적) · 공용 계측(조명·공조·사무·기타) · 환경 센서(온도·습도·CO₂) · 1시간 관측(시드·시뮬레이션) · 공조기(냉방·난방·송풍·정지) · 운전 스케줄(평일·주말) · 제어 명령(전원·모드·설정값) · 경보 규칙·경보(발생·확인·해제) · FEMS 전력 조회로 에너지 분해.

| 영역 | 소유 | BEMS와의 관계 |
|---|---|---|
| 건물 공용 에너지·환경·공조/조명 제어 | **BEMS** | 이 문서 |
| 공장 수전·피크·요금 | **FEMS** | BEMS는 FEMS 전력·피크 경보를 읽는다 |
| 시설 점검·고장 수리 | **CMMS** | BEMS 경보·불편 신고를 CMMS가 작업지시로 전환 |
| 회의실·자원 예약 | **GW** | 제외 |
| 휴일 | **Q1** | 여러 솔루션이 쓰는 달력 |

**요지**: BEMS는 "보고 → 공조를 켜고 끈다"까지 있다. 실무 건물 운영에 필요한 **휴일 달력·조명·피크 대응·불편 신고·건물 원단위/보고서**가 없다. 테이블은 10 → 대략 **17~20** 추정.

## 7. 결정 질문 (하나씩)

| # | 질문 | 제안 |
|---|---|---|
| Q1 | **휴일 달력을 어디에 두는가** — (a) core 공통 달력(회사 휴일, 모든 솔루션이 날짜로 읽음, FK 없음) (b) BEMS 자체 달력(FEMS TOU 휴일은 FEMS가 따로) | **(a) core**. 휴일은 운영 공통 정보다(AGENTS §3 "core는 운영"). BEMS 스케줄·FEMS TOU·MES 근무조·HR 근태가 같은 달력을 쓴다 |
| Q2 | **피크 대응** — FEMS 피크 경보 발생 시 BEMS가 감축안(공조기 우선순위대로 송풍 전환·설정 온도 상향)을 **제안**, 담당자가 **승인하면 제어 명령** 실행. 자동 제어는 하지 않음 | 그대로 |
| Q3 | **조명 제어** — 구역별 조명 회로(켜기·끄기·스케줄, 조명 계측 연결) 추가 | 추가 |
| Q4 | **환경 지표 확장** — 미세먼지·조도·재실 인원 센서 + 구역별 쾌적 범위(용도별 기준) 안 시간 비율 | 추가 |
| Q5 | **불편 신고** — 신고(구역·유형·내용) → 조치(제어 명령 또는 CMMS 작업지시 전환 신호) → 완료. 신고자는 게스트/회원 이름 | 추가 |
| Q6 | **에너지 관리·보고** — 면적당 원단위·월 목표·공용 비용(FEMS TOU 요금 조회)·부서 면적 비율 배분·월간 보고서(확정 스냅샷) | 추가 |
| Q7 | 범위 확정 — 포함 22, 제외 5(평면 배치 화면·최적 기동·재실 자동 제어·시설 점검표(CMMS)·인증 지표) | 제안대로 |
