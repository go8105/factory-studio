# FEMS — 에너지 관리

- 상태: **구현 대상**
- 업무 범위: 에너지원·계측 채널, 환산·배출 계수, 요금제, 목표, 원단위 기준선, 계측 이력·배분
- 이 폴더의 문서: FEMS_공통설계_FS-005c.md

## 메모

- FS-005c 반영으로 다중 에너지원(전력·가스·용수) 구조를 갖췄다. 메타데이터 v0.4.0 기준 6테이블.
- 계측 수집 파이프라인·알람 서버는 구현 범위 밖이다. 계측값은 seed로 생성한다.
- 에너지원이 다르면 단위가 다르므로 1차에너지 환산 후에만 합산한다.

## 규칙

이 폴더에 모듈 공통 설계서가 없으면 해당 모듈은 개발 착수 대상이 아니다.
설계를 먼저 확정하고 사용자 확인을 받은 뒤 구현에 들어간다.

공통 기준정보(품목·설비·작업장 등)는 core가 소유한다. 모듈별로 복제하지 않는다.

전체 현황은 [현재 기획과 진행 현황](../../plan/현재기획_진행현황.md)을 본다.
