- 읽는 조회: 없음(생산량은 시드의 MES 파생 값)

### 제공 조회 함수 (`backend/src/fs/fems/interface.py`)

| 함수 | 돌려주는 것 | 쓰는 곳 |
|---|---|---|
| `enabled()` | 사용 여부 | — |
| `site_electricity(date_from, date_to)` | 사업장 전력 일별 합(kWh) | BEMS |
| `manufacturing_electricity(date_from, date_to)` | 제조 전력 일별 합(kWh, 설비 배분) | BEMS |

모든 함수의 앞 두 인자는 `(connection, scoped)`이고, 이 솔루션이 꺼져 있으면 `None`을 돌려준다.

> 아래는 작성 당시 메모다. 위 "현재 기준"과 다르면 위가 우선한다.

- 업무 범위: 에너지원·계측 채널, 환산·배출 계수, 요금제, 목표, 원단위 기준선, 계측 이력·배분
- 이 폴더의 문서: FEMS_공통설계_FS-005c.md

## 메모

- FS-005c 반영으로 다중 에너지원(전력·가스·용수) 구조를 갖췄다. 메타데이터 v0.4.0 기준 6테이블.
- 계측 수집 파이프라인·알람 서버는 구현 범위 밖이다. 계측값은 seed로 생성한다.
- 에너지원이 다르면 단위가 다르므로 1차에너지 환산 후에만 합산한다.
