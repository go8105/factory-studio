## 0. 지금 FEMS와 경계

**지금(13테이블·14화면)**: 사업장·공간·설비 · 에너지원(전력·연료·열·유틸리티) · 계측기·채널(누적/순시) · **1시간 단위 계측** · 설비별 배분 · 환산(1차에너지)·배출 계수 · 요금제(기본요금 + 단일 사용 요율) · 목표 · 원단위 기준선 · 생산량(시드의 MES 파생값) · 대시보드·배출량·원단위·목표 대비·요금 산정.

| 영역 | 소유 | FEMS와의 관계 |

## 3. 기능 규칙 (범위 30 중 신규·보강 19)

공통: 계측은 1시간 단위 유지(Q2). **1차에너지 합산은 PRIMARY 계수 환산 후, 배출은 EMISSION 계수 — 섞지 않는다**(AGENTS §3). 월간 검토·온실가스 명세서·비용 배분은 "확정 1건 + 새 버전".

| 묶음 | 기능 ID | 규칙 |
|---|---|---|
| 요금 (Q1) | F05·F41 | 요금제 구분 FLAT/TOU. TOU = 계약전력 × 기본요금 단가 + Σ(시간 사용량 × 그 시간의 요율). 요율은 계절(여름 6~8·봄가을 3~5·9~10·겨울 11~2, 코드 상수) × 요일(평일·토요일·휴일) × 시간 구간(0~24시를 빈틈·겹침 없이) → 부하 구분(경부하·중간·최대부하). 합성 요율 |
| 피크 (Q2) | F15·F26 | 수요전력 = 수전 채널 시간 사용량(kWh = 평균 kW)의 최대값. 계약전력 대비 비율, 월 최대 시각. 화면에 "1시간 근사" |
| 데이터 (Q3) | F12~F14·F51 | 수동 검침(연료·용수 월 검침)과 CSV 올리기(행 검증, 반영/거부 합계)는 계측 행(입력 방법 MANUAL·FILE). 결측·이상값 탐지(0 연속·급증) → 보정(보간·직전값·수동)은 새 입력 수정 버전(원 값 보존). 생산량은 MES 조회로 가져오기(새 버전 확정) 또는 수동 |
| 분석 | F25·F27 | 부하 패턴: 시간대·요일 평균 프로파일, 기저부하(야간 최소), 비가동 시간 사용. 설비 비교: 같은 종류 설비 원단위 순위 |
| 경보 | F31·F34 | 규칙 3종(시간 사용량 임계·계약전력 대비 피크 비율·비가동 시간 사용). 규칙당 진행 경보 1건(발생 → 확인 → 해제). CMMS가 진행 경보를 전환 대기 신호로 읽는다 |
| 절감 (Q5) | F32 | 계획 → 시행 → 검증. 실제 절감 = (시행 전 원단위 − 시행 후 원단위) × 시행 후 생산량, 연 환산. 비교 기간 같은 길이. 검증 후 불변 |
| 보고서 (Q5) | F33 | 월간 검토: 1차에너지(toe)·비용·배출·목표 달성률·주요 이슈. 확정 스냅샷, 인쇄 |
| 온실가스 (Q6) | F35 | 연간 명세서: 배출 시설(설비)·에너지원별 활동량 × 그 연도 EMISSION 계수. Scope 1 = 연료, 2 = 전력·열. 확정 후 불변 |
| 신재생 | F37 | 에너지원 GENERATION + 발전 계측기(scope generation). 자가소비 = 발전량 − 역송(1차는 역송 0) |
| 비용 (Q4) | F42·F43 | 고지서 대조: 청구 금액 입력 vs 산정 스냅샷, 차이 사유. 비용 배분: 설비 배분량 × TOU 요율 + 기본요금 사용량 비율 → 설비·부서(ERP 부서 코드)·주 생산 품목. 확정분을 ERP가 참고로 읽음 |

## 6. 교차 조회

**FEMS가 읽는 것**

| 제공 | 함수 | FEMS 용도 |
|---|---|---|
| MES | `production_results(month)`(DSN-12) · `operation_runs`(있음, 가동/비가동 구분) | F51 생산량, F25 비가동 시간 사용 |
| ERP | `departments()` | 설비 부서 코드 선택 |

**FEMS가 제공하는 것** (지금 3개 + 추가)

| 함수 | 돌려주는 것 | 쓰는 곳 |
|---|---|---|
| `energy_costs(month)` | 확정 비용 배분(설비·부서·품목) | ERP 원가 화면 참고(Q4) |
| `open_alarms()` | 진행 에너지 경보(설비 코드·종류·최대값) | CMMS 전환 대기 신호(F34) |
| `monthly_summary(month)` | 1차에너지·비용·배출(확정 검토) | EIP 경영 요약 |

## 7. 결정 질문 (하나씩)

| # | 질문 | 제안 |
|---|---|---|
| Q1 | **전력 요금 체계** — 계약전력 기본요금 + 계절(여름·봄가을·겨울) × 시간대(경부하·중간·최대부하) 사용 요율, 시간대 구분표를 요금제 버전에 둔다. 요율은 합성 값 | 그렇게 한다 |
| Q2 | **수요전력 단위** — (a) 1시간 계측 그대로, 피크는 시간 최대값으로 근사 (b) 전력 수전 채널만 15분 계측 추가(시드 행 약 4배) | **(a)**. 시드 예산(DSN-01)을 지킨다. 화면에 "1시간 근사" 표시 |
| Q3 | **생산량** — MES `production_results` 조회로 가져오기(확정 버전), 수동 입력도 유지 | 그렇게 한다 |
| Q4 | **에너지 비용 배분 → ERP** — FEMS가 월 설비·부서·품목별 에너지 비용을 계산해 제공, ERP 원가 계산에서 경비 배부 참고로 읽기(ERP 배부 기준은 생산량 그대로) | 그렇게 한다 |
| Q5 | **에너지 경영** — 절감 활동(예상 → 실제 절감 측정·검증)과 월간 검토 보고서 포함 | 포함 |
| Q6 | **온실가스 명세서** — 연간 Scope 1(연료)·2(전력·열) 배출 시설별 보고서(확정 후 불변, 재산정은 새 버전). 배출권 거래 제외 | 포함 |
| Q7 | 범위 — 포함 29 + Q2 결과, 제외 3(게이트웨이 자동 수집·예측·배출권 거래) | 제안대로 |
