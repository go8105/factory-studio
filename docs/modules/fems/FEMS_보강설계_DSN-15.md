# DSN-15 FEMS 보강 설계

작성: 2026-10-05 (Claude Code) · 상태: **1단계 — 기준표·갭 요약·결정 질문(범위 확인 대기)**. 3~6장은 범위 확정 뒤.
양식: [DSN-00](../../plan/기능기준표_DSN-00.md) · 방침: [ROADMAP-02](../../plan/전체설계우선_전환_ROADMAP-02.md) · 기존 설계: [FEMS 공통 설계](FEMS_공통설계_FS-005c.md)
기준 참고: 에너지경영시스템 ISO 50001(에너지 검토·EnPI·기준선·개선 활동), 산업용 전력 요금(계약전력 기본요금 + 계절·시간대별 사용 요금), 온실가스 명세서(Scope 1·2).

## 0. 지금 FEMS와 경계

**지금(13테이블·14화면)**: 사업장·공간·설비 · 에너지원(전력·연료·열·유틸리티) · 계측기·채널(누적/순시) · **1시간 단위 계측** · 설비별 배분 · 환산(1차에너지)·배출 계수 · 요금제(기본요금 + 단일 사용 요율) · 목표 · 원단위 기준선 · 생산량(시드의 MES 파생값) · 대시보드·배출량·원단위·목표 대비·요금 산정.

| 영역 | 소유 | FEMS와의 관계 |
|---|---|---|
| 공장 에너지(생산 설비·수전) | **FEMS** | 이 문서 |
| 건물 에너지·환경·공조 | **BEMS** | FEMS 전력 조회를 이미 읽는다(있음) |
| 생산량 | **MES** | 지금은 시드 파생값. MES 조회로 가져오기(Q3) |
| 전기요금 청구·회계 | **ERP** | 고지서는 ERP 매입(직접 매입). FEMS는 산정·대조·배분 |
| 설비 보전 | **CMMS** | 에너지 이상 신호 → 작업지시 전환 후보(F34) |

| 영역 | 기능 | ✓ | △ | ✗ | 범위 ○ | Q | ✕ |

**요지**: FEMS는 운영 중 솔루션 가운데 가장 깊다(14화면). 비어 있는 것은 **실무 요금 체계(계약전력·시간대별)·피크 관리·경보·절감 활동·보고서**, 즉 "측정 다음의 관리"다. 테이블은 13 → 대략 **22~25** 추정.

## 7. 결정 질문 (하나씩)

| # | 질문 | 제안 |
|---|---|---|
| Q1 | **전력 요금 체계** — 계약전력 기본요금 + 계절(여름·봄가을·겨울) × 시간대(경부하·중간·최대부하) 사용 요율, 시간대 구분표를 요금제 버전에 둔다. 요율은 합성 값 | 그렇게 한다 |
| Q2 | **수요전력 단위** — (a) 1시간 계측 그대로, 피크는 시간 최대값으로 근사 (b) 전력 수전 채널만 15분 계측 추가(시드 행 약 4배) | **(a)**. 시드 예산(DSN-01)을 지킨다. 화면에 "1시간 근사" 표시 |
| Q3 | **생산량** — MES `production_results` 조회로 가져오기(확정 버전), 수동 입력도 유지 | 그렇게 한다 |
| Q4 | **에너지 비용 배분 → ERP** — FEMS가 월 설비·부서·품목별 에너지 비용을 계산해 제공, ERP 원가 계산에서 경비 배부 참고로 읽기(ERP 배부 기준은 생산량 그대로) | 그렇게 한다 |
| Q5 | **에너지 경영** — 절감 활동(예상 → 실제 절감 측정·검증)과 월간 검토 보고서 포함 | 포함 |
| Q6 | **온실가스 명세서** — 연간 Scope 1(연료)·2(전력·열) 배출 시설별 보고서(확정 후 불변, 재산정은 새 버전). 배출권 거래 제외 | 포함 |
| Q7 | 범위 — 포함 29 + Q2 결과, 제외 3(게이트웨이 자동 수집·예측·배출권 거래) | 제안대로 |
