# QMS — 품질 관리

- 상태: **준비 중**
- 업무 범위: 검사 기준·결과, 합격/불합격 판정, LOT 보류
- 이 폴더의 문서: 없음

## 메모

- **설계서 없음. 테이블 없음. 개발 착수 대상이 아니다.**
- 프로세스 맵에서 설명 카드로만 제공한다. 실적 확정과 패킹 사이에 들어갈 자리다.
- 품질 보류는 모듈 설정 변경으로 해제되지 않아야 한다는 정책이 이미 정해져 있다.

## 규칙

이 폴더에 모듈 공통 설계서가 없으면 해당 모듈은 개발 착수 대상이 아니다.
설계를 먼저 확정하고 사용자 확인을 받은 뒤 구현에 들어간다.

공통 기준정보(품목·설비·작업장 등)는 core가 소유한다. 모듈별로 복제하지 않는다.

전체 현황은 [현재 기획과 진행 현황](../../plan/현재기획_진행현황.md)을 본다.
