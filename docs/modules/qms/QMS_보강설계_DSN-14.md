# DSN-14 QMS 보강 설계

작성: 2026-10-05 (Claude Code) · 상태: **1단계 — 기준표·갭 요약·결정 질문(범위 확인 대기)**. 3~6장은 범위 확정 뒤.
양식: [DSN-00](../../plan/기능기준표_DSN-00.md) · 방침: [ROADMAP-02](../../plan/전체설계우선_전환_ROADMAP-02.md) · 기존 설계: [FS-023](QMS_모듈설계_FS-023.md)
넘겨받은 것: WMS(DSN-13 F18) 수입 검사 판정 → 격리 해제/불량. MES(DSN-12 Q5) 공정 검사는 **MES 소유** — QMS는 읽어 집계만.

---

## 0. 지금 QMS와 경계

**지금(6테이블·6화면)**: 불량 유형 · 품목별 검사 기준(게시 버전) · **출하 전 최종 검사(LOT, MES 완료 LOT 조회)** · 판정 · 품질 보류(재검사·특채·폐기 처분). MES에 보류 배지, SPC 이상 배지 표시. 수입 검사·부적합·시정조치·클레임·공급처·계측기·지표는 없다.

| 영역 | 소유 | QMS와의 관계 |
|---|---|---|
| 검사 기준·출하/수입 검사·판정·보류·부적합·시정조치 | **QMS** | 이 문서 |
| 공정 검사(초·중·종물) | **MES**(DSN-12 Q5) | QMS는 결과를 읽어 지표에만 |
| 관리도·공정능력 | **SPC** | QMS는 이상 배지(있음) |
| 재고 격리·이동 | **WMS** | QMS 판정을 WMS가 읽어 격리 해제/불량 위치로(WMS 반영) |
| 공급처·고객·반품 문서 | **ERP** | QMS는 코드 스냅샷으로 읽기 |
| 고객 접점(영업 이력) | **CRM**(신규) | 클레임 소유가 Q4 |

## 7. 결정 질문 (하나씩)

| # | 질문 | 제안 |
|---|---|---|
| Q1 | **수입 검사 흐름** — WMS 검수(수량) 후 검사 대상 LOT은 WMS 격리 위치 + QMS 보류 → QMS 수입 검사 → 판정을 WMS가 읽어 합격은 정상 위치, 불합격은 불량 위치(또는 반품). 검사 대상 = 품목 "검사 필요" + 공급처 검사 수준(면제면 생략) | 그대로 |
| Q2 | **샘플링** — (a) AQL 표(KS Q ISO 2859-1 일반 검사 수준 II·보통 검사·1회 샘플링)로 시료 수·합격 판정 개수(Ac/Re) 자동 (b) 시료 수 직접 입력(지금) | **(a)**. 기준에 AQL 값만 지정, 직접 입력도 허용 |
| Q3 | **부적합·시정조치 범위** — NCR(부적합 보고) + CAPA(원인·대책·유효성 확인)까지, 8D 형식은 제외 | 그대로 |
| Q4 | **고객 클레임 소유** — (a) QMS(접수·조사·회신, CRM은 고객 이력에서 읽기) (b) CRM(QMS는 조사만) | **(a) QMS**. 클레임의 본질은 품질 조사·시정조치다 |
| Q5 | **공급처 평가·검사 수준 전환** — 월 수입 불량률로 등급, 연속 합격 시 면제·연속 불합격 시 강화로 자동 전환(사람이 확정) | 그대로 |
| Q6 | **계측기 관리**(대장·교정 이력·도래 경고, 검사 때 사용 계측기 기록) 포함. MSA는 제외 | 포함 |
| Q7 | **4M 변경 신고**(변경 → 승인 → 초품 검사)를 포함하고 범위(포함 28, 제외 5: 8D·공급처 심사·MSA·품질 비용·ISO 문서) 확정 | 제안대로 |
