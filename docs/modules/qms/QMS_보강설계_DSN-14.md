# DSN-14 QMS 보강 설계

작성: 2026-10-05 (Claude Code) · 상태: **설계 완료(2026-10-05) — 사용자 확인 대기.** 1단계(기준표·Q1~Q7 확정) + 2단계(3장 기능 규칙 · 4장 DB 15테이블 · 5장 화면 13 · 6장 교차 조회).
양식: [DSN-00](../../plan/기능기준표_DSN-00.md) · 방침: [ROADMAP-02](../../plan/전체설계우선_전환_ROADMAP-02.md) · 기존 설계: [FS-023](QMS_모듈설계_FS-023.md)
넘겨받은 것: WMS(DSN-13 F18) 수입 검사 판정 → 격리 해제/불량. MES(DSN-12 Q5) 공정 검사는 **MES 소유** — QMS는 읽어 집계만.

## 0. 지금 QMS와 경계

**지금(6테이블·6화면)**: 불량 유형 · 품목별 검사 기준(게시 버전) · **출하 전 최종 검사(LOT, MES 완료 LOT 조회)** · 판정 · 품질 보류(재검사·특채·폐기 처분). MES에 보류 배지, SPC 이상 배지 표시. 수입 검사·부적합·시정조치·클레임·공급처·계측기·지표는 없다.

| 영역 | 소유 | QMS와의 관계 |
|---|---|---|
| 검사 기준·출하/수입 검사·판정·보류·부적합·시정조치 | **QMS** | 이 문서 |
| 공정 검사(초·중·종물) | **MES**(DSN-12 Q5) | QMS는 결과를 읽어 지표에만 |
| 관리도·공정능력 | **SPC** | QMS는 이상 배지(있음) |
| 재고 격리·이동 | **WMS** | QMS 판정을 WMS가 읽어 격리 해제/불량 위치로(WMS 반영) |
| 공급처·고객·반품 문서 | **ERP** | QMS는 코드 스냅샷으로 읽기 |
| 고객 접점(영업 이력) | **CRM**(신규) | 클레임은 QMS 소유(Q4 확정), CRM은 읽기 |

## 3. 기능 규칙 (범위 28 중 신규·보강 20)

공통: 검사·판정은 지금 출하 검사 엔진 하나로 종류만 늘린다(출하·수입·반품·초품). 확정 후 불변, 정정은 재검사. 다른 솔루션 값은 코드 스냅샷.

| 묶음 | 기능 ID | 규칙 |
|---|---|---|
| 기준 | F03·F04 | 품목·검사 종류(출하·수입)당 게시 기준 1개. 반품·초품 검사는 출하 기준을 쓴다. 기준에 AQL을 지정하면 샘플링 자동 |
| 샘플링 (Q2) | F04 | 로트 크기 → 시료 문자 → 시료 수·Ac/Re(KS Q ISO 2859-1, 일반 수준 II, 보통/강화 1회 샘플링). **표는 코드 상수**(DB 아님). 판정: 시료 불량 개수 ≤ Ac 이고 필수 항목이 모두 합격이면 합격. AQL 없으면 지금처럼 시료 수 직접 입력 |
| 수입 검사 (Q1) | F11~F14 | 대상 = WMS 입고 검수 LOT 중 품목 "검사 필요" AND 공급처 현재 수준 ≠ 면제. 검사 전 LOT은 QMS 보류(WMS 출고·불출 불가). 판정 확정 → WMS가 읽어 합격은 정상 위치, 불합격은 불량 위치 또는 반품(처분 RETURN). 불합격이면 부적합 보고 + 시정 요구 제안 |
| 공급처 (Q5) | F05·F51 | 월 평가: 검사 LOT·불합격 LOT·불량 PPM·시정 요구 건수 → 등급 A~D. 연속 합격(기본 10 LOT)이면 면제 제안, 연속 불합격(2 LOT)이면 강화 제안. **담당자가 확정**하면 새 검사 수준 행(적용일 이력) |
| 출하 검사 | F25·F27 | 성적서(COA) = 확정 검사의 항목·측정값·판정·계측기를 브라우저 인쇄. 검사 값마다 사용 계측기 기록, 교정 만료·수리 중 계측기면 경고 |
| 부적합·시정조치 (Q3) | F31·F32·F34 | 부적합 보고: 발생처 4종(수입·공정·출하·고객), 근거(검사·클레임·MES 불량 코드), 즉시 조치. CAPA: 근본 원인·대책·담당·기한 → 완료 → 유효성 확인(무효면 새 CAPA). 부적합 종결 = 연결 CAPA 모두 확인. MES 공정 불량·공정 검사는 MES 조회로 집계 |
| 클레임 (Q4) | F41~F43 | 접수 → 조사(고객 발생 부적합 보고 생성, LOT 역추적은 MES·WMS 조회) → 회신 → 종결. 반품 연결 시 반품 검사(RETURN) → 재입고/폐기를 WMS가 읽음 |
| 계측기 (Q6) | F61·F62 | 대장(번호·종류·범위·분해능·교정 주기). 교정 이력(결과·다음 기한, 불합격이면 수리 중). 도래 30일 경고 |
| 4M 변경 (Q7) | F06 | 신고(사람·설비·자재·방법) → 승인/반려 → 초품 검사(FIRST_ARTICLE, 원천 = 신고 번호) 합격 → 확인 완료 |
| 지표 | F72 | 수입·공정(MES)·출하·고객별 불량률·PPM, 불량 유형 파레토, 월 추이(조회 계산) |

## 7. 결정 질문 (하나씩)
