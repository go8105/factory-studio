# CAD-04 편집기 고도화 분석

2026-10-06. 연구노트 구현과 고도화 분석 작업이다. 아래 개발은 제안이며 아직 착수하지 않았다.

## 기획 의도 검토

사용자는 비누 케이스·힌지·마찰 돌기·가루통을 직접 수정하고 제작 결과를 확인하려 한다. 현재 일반 편집기와 비누 생성 모델은 연결되지 않았다. 비누 STL을 가져와 원래 치수/이력을 편집할 수 없다.

`src/model.js`는 rect/circle만 허용한다. stock 1개, 상면에서 파는 features 최대32개, 크기200×200×80mm 제한이다. 사각형 모서리 반경은 평면 윤곽이며 임의 3D 필렛이 아니다. `viewer.js`는 깊이별 단면 메시, `simulation.worker.js`는 평 엔드밀 높이장 소재 제거다. 자유 선/원호·측면 구멍·추가 보스·다중부품·구속·STEP이 없어 비누 전체를 직접 설계할 수 없다.

## 예상 문제점/제약

- 자유 윤곽: 열린 선·자기교차·중복점·작은 선분 검증 필요. 선/원호/슬롯/치수/끝점 스냅부터, 자유곡선과 완전 구속 솔버는 후속.
- 데이터: 피처 의존 관계·참조 면/모서리 ID·실패시 직전 정상 형상 유지 필요. STL에서 파라미터를 복원하지 못한다. STEP도 우리 작업 이력을 자동 복원하지 않는다.
- 커널: 현재 Manifold 메시 boolean과 정밀 OCCT B-Rep 후보를 실증해야 한다. 표시 메시와 원본 형상 분리. 임의 필렛/셸/STEP을 UI 버튼만으로 구현할 수 없다.
- 성능: WASM 로딩·메모리·재계산 시간을 실측 전 약속하지 않는다. worker·오래된 결과 폐기·캐시·복잡도 상한, 커널 중단 불가시 worker 재시작 필요.
- CAM: 오목 윤곽·좁은 영역의 공구경 오프셋·진입/퇴피·잔삭 검증 필요. 높이장으로 언더컷·다축·홀더 충돌은 검증하지 못한다.
- 제작: FDM은 CAD→STL/3MF→슬라이서→출력. CNC CAM과 별개. 유연 케이스 물성/접촉·힘/복원은 별도 CAE/실물 시험이며 애니메이션이 성능 증거는 아니다.
- 연구 기록: 이번 신규 기록은 브라우저 저장·JSON 백업. 다기기/사진 업로드/공동편집/서명은 서버 저장 설계를 먼저 해야 한다. 관리자 자료를 공개 예제로 넣지 않는다.

## 질문

관리자 웹 연구노트·파일 이력은 사용자 답변으로 확정했다. 고도화 착수 전 전체 방향을 확인한다.

1. 비누 CAD와 CNC 학습 중 우선순위? 제안: 비누 CAD.
2. 자유 스케치와 비누 전용 치수 중 첫 목표? 제안: 커널 실증 후 선/원호/슬롯과 기본 치수, 같은 피처 모델에 비누 치수 연결.
3. 서버 연구노트/사진 업로드가 즉시 필요한가? 이번은 브라우저 저장이다.

E0부터 실증한다. 피처 ID/파라미터/선행 참조/결과 상태, 부품 모델과 배치/조인트를 원본으로 둔다. worker가 표시 메시/피킹 ID를 반환하고 Three.js가 표시한다. JSON 원본과 STEP/STL 산출물을 연구 버전별로 묶는다.

CAM 세팅·공구·대상·작업 순서는 CAD 피처와 별도 저장한다. 모델 변경시 경로는 미검증으로 전환한다. 연구 버전은 원본/산출물 해시·조건·결과·판단을 연결한다. 서버 확장시 CAD 데이터는 자기 모듈이 소유하며 다른 업무 솔루션 FK는 만들지 않는다.

### 기술 근거

- [replicad 공식 문서](https://replicad.pages.dev/docs/use-as-a-library/): OCCT WASM·STL/STEP·worker 배치. GUI/구속/CAM이 자동 완성되는 제품은 아니다.
- [Manifold CrossSection API](https://manifoldcad.org/docs/html/classmanifold_1_1_cross_section.html): polygon boolean·offset. 우리 오목 영역/CAM 검증을 대체하지 않는다.
- [OCCT 공식 교육 자료](https://www.opencascade.com/sites/default/files/documents/OCCT_Training/occt_training_fundamentals.pdf): B-Rep·boolean/fillet/offset. 우리 모델의 성공/성능 보증은 아니다.

후보 라이브러리 설치·커널 실증·STEP 왕복·실물 가공은 이번에 미실행. 전체 계획 확인 후 다음 ID 착수.

## 2026-10-06 사용자 확정 — CAD-05 시작

1. CNC 가공을 먼저 강화한다. 비누 제품 심화는 사용자가 창업 후속 단계에서 재개한다.
2. 자유 스케치/치수·피처 모델 방향을 승인한다. 우선 CNC용 자유 평면 윤곽을 지원할 근거를 검증한다.
3. 사진 업로드는 필요 없다. 연구 기록과 실제 설계 파일의 폴더/네이밍만 연결한다. 브라우저 기록·JSON 백업을 유지하며 서버 동기화는 당장 만들지 않는다.
4. main push를 명시 승인했다. 운영 배포와는 별개다.

CAD-05는 CNC 우선 E0: 기존 Manifold WASM으로 오목 윤곽/섬/좁은 통로/과대 공구의 offset·분리 경로와 독립 경계 검사를 실행한다. 비누 셸/필렛·OCCT STEP 실증은 비누 심화/정밀 B-Rep 단계로 옮긴다. E0 결과 후 다음 ID는 자유 스케치(선/슬롯/원호·치수·닫힘 검증)와 기존 2.5D 편집기 연결이다. 이번 E0를 완성 편집기 기능으로 표시하지 않는다.

## 2026-10-06 권장안 E1 구현 반영

사용자의 이어가기 승인으로 CAD-06/E1을 실제 편집기에 연결했다. 선 연결·3점 원호·회전 슬롯·좌표 치수·격자/끝점 스냅·JSON v2/v1 호환·CNC Worker와 분리 구간 안전 높이 이동을 제공한다. [구현 결과·검증·남은 제약](../../agent/자유스케치_편집기_CAD-06.md)을 기준으로 다음 E2를 검토한다. 완전 구속 해석기·혼합 선/원호 이어 그리기·섬 편집 UI는 미구현이다.
