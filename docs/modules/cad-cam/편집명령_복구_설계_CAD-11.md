# CAD-11 공통 편집 명령과 실수 복구 계약

2026-10-07 · CAD-10 권장안 사용자 승인 · 3축 밀링/G-code 우선

## 범위와 명령

기존 E1 2.5D 및 E2 단일 부품 편집기를 개선한다. 새 NC 해석기/에너지 모델/범용 CAD 엔티티는 이 ID에 포함하지 않는다. 기존 JSON v2/v3와 저장 범위를 유지한다.

| 입력 | 동작 |
|---|---|
| Ctrl/⌘+Z | 진행 중 편집이 있으면 초안 취소, 아니면 확정 모델 취소 |
| Ctrl/⌘+Shift+Z, Ctrl+Y | 동일 범위 다시 실행 |
| Esc | 현재 편집 취소·마지막 확정 값 복원, 계산 중에는 Worker 취소 |
| Delete | 선택 피처 삭제; E2 참조 영향이 있으면 목록 표시·거부 |
| Backspace | 입력칸 밖 진행 중 스케치/초안 한 단계 복구 |
| F | 전체 보기 |
| Ctrl/⌘+S | 마지막 확정 설계 JSON 저장 |
| ? | 단축키 도움말; Esc로 닫기 |

입력칸·textarea·select·contenteditable의 undo/redo는 브라우저 기본 동작을 유지한다. 저장/Esc는 명시적 공통 동작이다. IME 조합·키 반복·Alt 조합은 설계 명령을 실행하지 않는다.

## 이력과 확정 경계

- 초안 이력은 최대50단계이며 점 ID·좌표·원호 통과점·닫기 상태와 진행 중 원호 클릭을 복제해 기록한다. 확정 모델은 기존 E1 50/E2 30단계 이력을 유지한다.
- 점 클릭/윤곽 닫기 한 번=한 단계, 사각형·원·슬롯 드래그는 pointerup 한 번=한 단계. 치수의 연속 입력은 같은 입력칸에서 한 단계로 묶고 focusout 때 끝낸다.
- 초안 이력이 끝나도 redo가 남으면 확정 모델 취소로 넘어가지 않는다. 새 초안은 적용 전 기존 모델을 되돌리지 않는다. 새 변경은 redo를 비운다.
- 취소·선택 변경·새 편집·성공한 적용은 초안 세션을 정리한다. 형상 검증 실패·계산 취소는 확정 모델/저장/확정 이력을 변경하지 않는다. 실패한 3점 원호는 직전 두 점을 유지한다.
- E2 삭제는 referenceId/sourceId의 직접·간접 참조를 검사한다. 자동 연쇄 삭제는 하지 않는다. 참조 없는 피처 삭제도 커널 성공 후 하나의 확정 이력이 된다. 삭제 복구는 원래 모델을 다시 계산한다.
- E2 취소한 Worker의 늦은 결과는 현재 Worker 인스턴스 검사로 거부한다. 카메라/선택/도움말은 설계 이력에 넣지 않는다.

## 검증 기준

순수 명령 라우팅/스냅샷/그룹/참조 테스트와 실제 iframe 키 입력을 구분해 기록한다. 기존 전체 프런트 테스트·빌드/공개 자산 격리를 확인한다. 실패/취소·원호/드래그 등의 미실행 브라우저 사례는 완료한 실사용 사례로 표시하지 않는다. DB 변경은 없다.
