# CAD-16 전문 스케치·직접 편집 계약

2026-10-08 · CAD-10의 승인된 CAD-16 범위. 기존 E1/E2에 같은 전문 스케치 창을 연결한다. NC/비누 권한/DB는 변경하지 않는다.

## 엔티티·와이어·영역

- 기존 JSON v2/v3의 `nodes`를 보존한다. 점 ID는 와이어 안에서 유일하다. 노드의 ID는 그 점에서 다음 점으로 향하는 선/3점 원호의 의미 ID이기도 하다. `closed=false`의 마지막 점에는 나가는 엔티티가 없다.
- 한 외곽 + `holes`의 최대8개 내부 닫힌 profile을 영역으로 사용한다. 내부 경계는 가공에서 남기는 섬, 돌출에서 구멍이다. 내부 경계는 외곽과 최소0.1mm 떨어지고 서로 중첩/접촉/포함하지 않아야 한다. 중첩 섬/여러 외곽은 이번 버전에 넣지 않는다. 원호를 유지하며 표시/가공만 0.01mm 현 오차로 근사한다.
- 열린 와이어는 창 안에서 편집 가능하나 적용/돌출/CAM은 거부한다. 취소/실패는 확정 설계를 보존한다. 최대64점/와이어, 전체4096근사점, 기존 파일100KB·피처 상한 유지.
- 구속은 점 ID 기반 기존 수평/수직/일치/길이/반경/고정 해석기를 사용한다. 참조를 없애거나 변형하는 명령은 구속이 있으면 먼저 해제를 요구한다. 암묵적인 구속 삭제/치수 변경 없음.

## 명령·사용 흐름

- 클릭 선택, Shift 다중 선택, 점/원호 경유점 드래그, 격자/끝점 스냅, 연속 선/3점 원호 작성, 선택점 사이 거리/선 길이/원호 반경 측정, 좌표·길이 구속.
- 선택점 이동/회전/축 반사, 전체 와이어 복사(새 내부 경계), 내부 경계 생성/삭제. 복사는 새 점 ID를 만들며 구속은 복제하지 않는다.
- trim: 닫힌 와이어의 선택 엔티티 제거 → 열린 와이어. 열린 와이어는 끝의 직선을 비율로 자른다. extend: 열린 직선 끝을 지정 mm 연장. 교차 대상 자동 검색/원호 자르기는 후속이다.
- offset: 직선만으로 이루어진 엄격 볼록 닫힌 와이어의 평행 교차선으로 계산. 원호/오목 윤곽/퇴화·자기교차·영역 충돌은 거부한다. 임의 윤곽 자동 보정으로 표시하지 않는다.
- 창 내부50단계 undo/redo, 입력 기본 undo 보호, Esc 취소. 성공한 적용은 기존 편집기 초안 이력 한 단계, 최종 형상 적용은 기존 모델 이력 한 단계다.

## 직접 편집 참조

- E2의 실제 OCCT 직선 모서리를 형상 종류·시작/끝좌표·길이로 식별하고, 현재 형상에서 정확히 하나일 때만 국소 필렛/모따기를 적용한다. 재계산 때 재매칭 실패/중복은 피처 실패로 중단하고 마지막 정상 설계를 유지한다. 참조 재선택은 해당 피처와 종속 피처를 지운 뒤 새 피처로 한다. 현재 완성 형상의 대상을 과거 이력 중간 피처에 잘못 연결하지 않도록 새 피처에서만 선택을 허용한다. 메시 삼각형 번호를 영구 참조로 저장하지 않는다.
- 면 선택은 축 정렬 평면의 기하 경계와 법선·면적을 기록하고 재확인한다. 지원 평면에서만 새 돌출/파내기 작업면으로 사용한다. 기울어진 면/곡면·임의 면 이동·범용 위상 이름 추적은 미지원이다.
- STEP/STL·체적·솔리드 유효성은 실제 커널로 검증한다. CAD-17(공통 검증/배포 준비)은 시작하지 않는다.

## 완료 검증

기존 파일 호환, 명령 불변성/ID/구속/실패 복구, 섬의 체적·공구 여유·잔삭, 실 OCCT 국소 편집과 선행 변경 참조 실패, 실제 E1/E2 창 드래그/혼합 작성/변형/undo·적용·PC/모바일, 전체 prototype/frontend 테스트와 빌드/비누 격리. 실 CNC/출력·운영 배포/실측 검증은 별도다.
