# 품질 우선 경로 제안 — 검토용 설계

2026-10-07 사용자 요청: 경로 생성 때 제안, 1순위 품질·2순위 전력 소비 감소. 이번 CAD-08은 운영 비누 자산 복구와 이 방향의 분석이다. 경로 제안 제품 코드는 아직 적용하지 않았다. 기존 작업 ID별 결과 확인 규칙에 따라 다음 구현 전에 이 설계를 확인한다.

## 기획 의도 검토

품질과 에너지를 가중 합산하지 않는다. 안전 검사를 먼저 통과하고, 목표 품질 조건을 만족하는 후보를 추린 뒤 소비 에너지로 비교한다. 전력 kW는 순간 부하이고 소비 에너지는 kWh다. 사용자가 원하는 소비 감소는 후자를 2순위로 두고 최대 전력은 장비 제약으로 별도 취급한다.

초기 대상은 **E1 상면 2.5D 포켓**이다. E2 임의 3D/측면 모델을 지원한다고 표시하지 않는다. 공구·이송·깊이·절삭 방향·마무리 윤곽은 유지하고, 같은 깊이의 래스터 스트로크 방문 순서만 바꾼 후보부터 비교한다. 매 스트로크 사이에는 기존 안전 높이로 후퇴한다. 다른 깊이/피처를 섞거나 방향을 뒤집거나 마무리 윤곽을 생략하지 않는다. 기존 경로도 항상 후보에 포함한다.

## 예상 문제점/제약

현재 CAM은 근사 폴리곤, 고정0.05mm 여유, 평 엔드밀·격자 소재 제거다. 0.6mm 수준 표시 격자로 실제 치수 공차/Ra를 보증할 수 없다. 작은 공구가 닿지 않는 코너 잔삭은 경로 순서 변경으로 해결되지 않는다. 형상 잔삭이 같아도 실제 진동·공구 처짐·마모·열·고정 상태에 따라 표면 품질이 달라진다.

현재 래스터와 마무리 윤곽을 같은 공구로 생성한다. 황삭/정삭 공구 분리, 가공 여유/정삭 패스, 재질별 절삭조건, 강성/장비 제약은 별도 확장이다. 스텝다운·스텝오버·이송을 자동으로 공격적으로 키워 절전이라고 표시하지 않는다.

‘최적’은 전역 최적 해 보장이 아니다. **검토한 후보 중 품질 기준을 유지한 제안**이라고 표시한다. 탐욕 순서 변경은 최적을 보장하지 않으며 기존 후보보다 나쁘면 채택하지 않는다. 일정한 절삭 에너지 모델에서는 같은 제거 부피의 이론 절삭 에너지가 같을 수 있어, 이동 거리 감소를 절삭 전력 감소로 치환하지 않는다.

## 질문과 미정 값

재질·장비·공구·목표 공차/Ra 유무를 사용자에게 질문했다. 답변 전에는 미정으로 다룬다. 첫 단계 품질 지표는 시뮬레이션 잔삭과 공구 경계 여유로 제안한다. 미정 값을 임의 재질/장비의 권장 절삭조건으로 채우지 않는다.

실제 품질·에너지 제안을 원하면 다음 입력이 필요하다: 공차/목표 거칠기, 공구 형상/날수/직경/마모 상태, 소재와 비절삭저항, 회전수/이송 범위, 기계 강성·고정 조건, 공회전/보조/축 전력·효율·장비 부하 상한. 실측으로 보정하기 전까지 예측값이다.

## 제안 UI와 결정 규칙

기존 ‘가공 경로 생성’ 옆에 ‘품질 우선 경로 제안’. 결과는 현재 경로와 후보별 **안전·예상 잔삭·공구 여유·절삭/비절삭 길이·예상 시간·에너지 근거**를 보여준다. 결과 생성만으로 현재 경로를 바꾸지 않고, 사용자가 ‘이 제안 적용’을 누르면 공구/경로와 시뮬레이션을 함께 갱신한다. 입력/모델 변경은 후보를 무효화한다.

1. 안전: 경계 여유·깊이·분리 구간 안전Z 검사 실패 후보 제외. 기존 CNC oracle 재사용.
2. 품질: 같은 절삭 세그먼트/방향·공구·깊이와 마무리 단계 보존 확인. 동일 해상도에서 잔삭 비교. 목표를 만족하는 후보가 없으면 ‘적합 후보 없음’; 공구/정삭 수정 이유를 표시.
3. 소비: 품질 적합 후보 중 기계 정보가 있으면 추정kWh 최저 후보 제안. 정보가 없으면 **품질 유지·비절삭 이동 감소 제안**으로 제한하고 kWh/절감률은 ‘산정 불가’로 표시. 후보 차이가 계산 오차 범위면 동등 표시.
4. 상한: Worker 계산·후보3개·같은 깊이 묶음 최대256스트로크부터 제한, 30초 취소/오래된 응답 무시. 큰 모델은 기존 경로를 유지하고 제안 불가 이유 표시. 수치는 구현 실증 후 조정한다.

| 화면 항목 | 장비 미정 | 장비 정보·실측 보정 이후 |
|---|---|---|
| 품질 | 형상 잔삭 근사·경계 여유, Ra/공차 보증 없음 | 목표 조건/검증 근거, 여전히 실물 확인 필요 |
| 소비 | 절삭/비절삭 길이·시간, 전력 산정 불가 | 추정kWh·추정 최대kW·가정/측정 출처 |
| 제안 근거 | 같은 절삭·마무리를 보존하며 비절삭 이동 축소 | 품질 적합 후보의 추정 소비 에너지 비교 |

## 에너지 모델과 출처

제조사 밀링 공식의 순 절삭동력은 `Pc = ae × ap × vf × kc / (60 × 10^6)` kW다. ae/ap는 mm, vf는 mm/min, kc는 N/mm². [Sandvik Coromant 공식](https://cdn.sandvik.coromant.com/files/sitecollectiondocuments/services/metal-cutting-e-learning/formulas-and-definitions/formulas-and-deinitions-for-milling-metric-enu.pdf).

이는 기계 전체 소비 전력과 다르다. 제안 추정 모델은 `E = ∫(P_idle + Pc/η + P_axis + P_aux) dt / 3600` kWh(전력kW, 시간초). 구성요소를 중복 합산하지 않도록 idle 측정 범위를 정의한다. 칩 두께/접촉이 변하는 구간에 ae/ap를 상수로 잘못 적용하지 않고 소재 제거로 유효 접촉을 추정하거나 산정 불가로 처리한다. 장비 실측 계수가 없으면 기본 kWh 숫자를 만들지 않는다.

마무리의 공구 처짐과 낮은 반경 방향 절삭 깊이 관련 근거: [Sandvik 슬롯 밀링 안내](https://www.sandvik.coromant.com/en-gb/knowledge/milling/groove-or-slot-milling). 이 자료를 사용자 장비의 절삭조건으로 자동 적용하지 않는다.

## 구현 인수 기준

- 안전 실패/목표 미달 후보가 에너지 점수가 좋아도 선택되지 않는 테스트.
- 세그먼트 다중집합·방향·공구·깊이·마무리 보존, 독립 경계 oracle, 전체 제거/잔삭 비교.
- 비절삭 이동/시간 산술을 독립 계산하고 기존 후보보다 나쁜 제안 거부.
- 장비 미정이면 kWh/절감%를 표시하지 않는 UI 시험, 입력 변경의 후보/시뮬레이션 무효화.
- 같은 최종 형상을 다른 순서로 가공한 실물/Ra/공차·계측 에너지 검증은 별도이며 디지털 시험 통과와 구분한다.

DB/FEMS 계측 연동·NC·실기계 자동 제어는 이 초기 범위에 포함하지 않는다. 제품 구현은 다음 CAD 작업으로 이 기준 확인 뒤 진행한다.
