# CAD-14 시간·소비 모델 계약

2026-10-08. CAD-10 권장안/전체 설계 승인 및 이번 CAD-14 구현 승인에 따른 단일 ID. NC/설계/가공 경로는 수정하지 않는다. CAD-15 개선 제안은 미착수.

## 모델 경계

- 장비 전체 전기(kW) 상태 모델 하나만 사용한다. 기본/주축/축/펌프/절삭 항을 추가 합산하는 분해 모델은 이번에 제공하지 않는다. 각 입력은 해당 조건의 전체 장비 전력 min/max이며 base를 다시 더하지 않는다. 명판 정격을 소비 전력으로 취급하지 않는다.
- 소재 분석 완료·동일 NC SHA-256·각 이동 제거량 연결 필수. G0 소재 접촉 후보가 있으면 전력 분석 차단. 과절삭/잔삭은 결과의 제약으로 표시한다. 제거량>0인 이송은 ‘제거 발생’, 나머지는 ‘제거 미검출’이다. 제거0을 비접촉/공중으로 확정하지 않는다. 행 내부 접촉 시간 분해는 없으며 해당 행 전체에 입력한 평균 전력 범위를 적용한다.
- 상태 키는 이동/대기/이벤트 종류 + 주축 방향/rpm + 쿨런트 + 활성 T. 같은 상태만 전력 값을 공유한다. 회전수/공구/쿨런트가 달라지면 별도 입력이며 보간/외삽 없음. 축 방향·이송 F·제거율은 전력 상태 키에 포함하지 않으므로 같은 키의 모든 이동 조건을 포괄하는 평균 전력 범위를 사용자가 입력해야 한다. 세부 부하 추정은 후속 범위다. 이벤트는 전후 상태를 키로 기록한다. 출처는 사용자 가정 또는 사용자 제공 측정값이며 실측 보정/정확도 검증 완료로 승격하지 않는다.
- 이동: 축별 최고 속도(mm/min)/가속도(mm/s²), F(mm/min)로 구간마다 시작/끝 속도0인 삼각/사다리꼴 모델. 직선은 축 방향 비율로 경로 속도/가속도 제한. XY 원호는 X/Y 제한의 최소값, 가속도 절반을 접선/법선에 각각 배정하고 v≤sqrt(a*r/2), 원호의 해석 길이 사용. look-ahead/블렌딩·jerk·override·실기계 급속 궤적 재현 아님. 사용자가 가정/override100% 확인해야 실행한다.
- G4는 NC P초. 주축 시작/정지/회전수·방향 변화, 쿨런트 변화, M6, M2/30은 각 조건별 사용자 이벤트 시간 필요. M6/종료의 주축/쿨런트 변화는 이벤트 시간/전체 전력에 한 번만 포함하며 중복 이벤트로 더하지 않는다. 자동 축 이동/교환/팔레트/정지 시간도 그 입력에 포함한다는 확인 필요. 이동/대기와 S 회전 변화가 같은 행이면 시간 순서를 확정할 수 없어 차단한다. T 선택/상태 설정·주석·no-op 해석 비용은0 가정. NC 시작~종료 범위이며 부팅/준비/프로그램 밖 대기는 제외.
- 입력 칸 빈값은 null(미정). 필요한 속도/가속/이벤트 시간/전력이 하나라도 미정이면 전체 해당 합계는 null. 알려진 구간 소계는 명시적으로만 표시한다. 0초를 명시하면 에너지0, 불필요 전력 입력 없이 가능. 0kW는 사용자가 명시한 가정값으로만 허용한다. 음수/NaN/역전 범위는 오류.
- E_kWh=P_kW*t_s/3600. 구간별 min/max 합계는 입력 범위 시나리오이며 통계적 신뢰구간/오차 보증 아님. 평균 전력 min/max = 에너지×3600/시간. 독립 합계·단위·중복/미정 전파를 시험한다.

## 근거·검증·UI

장비 이름/근거 설명/측정 날짜/적용 조건을 기록한다. 측정값 선택 시 날짜/조건 필수. 별도 검증 운전의 총 시간/kWh를 비교용으로 입력할 수 있고 예상/실측 차이를 표시한다. 보정 계수를 자동 적용하거나 같은 검증 운전을 학습에 재사용하지 않는다. 실제 계측 자료 미제공 상태에서는 합성 시험군만 검증하고 실제 정확도는 미검증으로 남긴다.

상태표 생성→시간/전력 입력→계산. 합성 장비 예제는 명시 버튼으로만 채우고 사용자 입력으로 위장하지 않는다. 평균전력 막대(폭은 시간 비례 아님)/200구간 페이지/구간 행 클릭→NC 원본/경로 선택. 설정·NC·소재/공구/정합 변경은 결과 무효화. JSON에 모델 버전/원문 해시·출처·설정/상태 입력·구간·전체/부분 합계/제약·별도 검증 비교를 포함한다. 고객 파일 서버/DB/외부 AI 전송 없음.

상태200종/50,000행·Worker30초/수동취소/revision·인스턴스 방어. 미지원 NC/이벤트 순서/미정 자료는 그 이유를 표시. 물리 검증·실측 수집/보정·FEMS/DB 연동·NC 출력/경로 개선은 별도 단계.

근거: [LinuxCNC G-code](https://linuxcnc.org/docs/html/gcode/g-code.html), [M-code](https://linuxcnc.org/docs/html/gcode/m-code.html), [NIST 기계 에너지 예측](https://www.nist.gov/publications/towards-generalized-energy-prediction-model-machine-tools). 장비 자동 이벤트/실제 가감속은 NC 리터럴만으로 확정할 수 없다.
