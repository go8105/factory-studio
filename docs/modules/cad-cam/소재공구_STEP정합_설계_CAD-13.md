# CAD-13 소재·공구·STEP 정합 계약

2026-10-07. CAD-10 권장안 및 이번 다음 단계 승인 범위. CAD-14 전력 계산은 착수하지 않는다.

- NC는 기존 LinuxCNC 제한 프로필, G54 공구 끝점 좌표다. 활성 T와 사용자 공구표를 연결한다. 시작 시 활성 T 미정인 구간은 별도 초기 T 입력으로만 연결한다. H/D 번호는 공구표의 참조 정보이며 G43/H·G41/42/D 보정 계산은 계속 차단한다. 길이 보정이 적용된 실제 NC는 범위 밖이다.
- 직육면체 소재의 최소 XYZ·크기 XYZ(mm), 소재 이름(자유 기록), 평엔드밀 지름·날 길이(mm)를 입력한다. 재질로 절삭력/전력을 자동 추정하지 않는다. 회전 중 이송만 제거하며 플런지·수평 이송을 지원한다. 기울어진 직선은 차단. 홀더·지그·기계/교환 자동 이동은 분석하지 않는다.
- STEP은 OCCT의 실제 importSTEP으로 읽고 단일 Solid 여부/체적/메시를 검증한다. 내부 단위는 OCCT가 STEP 단위를 mm로 변환한 결과다. 사용자 배율 추측 없음. STEP→G54는 Z축 회전 후 XYZ 평행 이동이며 NC는 변환하지 않는다. 파일·치수·좌표를 사용자가 확인하기 전 비교 차단. 설정을 바꾸면 정합 확인/이전 결과 무효화한다.
- 형상 비교는 수평/수직 면으로 된 단일 상면 형상만 지원한다. 격자별 Z 교차가 0 또는 소재 바닥부터 시작하는 한 구간이어야 한다. 경사/곡면·떠 있는 부품·중공/다층은 차단. 격자보다 작은 특징은 놓칠 수 있으므로 사용자의 상면 형상 확인도 필수다. 범용 STEP/3D 충돌 판정으로 표시하지 않는다.
- 셀 중심의 높이장: 소재 높이에서 시작해 원통 평엔드밀의 프로그램 경로로 최저 높이를 갱신한다. 원호는 CAD-12 표시점(현오차 최대0.05mm)의 근사다. 급속은 갱신 없이 현재 소재와 접촉 후보 행을 기록한다. 격자별 목표 높이와 비교해 제거/잔삭/과절삭 체적 및 최대 깊이를 계산한다. 공차는 0.1mm 고정(물리적 품질 공차 아님), 셀 면적 적분 근사다. 접촉/과절삭 0은 안전 보증이 아니다.
- STEP10MiB·메시20,000삼각형·격자40,000셀·삼각형×셀20,000,000회·경로×셀 검사5,000,000회·Worker30초. 실패/부분 NC/공구 누락/정합 미확인은 결과 없음. 입력 변경/새 파일/취소는 revision+terminate로 응답을 무효화한다.
- 소스 파일·해시·공구/소재/변환·격자·결과를 분석 JSON에 포함한다(STEP 원본은 미포함, 이름/해시/체적/경계만). 서버/DB/저장소 전송 없음. 에너지/전체 시간은 계속 미정.

근거: [replicad 실제 importer](https://github.com/sgenoud/replicad/blob/main/packages/replicad/src/importers.ts), 설치된1.1.0 구현과 [LinuxCNC G-code](https://linuxcnc.org/docs/html/gcode/g-code.html). H는 공구 길이 보정 참조, D는 직경 보정 참조로서 T와 무조건 같다고 간주하지 않는다.

검증: 실제 BRep STEP roundtrip 및 단위·정합, 독립 박스 체적/제거/잔삭/과절삭/급속 접촉 oracle, 무지원 조건/자원 상한·입력 변경, 실제 웹 STEP 읽기와 겹쳐보기·비교 차단/실행을 확인한다. 결과는 별도 보고서에 실제 실행만 기록한다.
