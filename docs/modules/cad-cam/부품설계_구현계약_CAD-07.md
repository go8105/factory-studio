# CAD-07 / E2 부품 설계 구현 계약

2026-10-06 사용자가 E1 결과를 확인하고 E2 진행을 명시했다. 기존 전체 고도화 방향 승인과 이번 E2 구현 지시를 적용한다. 새 업무DB·비누 심화·조립(E3)은 범위 밖이다.

## 기획 의도 검토

기존 자유 스케치와 상면 CAM을 유지하고 별도의 ‘3D 부품 설계’ 작업 화면을 연결한다. XY/XZ/YZ의 기준 평면과 선행 피처의 바깥 평면을 기준으로 돌출·파내기/측면 구멍을 쌓는다. 선행 치수 수정은 뒤 피처를 재계산하며 실패 위치와 직전 정상 부품을 보존한다.

## 예상 문제점/제약

Manifold 평면 offset만으로 실제 3D 필렛/쉘을 구현할 수 없다. replicad1.1.0(MIT)+replicad-opencascadejs1.1.0(LGPL2.1)의 OCCT single-thread WASM을 별도 Worker에서 사용한다. Node 초기화 약128ms, WASM 약23MB는 최초 실증이며 브라우저 성능 보증이 아니다. 배포에 라이선스/소스 위치·교체 방법을 함께 포함한다.

영구 face/edge 번호에 의존하지 않고 피처 ID+기준 XY/XZ/YZ 평면+법선 방향 거리로 참조한다. 형상이 변해 해당 평면의 면/모서리가 사라지면 실패 처리한다. 임의 곡면 작업면과 선택한 모서리의 위상 추적은 이번에 구현하지 않는다.

E2 모델은 단일 연결 솔리드다. 떨어진 보스·부품을 나누는 절삭을 거부한다. 기존 CAM은 E1 평면 소재 전용으로 유지한다. E2 3D 부품은 자동 가공 경로를 만들지 않으며 3D/측면 가공은 E5다.

## 확정 구현 계약

- 다중 돌출/파내기, 원을 이용한 측면 구멍, XY/XZ/YZ 작업면·선행 평면 참조, 스케치 회전, 선행 add/cut 피처의 직선/원형 배열·미러.
- 실제 OCCT 필렛(전체 또는 지정 기준 평면의 모서리), 쉘(지정 기준 평면의 면 제거·안쪽 벽 두께). 실패는 성공으로 표시하지 않는다.
- 자유 윤곽 원본의 수평/수직/일치/길이/원호 반경/점 고정 구속과 모순 진단. 수치 해석은 지원하는 점/3점 원호에 한정하며 Fusion 수준의 완전 구속 해석기는 아니다.
- JSON v3 원본 모델(base/operations/스케치/구속/참조 ID), v1/v2를 가져와 base/cut 원본으로 변환. E1 브라우저 저장을 덮어쓰지 않고 별도 v3 공간별 키. 피처 최대32·스케치64점·배열16개·총 인스턴스128개·파일250KB.
- candidate를 Worker에서 전부 재계산/검증한 뒤에만 모델·자동 저장·undo 이력을 확정한다. 실패 시 마지막 정상 모델/표시를 유지하고 실패 ID·뒤 피처 미계산을 알린다. 오래된 응답 폐기, 취소/시간 제한 시 Worker 종료.
- 표시 메시와 원본 분리, JSON·STL 보관. STEP 산출물은 보조 기능으로 가능하면 검증하되 E4 제작 완료나 외부 STEP 이력 복원으로 표시하지 않는다.
- CNC 브래킷·쉘 예제 파일을 examples에 버전/날짜/이름으로 보관. 비누 연구노트에 실물 성능 기록을 새로 만들지 않는다.

## 검증 기준

OCCT 실제 부피/솔리드 유효성·측면 구멍·배열/미러·필렛/쉘, 선행 치수 수정/참조 삭제/과대 필렛 실패, 구속 성공/모순, JSON v1/v2/v3 왕복, 브라우저 편집·취소·마지막 정상 형상 보존, frontend 단독 의존성 빌드/자산 분리. DB·실물·기계 NC·연속 충돌은 미실행으로 기록한다.
