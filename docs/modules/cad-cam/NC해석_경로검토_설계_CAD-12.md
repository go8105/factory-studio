# CAD-12 NC 해석·3D 경로 검토 계약

2026-10-07 · 사용자 다음 단계 승인 · 3축 밀링/G-code 우선

## 범위

CAD-10 승인된 권장안의 CAD-12만 구현한다. LinuxCNC 문법에 근거한 제한 프로필 `linuxcnc-mill-subset-v1`을 명시한다. 실제 컨트롤러 호환 보증·NC 수정/실행/출력·CAD 이력 복원·소재 제거/충돌·전체 시간/kWh는 제공하지 않는다. 기존 E1/E2와 별도 NC 검토 화면이며 파일은 브라우저 메모리에서만 읽는다. 서버 업로드·로그·자동 영구 저장 없음.

## 지원과 초기 상태

- G0/G1 XYZ 직선, G17 G2/G3 XY 단일 원호: I/J 증분 중심 또는 부호 있는 R, I/J 전체 원. G20/21 단위·G90/91 절대/증분·G91.1·G94·G54·G40/G49·G80(모션 취소), G4 P초. F/S/T, M3/4/5, M6, M7/8/9, M2/30. 숫자 리터럴·행 번호 N·프로그램 번호 O·괄호/세미콜론 주석·단독 % 구분자를 지원한다.
- 초기 XYZ는 사용자 확인 필수, 선택 단위로 입력 후 내부 mm로 통일. G54 작업좌표로 표시하며 기계좌표 변환 없음. 초기 G17/G90/G91.1/G94/G0, 보정 해제·주축/쿨런트 OFF, 활성 공구 미정은 프로필 기본 가정으로 노출한다. F는 프로그램에서 선언해야 한다.
- G18/19·헬릭스/다회전·G90.1·G43/H·G41/42/D·G28/G53·G55이상·고정 사이클·G93/95·회전축·매크로/식·서브프로그램·M0/1·사용자 코드·선택 블록은 미지원. 중복 주소·모달 그룹 충돌·원호 불일치·비정상 숫자/문자도 오류다.
- M6는 주축 정지·공구 교환 이벤트를 표시한다. 기계 자동 이동/교환 시간은 알 수 없다. M6/M30의 기계 자동 동작은 machineMotionUnknown으로 기록한다. M2/30 또는 닫는 % 이후는 실행 제외로 표시한다. M 이벤트는 행당 하나, 대기/이동과 별도이며 종료는 단독 행만 지원한다. 지원 범위 해석 완료는 장비 전체 동작 재현 완료를 뜻하지 않는다.

## 모델·중단·뷰어

원본 행/번호, 해석 전후 상태, mm 이동 시작/끝, F/S/T/활성 공구/주축/쿨런트, 원호 중심/방향/각도/반경·해석 길이, 이벤트, 진단을 연결한다. 파일 SHA-256와 설정·프로필을 결과에 기록한다. 원호 표시만 현 오차 목표0.05mm 및 최대5도 분할; 길이는 원호 해석식으로 구한다.

첫 오류 행은 전체 미완료, 이후 행은 미해석이다. 오류 행은 상태/이동/이벤트를 확정하지 않는다. 이전 구간만 부분 경로로 표시하며 이후를 연결하지 않는다. 치명 오류·자원 상한은 이유를 보여준다. 첫 실행 이후 입력/설정 변경은 결과와 선택을 즉시 무효화한다. 새 실행·취소·시간 만료는 Worker 종료·revision/인스턴스 검사로 늦은 결과를 거부한다.

코드 행 선택→경로 강조/상태, 3D 경로 클릭→원본 행 선택, 이동 슬라이더/이전·다음→같은 선택으로 연결한다. 급속/이송 색과 범례를 구분하되 G1을 절삭으로 표시하지 않는다. 전체 보기와 초기 설정·지원 명령 도움말·합성 예제·분석 JSON 다운로드를 제공한다. 코드 목록은 최대200행 페이지로 표시한다.

## 상한과 검증

후보 상한2MiB UTF-8/50,000원본행/500,000표시점/30초. 숫자는 유한·좌표 절대1,000,000mm 이하, 원호 원점 오차0.005mm 이하로 보수적으로 거부한다. 합성1천/1만/5만행 측정·실제 Worker 취소·원호 수학 oracle·부분 해석 차단·UI 동기 선택·모바일 폭을 확인한 뒤 적용한다. 메모리/시간 계측값은 환경과 범위를 기록하며 모든 장비의 성능 보증으로 쓰지 않는다.

DB 변경 없음. [LinuxCNC G 코드](https://linuxcnc.org/docs/html/gcode/g-code.html)·[문법](https://linuxcnc.org/docs/html/gcode/overview.html)·[M 코드](https://linuxcnc.org/docs/html/gcode/m-code.html)를 기준으로 한다. CAD-13은 소재·공구·원점/목표 STEP 정합, CAD-14 소비 모델, CAD-15 품질1/소비2 제안이며 이번에 자동 착수하지 않는다.
