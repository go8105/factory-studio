# CAD-V03 YC 음성 요청 중심 준비 흐름 (2026-10-13)

사용자의 기존 승인 CAD-V02 흐름 보정 요청: Step4 비교만으로 팝업을 열지 않고 YC 호출·최적안 요청 후 표시한다. 예제 버튼에서 음성을 켜고 합성 조건을 준비한다. 번호 요청은 기존 검증/뷰어를 유지한다.

- Step4 비교는 결과 계산만, YC 음성/제안 버튼에서 present 옵션으로 정지 카드 표시.
- YC 발표 예제 클릭의 사용자 동작 안에서 마이크 시작·권한 요청. NC해석→STEP→합성 정합/상면→소재→합성 장비→에너지→합성 품질 대기 조건만 준비. 제안/재생 자동 시작 없음.
- 실제 업로드 파일은 기존 NC·STEP·정합/장비/품질 조건 수동 확인 유지. 안전 판정·실측·실장비 실행 아님. 일반 파일의 후보 수를 강제3으로 만들지 않음.
- 준비 상태·실패·재시도, 사용자 파일/설정 변경·탭 숨김 시 순서 중단. 세대 번호로 이전 비동기 순서가 다음 입력을 덮지 못하도록 보호.
- 기존 호출어 전환 별칭 유지하되 기본 표시/대기는 YC·헤이 와이씨. 기존 로컬 antigravity 브랜치의 휴디 코드와 최신 main을 구분.
