## 0. SCM의 자리 — 실행이 아니라 계획·분석

판매계획 확정·생산계획·발주·재고는 이미 ERP·MES·WMS가 **실행**한다. SCM이 그 일을 다시 하면 두 벌이 된다. 그래서 **SCM = 여러 솔루션 실적을 읽어 수요 예측·수급 균형(S&OP)·재고 정책·공급처 성과를 계산하고, 결과를 실행 솔루션이 가져가게 하는 계획·분석 솔루션**으로 둔다(Q1).

| 영역 | 소유 | SCM과의 관계 |
|---|---|---|
| 수요 예측·S&OP 계획·재고 정책 산정·공급처 성과 | **SCM** | 이 문서 |
| 판매계획(확정) | **ERP** | 확정 예측을 ERP가 가져가 판매계획 초안(Q3) |
| 생산계획·자재 소요 | **MES** | S&OP 생산량을 MES가 참고, SCM은 MES 능력·계획을 읽음 |
| 안전·최대 재고 값 | **WMS** | SCM이 산정·제안, WMS가 가져가 반영(Q5) |
| 공급처 품질 등급 | **QMS** | SCM은 읽어 공급처 종합 평가에 사용 |

## 7. 결정 질문 (하나씩)

| # | 질문 | 제안 |
|---|---|---|
| Q1 | **SCM 경계** — SCM은 계획·분석만(예측·S&OP·재고 정책·공급처 성과), 실행(판매계획 확정·생산계획·발주·재고 값)은 ERP·MES·WMS가 SCM 결과를 "SCM에서 가져오기"로 반영 | 그대로 |
| Q2 | **예측 방법** — 이동평균(3개월)·단순 지수평활·계절 지수(12개월 이상 이력) 3가지를 계산해 오차가 가장 작은 방법을 기본 추천, 사람이 방법·값을 조정 | 그대로 |
| Q3 | **예측 → ERP** — 월 예측 확정(버전) → ERP가 "SCM에서 가져오기"로 판매계획 초안. CRM 파이프라인 가중 금액은 조정 화면에 참고로만 | 그대로 |
| Q4 | **S&OP·개략 생산 능력** 포함(월 수요 vs MES 능력 vs 재고 목표, 부족·과잉 경고) | 포함 |
| Q5 | **재고 정책 산정 → WMS 제안** 포함(안전재고 = z × 수요 표준편차 × √리드타임, 재주문점 = 리드타임 수요 + 안전재고) | 포함 |
| Q6 | **공급처 성과** 포함(납기 준수·리드타임 실적 + QMS 품질 등급 → 종합 점수) | 포함 |
| Q7 | 범위 확정 — 포함 12 + Q 6, 제외 4(머신러닝 예측·APS·협업 포털·네트워크 설계) | 제안대로 |
