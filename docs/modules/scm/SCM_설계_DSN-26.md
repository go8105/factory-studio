## 0. SCM의 자리 — 실행이 아니라 계획·분석

판매계획 확정·생산계획·발주·재고는 이미 ERP·MES·WMS가 **실행**한다. SCM이 그 일을 다시 하면 두 벌이 된다. 그래서 **SCM = 여러 솔루션 실적을 읽어 수요 예측·수급 균형(S&OP)·재고 정책·공급처 성과를 계산하고, 결과를 실행 솔루션이 가져가게 하는 계획·분석 솔루션**으로 둔다(Q1).

| 영역 | 소유 | SCM과의 관계 |
|---|---|---|
| 수요 예측·S&OP 계획·재고 정책 산정·공급처 성과 | **SCM** | 이 문서 |
| 판매계획(확정) | **ERP** | 확정 예측을 ERP가 가져가 판매계획 초안(Q3) |
| 생산계획·자재 소요 | **MES** | S&OP 생산량을 MES가 참고, SCM은 MES 능력·계획을 읽음 |
| 안전·최대 재고 값 | **WMS** | SCM이 산정·제안, WMS가 가져가 반영(Q5) |
| 공급처 품질 등급 | **QMS** | SCM은 읽어 공급처 종합 평가에 사용 |

## 3. 기능 규칙 (범위 18)

공통: **SCM은 계획·분석만** — 실행 솔루션 실적을 읽어 계산하고, 결과는 ERP·MES·WMS가 "SCM에서 가져오기"로 반영한다(Q1). 예측·S&OP는 "확정 1건 + 새 버전", 재고 정책은 품목당 제안 1건.

| 묶음 | 기능 ID | 규칙 |
|---|---|---|
| 기준 | F01~F04 | 계획 품목(계획 대상·예측 방법 AUTO/지정·서비스 수준·리드타임·최소 주문량·주문 단위), 공급처 품목(우선순위·할당 비율 합 100·계약 리드타임·적용일), 월 버킷·12개월 수평선 |
| 수요 (Q2) | F11~F15 | 수요 이력 = ERP 확정 출하(반품 차감) 월 집계 스냅샷(다시 가져오면 갱신). 이동평균(3개월)·단순 지수평활(α 0.3)·계절 지수(12개월 이상) 계산 → 최근 6개월 MAPE 최소 방법 추천. 조정은 사유 필수. 정확도 = 확정 예측 vs 이후 실적(MAPE·편향) |
| 확정 → ERP (Q3) | F14 | 기준 월 예측 확정(불변) → ERP "SCM에서 가져오기" → 판매계획 초안. CRM 파이프라인 가중 금액은 조정 화면에 참고로만 |
| S&OP (Q4) | F21~F23 | 품목·월: 수요(확정 예측) · 생산 능력(MES 설비 × 근무조 시간 ÷ 표준 사이클, 휴일은 core 달력) · 계획 생산 · 재고 목표 일수 · 예상 기말 재고. 생산 > 능력 = 부족, 예상 재고 > 목표 × 1.5 = 과잉. 확정 S&OP를 MES가 생산계획 참고로 읽음 |
| 재고 정책 (Q5) | F31·F32 | 안전재고 = z × 월 수요 표준편차 × √(리드타임/30), 재주문점 = 월평균 수요 × 리드타임/30 + 안전재고. 품목당 제안 1건 → WMS가 가져가 안전재고 반영 |
| 공급처 (Q6) | F33 | 월 납기 준수율(WMS 입고일 ≤ ERP 발주 납기)·평균 리드타임 + QMS 품질 등급 → 종합 점수(납기 50·리드타임 20·품질 30) → A~D |
| 가시성 | F34·F41·F42 | 결품 위험 = 예상 재고 < 안전재고가 되는 첫 달(조회 계산). 대시보드(재고 일수·납기 준수·결품 위험·예측 정확도). 품목 수급 현황(수요·공급·재고 월 시계열) |

## 6. 교차 조회

**SCM이 읽는 것**

| 제공 | 함수 | SCM 용도 |
|---|---|---|
| ERP | `shipments_monthly(from, to)`(신규) · `purchase_orders(open=False)`(DSN-11) · `partners()` | 수요 이력, 공급처 납기 |
| WMS | `stock_on_hand(items)` · `receipts(period)`(DSN-13) | 예상 재고, 입고일 |
| MES | `capacity(month)`(신규: 설비·표준 사이클·근무조) · `production_plan(month)`(신규) | S&OP 능력·계획 |
| QMS | `supplier_grades(month)`(DSN-14) | 공급처 품질 등급 |
| CRM | `pipeline_summary(month)`(DSN-25) | 예측 조정 참고 |
| core | `holidays(from, to)` | 근무일 |

**SCM이 제공하는 것**

| 함수 | 돌려주는 것 | 쓰는 곳 |
|---|---|---|
| `demand_forecast(month)` | 확정 예측(품목·월·수량) | ERP 판매계획 초안(Q3) |
| `sop_plan(month)` | 확정 S&OP 계획 생산 | MES 생산계획 참고 |
| `inventory_policies()` | 제안 안전재고·재주문점 | WMS 안전재고 반영(Q5) |
| `supplier_scores(month)` | 공급처 종합 등급 | ERP 구매·QMS 참고 |
| `monthly_summary(month)` | 예측 정확도·재고 일수·납기 준수 | EIP |

> 넘길 것: **ERP** "SCM에서 가져오기"(판매계획 초안), `shipments_monthly` 제공 · **MES** `capacity`·`production_plan` 제공, 확정 S&OP 참고 · **WMS** `inventory_policies` 가져오기 → 품목 안전재고.

## 7. 결정 질문 (하나씩)

| # | 질문 | 제안 |
|---|---|---|
| Q1 | **SCM 경계** — SCM은 계획·분석만(예측·S&OP·재고 정책·공급처 성과), 실행(판매계획 확정·생산계획·발주·재고 값)은 ERP·MES·WMS가 SCM 결과를 "SCM에서 가져오기"로 반영 | 그대로 |
