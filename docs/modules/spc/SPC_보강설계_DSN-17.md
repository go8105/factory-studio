# DSN-17 SPC 보강 설계

작성: 2026-10-05 (Claude Code) · 상태: **설계 완료(2026-10-05) — 사용자 확인 대기.** 1단계(기준표·Q1~Q7 확정) + 2단계(3장 기능 규칙 · 4장 DB 10테이블 · 5장 화면 11 · 6장 교차 조회).
양식: [DSN-00](../../plan/기능기준표_DSN-00.md) · 방침: [ROADMAP-02](../../plan/전체설계우선_전환_ROADMAP-02.md) · 기존 설계: [FS-028 결정서](../../plan/SPC도입_관리도_결정_FS-028.md)(D37~D44)
기준 참고: KS Q ISO 7870-2(슈하트 관리도), Nelson 판정 규칙 8개, AIAG SPC 매뉴얼(Pp/Ppk·OCAP).

## 0. 지금 SPC와 경계

**지금(5테이블·7화면)**: 관리 특성(품목·공정·규격) · **부분군 n=5 고정 · X̄-R 관리도만** · 관리 한계(처음 20개로 게시, 재산정은 새 버전) · 판정 규칙 1~3 · 이상 → 조치(4M1E+측정) · Cp/Cpk(조회 계산) · QMS·CMMS에 이상 신호 제공(배지·전환 대기).

| 영역 | 소유 | SPC와의 관계 |
|---|---|---|
| 측정값·관리 특성·관리 한계·이상 | **SPC**(D38) | 이 문서 |
| 공정 실행·생산 실적(검사 수량·불량 수) | **MES** | SPC가 조회로 읽음(계수형 관리도 Q2) |

| 계측기·교정 | **QMS** | SPC 측정에 사용 계측기 기록(QMS 대장 코드) |

## 3. 기능 규칙 (범위 24 중 신규·보강 15)

공통: 측정값·특성·한계·이상은 SPC 소유(D38). 관리도 계수(A2·D3·D4·d2·E2, n=1~10)는 코드 상수. 게시한 한계 불변, 재산정은 새 버전(D40). 능력 지표는 조회 때 계산하고 보고서만 스냅샷.

| 묶음 | 기능 ID | 규칙 |
|---|---|---|
| 관리도 (Q1) | F03·F04 | 특성마다 관리도 종류. n=1 → I-MR(I = 개별값, MR = 이웃 차이, σ̂ = MR̄/1.128), n=2~10 → X̄-R(σ̂ = R̄/d2). 한계 = 처음 20개(I-MR은 20점) |
| 계수형 (Q2) | F05 | p(불량률)·np(불량 수)·c(결점 수)·u(단위당 결점). 부분군 = MES 확정 실적을 LOT·일별로 읽어(검사 수 = 투입, 불량 수) 생성하거나 수동. 한계는 중심값만 저장하고 부분군 검사 수마다 계산(p: p̄ ± 3√(p̄(1−p̄)/n)) |
| 판정 (Q3) | F21~F23 | Nelson 1~8. 특성별 사용 규칙 선택(없으면 1~3). 2~8은 위치 관리도(X̄·I·p·np·c·u)에만, 계수형은 1~4만 |
| 규격 이탈 (Q4) | F24·F33 | 측정값별 LSL·USL 비교 → 측정값당 이탈 1건(관리 이탈과 별개). QMS가 읽어 부적합 보고 후보(발생처 공정). 부분군 무효화 시 함께 무효 |
| 데이터 | F07·F14 | 부분군에 사용 계측기(QMS 대장 코드), 교정 만료면 경고. CSV 올리기(행 검증 후 부분군 생성, 출처 FILE) |
| OCAP (Q5) | F32 | 점검 항목(특성·규칙별 또는 공통, 순서·원인 분류). 이상 조치 전에 해당 항목 모두 OK/NG/NA 기록, NG 항목의 원인 분류를 조치 원인으로 제안 |
| 분석·보고 (Q6) | F42~F46 | Pp·Ppk = 전체 표준편차 기준. 정규성: 왜도·첨도 + 히스토그램. 월별 Cpk 추이. 층별 비교(설비·LOT·작업자별 X̄·Cpk). 보고서 = 특성·기간 확정 스냅샷(부분군 20개 이상, 인쇄) |

## 6. 교차 조회

**SPC가 읽는 것**

| 제공 | 함수 | SPC 용도 |
|---|---|---|
| MES | 기존 `operation_runs` · `production_results`/`defects`(DSN-12·14 요청) | F13, F05 계수형 부분군 |

**SPC가 제공하는 것** (지금 2개 + 추가)

| 함수 | 돌려주는 것 | 쓰는 곳 |
|---|---|---|
| `spec_violations(since)` | 규격 이탈(LOT·특성·값·방향) | QMS 부적합 보고 후보(Q4) |

| 기존 `open_signal_lot_nos`·`equipment_signals` | 그대로 | QMS 배지·CMMS |
