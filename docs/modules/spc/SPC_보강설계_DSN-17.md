작성: 2026-10-05 (Claude Code) · 상태: **1단계 — 기준표·갭 요약·결정 질문(범위 확인 대기)**. 3~6장은 범위 확정 뒤.
양식: [DSN-00](../../plan/기능기준표_DSN-00.md) · 방침: [ROADMAP-02](../../plan/전체설계우선_전환_ROADMAP-02.md) · 기존 설계: [FS-028 결정서](../../plan/SPC도입_관리도_결정_FS-028.md)(D37~D44)

## 0. 지금 SPC와 경계

**지금(5테이블·7화면)**: 관리 특성(품목·공정·규격) · **부분군 n=5 고정 · X̄-R 관리도만** · 관리 한계(처음 20개로 게시, 재산정은 새 버전) · 판정 규칙 1~3 · 이상 → 조치(4M1E+측정) · Cp/Cpk(조회 계산) · QMS·CMMS에 이상 신호 제공(배지·전환 대기).

| 영역 | 소유 | SPC와의 관계 |
|---|---|---|
| 측정값·관리 특성·관리 한계·이상 | **SPC**(D38) | 이 문서 |
| 공정 실행·생산 실적(검사 수량·불량 수) | **MES** | SPC가 조회로 읽음(계수형 관리도 Q2) |
| 공정 검사(초·중·종물) | **MES**(MES Q5) | 별개 — 관리도용 측정은 SPC |
| 부적합 보고·시정조치 | **QMS** | 규격 이탈은 QMS 부적합 보고 후보(Q4) |
| 계측기·교정 | **QMS** | SPC 측정에 사용 계측기 기록(QMS 대장 코드) |
| 설비 원인 이상 → 보전 | **CMMS** | 이미 설계됨(CMMS D48) |

## 7. 결정 질문 (하나씩)

| # | 질문 | 제안 |
|---|---|---|
| Q1 | **계량형 관리도 범위** — 부분군 n=1(I-MR)·n=2~10(X̄-R)을 특성마다 지정, 계수(A2·D3·D4·d2·E2)는 코드 상수표. X̄-S는 제외 | 그대로 |
| Q2 | **계수형 관리도(p·np·c·u)** — MES 확정 실적(검사 수 = 투입, 불량 수)을 조회로 읽어 LOT·일별 부분군 생성. 수동 입력도 허용 | 포함 |
| Q3 | **판정 규칙** — Nelson 8개 전체를 두고 특성별로 사용 규칙 선택(기본 1~3 = 지금과 같음) | 그대로 |
| Q4 | **규격 이탈** — 개별 측정값이 LSL·USL 밖이면 규격 이탈 기록(관리 이탈 이상과 별도), QMS가 읽어 부적합 보고(발생처 공정) 후보로 | 그대로 |
| Q5 | **OCAP** — 규칙·특성별 표준 점검 항목, 조치할 때 점검 결과 기록 | 포함 |
| Q6 | **분석·보고** — Pp/Ppk·정규성 지표·월별 Cpk 추이·층별 비교·공정능력 보고서(확정 스냅샷) | 포함 |
| Q7 | 범위 확정 — 포함 24, 제외 3(X̄-S·장비 자동 수집·다변량/EWMA/CUSUM) | 제안대로 |
