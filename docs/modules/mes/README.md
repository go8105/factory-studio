# MES — 생산 관리

- 상태: **구현 대상**
- 업무 범위: 공정·공정설비, 표준경로, 생산계획, 작업지시·LOT, 공정 실행·실적, 패킹·완제품 입고
- 이 폴더의 문서: MES참조설계_검토_FS-003.md, 첫업무카드_역할_범위_FS-003.md

## 메모

- 작업장·설비·품목은 core가 소유한다. MES 화면에서는 참조로 표시한다.
- 모듈 공통 설계서 없음. 원본 MES 참조 분석과 첫 업무 카드만 있다.

## 규칙

이 폴더에 모듈 공통 설계서가 없으면 해당 모듈은 개발 착수 대상이 아니다.
설계를 먼저 확정하고 사용자 확인을 받은 뒤 구현에 들어간다.

공통 기준정보(품목·설비·작업장 등)는 core가 소유한다. 모듈별로 복제하지 않는다.

전체 현황은 [현재 기획과 진행 현황](../../plan/현재기획_진행현황.md)을 본다.
