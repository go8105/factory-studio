## 0. 지금 MES와 경계

**지금(21테이블·15화면)**: 사업장·공간·설비·품목(코드·이름·단위·구분 4항목)·공정·경로·BOM → 생산계획 → 작업지시 → LOT → 공정 실행·실적(불량 사유는 자유 입력) → 자재 투입(BOM 기준, 자재 LOT은 MES 생산 LOT만) → 박스·팔레트 패킹 → 완제품 입고. **바코드·라벨·스캔은 없다.**

| 영역 | 소유 | MES와의 관계 |
|---|---|---|
| 재고(창고·로케이션·LOT 수량) | **WMS**(FS-024 D13) | MES는 현장 사건(투입·비계획 출고/반납·폐기·완제품 입고)을 **기록**하고 WMS가 읽어 재고에 반영한다. 지금 `completed_material_issues`·`finished_goods_receipts`와 같은 방식 |
| 구매 자재 LOT 번호 | **WMS**(입고 때 부여) | MES 자재 투입이 WMS LOT 번호를 **스냅샷 문자열**로 받는다(FK 없음) |
| 출하 검사·검사 기준·보류 | **QMS** | MES는 보류 배지만(있음). 공정 중 검사는 Q5 |
| 설비 보전·고장 작업지시 | **CMMS** | MES는 "보전 중" 배지(CMMS 설계 D52). 비가동 기록은 MES(Q6) |
| 현장 단말 화면 | **POP**(예정, ROADMAP-01 §6-1) | **바코드 스캔 화면을 어디에 두는지가 Q1** |
| 외주비·원가 | **ERP**(DSN-11 F34·F36) | MES가 외주 실적·생산 수량을 조회 함수로 제공 |
| 작업자 인사 정보 | **HR**(D79) | MES 작업자 코드는 자체 마스터, HR 사원 코드는 스냅샷 |
