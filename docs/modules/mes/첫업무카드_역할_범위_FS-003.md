# FS-003 첫 업무 카드·역할·범위

작성일: 2026-09-20
상태: 업무 요구사항 정의 완료, 사용자 확인 대기. 실제 기능·DB 구현 완료 아님.
출처: 사용자 제공 MES 기초 설계, 승인된 플랫폼 기획. 아래 사업장·공정·수량은 이번 프로젝트의 가상 설계 가정이며 실제 회사 공정이 아니다.

## 업무 카드 MES-001
업무명: 작업지시를 받아 LOT 한 건을 생산하고 양품·불량 실적을 확정한다.
목적: 계획, LOT, 공정 실행, 생산 결과를 구분하고 누가 어떤 설비에서 언제 처리했는지 추적한다. 후속 에너지 분석에 필요한 생산 시간과 설비·수량을 제공한다.

수행자: 개인 공간의 학습자가 계획 담당과 생산 작업자의 역할을 차례로 체험한다. 역할 체험용 표시와 실제 서버 접근 권한은 별개다.
시작 조건: 로그인, 본인 체험 공간/활성 세대, MES 활성, 품목·공정 경로·설비가 준비되어 있다.
필요 입력: 품목, 기준단위, 계획 수량, 적용 경로 버전, 계획일, 공정별 설비, 실행 시작/종료, 양품/불량 및 불량 사유.
산출물: 확정된 작업지시/LOT/공정 실행/실적, 업무 변경 이력, 학습 검증용 결과 요약.
다음 업무: FEMS 생산 연계 분석. QMS 정식 판정과 WMS 완제품 입고는 후속 공개에서 연결한다. MES 완료는 재고 입고 완료와 다르다.

## 가상 실습 기준정보
- 사업장: 한빛 패키징, Line A.
- 품목: QFN-48 학습용 제품, 기준단위 EA. 첫 과정은 정수 개수만 허용한다.
- 작업지시: WO-DEMO-001, 계획 1,000 EA, LOT-DEMO-001.
- 경로: 다이 접착 → 와이어 본딩 → 최종 검사. 실제 반도체 후공정 전체를 구현하는 것이 아니라 세 단계로 단순화한 학습 경로다.
- 설비: DA-01, WB-01, FT-01. 작업장과 실제 설비는 구분한다.
- 첫 실습은 1지시/1LOT, 직렬 공정, 분할/병합/재작업 없음. 불량은 이후 공정으로 재투입하지 않는다.

## 정상 업무 흐름
| 순서 | 사용자 행동 | 필요한 안내 | 남는 결과 |
|---|---|---|---|
| 1 | 품목·경로·설비·단위를 확인 | 각 기준정보가 왜 필요한가 | 준비사항 확인 |
| 2 | 계획 수량을 넣어 지시를 등록하고 발행 | 등록과 현장 실행 허용의 차이 | 발행된 작업지시, 고정 경로 버전 |
| 3 | LOT 생성 | 작업지시와 생산 묶음의 차이 | LOT와 작업지시 연결 |
| 4 | 첫 공정 설비를 선택해 시작 | 시각·설비가 추적과 에너지 분석에 쓰임 | 진행 중 공정 실행 |
| 5 | 양품·불량·사유를 입력하고 완료 | 투입·산출·양품·불량 구분 | 검증된 확정 실적 |
| 6 | 직전 양품을 다음 공정에 투입해 반복 | 불량을 다음 투입에 포함하지 않는 이유 | 순차 공정 이력 |
| 7 | 마지막 공정 결과로 LOT/지시 완료 | 공정 합계와 최종 제품 수량 구분 | 최종 양품·누적 불량·시간 |
| 8 | 결과를 해석하고 다음 학습 확인 | 생산량과 에너지 원단위 연결 | 업무 근거 기반 학습 결과 |

## 수량 기준 예시
| 공정 | 투입 | 양품 | 불량 | 다음 투입 |
|---|---:|---:|---:|---:|
| 다이 접착 | 1,000 | 995 | 5 | 995 |
| 와이어 본딩 | 995 | 990 | 5 | 990 |
| 최종 검사 | 990 | 980 | 10 | 없음 |

이 단순 실습에서 공정 완료 시 투입=양품+불량=산출이다. 미처리 잔량·재작업·자재 환산은 첫 과정에 없다. 최종 양품 980 EA, 중복 없는 누적 불량 20 EA, 초기 투입 1,000 EA로 대사한다. 공정 양품의 합계 2,965를 완제품 수량으로 사용하지 않는다. 에너지 예시의 분모도 해당 기간·LOT의 최종 양품과 일치시킨다.

## 예외·수정·취소의 업무 요구사항
- 품목/설비 비활성, 선행 공정 미완료, 부적합한 경로·설비, 권한/공간/세대 불일치: 실행 거부와 해결 위치 안내.
- 음수·소수 EA·수량 불일치·종료<시작·불량 사유 누락: 입력 오류 표시.
- 중복 클릭/재시도: 같은 실행을 두 번 기록하지 않음.
- 등록 상태: 수정 또는 취소 가능. 취소 이력을 보존하고 물리 삭제를 기본으로 하지 않음.
- 발행 후: 계획·품목·경로 고정. 취소/생산 중단은 첫 과정에서 지원하지 않으며 임의 상태 되돌리기 금지.
- 실행 중: 저장 전 입력 수정 가능. 확정 후 수량 직접 덮어쓰기 금지. 첫 과정의 오입력 재체험은 본인 공간 초기화로 제공하고 실제 업무용 정정·역처리는 후속 요구사항으로 분리.
- 초기화: 학습 기록은 보존. 진행 중 실습은 새 예시로 다시 준비하고 과거 행 참조를 성공으로 간주하지 않음.
- FEMS 비활성: MES 생산 완료 가능. 에너지 학습으로 이동할 때 필요한 모듈을 안내.

## 역할과 권한 범위
| 역할 | 허용 | 제한 |
|---|---|---|
| 학습자 | 본인 공간의 지시·LOT·실적 실행, 모듈 선택, 실습 초기화, 진도 확인 | 다른 사용자의 업무/학습 접근, 콘텐츠 게시 불가 |
| 콘텐츠 관리자 | 가상 과정·기준 예시·안내의 버전 관리·게시 | 학습자 업무의 임의 대행·완료 처리 불가 |
| 운영 관리자 | 운영 상태·실행 실패·초기화 작업 관리 | 타 사용자 데이터 접근을 기본 권한으로 부여하지 않음 |

관리 기능은 초기에는 하나의 관리자 계정에서 수행할 수 있어도 권한 항목은 구분한다. 추가적인 협업 생산 권한과 승인 체계는 후속 범위다.

## 공통화 경계와 첫 공개 범위
공통 기반: 계정/권한, 개인 공간/세대, 코드·단위·기준정보 식별, 감사, 모듈 설정, 학습 진도.
MES 소유: 공정 경로·버전, 지시, LOT, 실행·실적, 생산 상태와 수량 규칙.
FEMS/BEMS: 후속 단계에서 실제 설비와 계측 경계를 연결. MES DB를 직접 변경하지 않음.
WMS/ERP: 참고 설계에 포함됐어도 이번 첫 업무에 구현하지 않음. 거래처·가격·자재불출·재고 원장은 해당 공개 단계에서 소유 모듈에 구현.

범용적으로 재사용할 것: 기준정보 선택, 단위 표시, 목록/상세, 입력 검증·이력 UI, 학습 안내 틀.
업종 설정으로 둘 것: 공정명·경로·설비·불량 사유·기준단위.
도메인에 남길 것: 생산 상태·수량 검증, 재고 원장, 회계 전기 등 고유 규칙.
