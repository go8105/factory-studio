# POP — 현장 단말

- 상태: **설계 완료(신규, 2026-10-05) — 확인 대기** — [DSN-22 설계](POP_설계_DSN-22.md)(ROADMAP-02). 생산·창고 현장 단말과 스캔·확정 입력 원장. MES·WMS가 확정 입력을 가져가 반영한다(ROADMAP-01 §6-1, MES Q1·WMS Q1).
- 스키마 `pop`, 모듈 키 `pop`, 화면 접두어 `T`(Terminal). 개발은 18개 설계가 끝난 뒤(D75).
