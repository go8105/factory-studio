## 0. CRM의 자리 — ERP 앞단의 영업

**CRM = 수주 전 영업(잠재 고객 → 영업 기회 → 견적 요청)과 고객 관계 활동을 관리하는 솔루션.** 견적서 확정·수주·출하·매출·채권은 ERP, 품질 클레임은 QMS가 소유한다.

| 영역 | 소유 | CRM과의 관계 |
|---|---|---|
| 잠재 고객·연락처·영업 기회·영업 활동 | **CRM** | 이 문서 |
| 거래처·견적·수주·매출·채권 | **ERP** | CRM 기회를 ERP가 견적으로 가져감(Q2), CRM은 ERP 수주·매출을 읽음 |
| 고객 클레임 | **QMS**(DSN-14 Q4) | CRM은 읽기, 문의 중 품질 건은 QMS로(Q4) |
| 배송 | **TMS** | 고객 360 화면에서 읽기 |

## 3. 기능 규칙 (범위 21)

공통: **견적서·수주·출하·매출은 ERP, 클레임은 QMS** — CRM은 그 앞단(리드·기회·활동·문의)만 소유하고, 다른 솔루션 결과는 조회로 읽는다. 연락처는 합성 데이터.

| 묶음 | 기능 ID | 규칙 |
|---|---|---|
| 리드 | F01 | 출처(전시회·세미나·웹·소개·콜드·기타)·캠페인. 신규 → 접촉 → 자격 확인 → 전환(고객사 생성·연결) 또는 실격(사유) |
| 고객 (Q1) | F02~F06 | 고객사는 CRM 소유. ERP가 "CRM에서 가져오기"로 거래처를 만들면 CRM은 ERP 조회로 거래처 코드를 연결(ERP 거래처 1건 = 고객사 1건). 주 담당 1명. 등급 A/B/C = 최근 12개월 ERP 매출(조회). 태그로 분류·관심 품목 |
| 기회 (Q2·Q3) | F11~F16 | 6단계 + 수주/실주, 단계 기본 확률 10·20·40·60·80(조정 가능), 단계 이동마다 이력. 견적 단계에서 "견적 요청"(품목 스냅샷, 기회당 열린 요청 1건) → ERP가 가져가 견적 초안. ERP 수주를 CRM이 읽어 "수주 확인" 제안 → 사람이 WON(ERP 수주 번호 필수, 수주 1건 = 기회 1건). 실주는 사유·경쟁사. 매출 예측 = 월별 Σ(금액 × 확률) |
| 활동 | F21·F22 | 방문·전화·메일·회의 기록(고객사·기회·리드 중 하나 이상), 할 일(예정일·완료). 메일 발송·캘린더 연동 없음 |
| 문의 (Q4) | F31·F32 | 접수 → 답변 → 종결. 품질 문의만 "QMS 클레임으로 전환"(TRANSFERRED) → QMS가 가져가 클레임 접수, 진행은 QMS 조회로 표시 |
| 캠페인 (Q5) | F41·F42 | 캠페인(종류·기간·예산). 출처·캠페인별 리드 수·전환율·기회 수·수주 금액(조회) |
| 분석 | F51~F53 | 고객 360(기회·활동·문의 + ERP 수주·매출·채권 + QMS 클레임 + TMS 배송), 담당자별 실적(수주 금액·건수·전환율), 파이프라인(단계별 금액·평균 체류·30일 이상 정체 기회) |

## 6. 교차 조회

**CRM이 읽는 것**

| 제공 | 함수 | CRM 용도 |
|---|---|---|
| ERP | `crm_imports()`(신규: 가져간 고객사·견적 요청 → 거래처 코드·견적 번호) · `sales_orders_for_crm(since)`(신규) · `partner_summary(partner_codes)`(신규: 수주·매출·채권) | Q1 연결, Q2 수주 확인, 등급·고객 360 |
| QMS | `claims(customer_code)`(DSN-14) | 문의 전환 진행, 고객 360 |
| TMS | `deliveries(since)`(DSN-23) | 고객 360 배송 |

**CRM이 제공하는 것**

| 함수 | 돌려주는 것 | 쓰는 곳 |
|---|---|---|
| `accounts(ready_for_erp=True)` | ERP 거래처로 만들 고객사(이름·사업자번호·주소·담당자) | ERP "CRM에서 가져오기"(Q1) |
| `quote_requests(since)` | 견적 요청(기회·고객사·품목 스냅샷) | ERP 견적 초안(Q2) |
| `quality_inquiries(since)` | QMS 전환 품질 문의 | QMS 클레임 접수(Q4) |
| `pipeline_summary(month)` | 단계별 금액·예측 | EIP·SCM 수요 참고 |

> 넘길 것: **ERP** "CRM에서 가져오기"(거래처·견적 초안), `crm_imports`·`sales_orders_for_crm`·`partner_summary` 제공 · **QMS** `quality_inquiries` 가져오기 → 클레임 · **SCM(신규)** 파이프라인 예측을 수요 참고로.

## 7. 결정 질문 (하나씩)

| # | 질문 | 제안 |
|---|---|---|
| Q1 | **고객 마스터** — CRM 고객사는 CRM 소유(리드 전환·직접 등록). 거래가 시작되면 ERP가 "CRM에서 가져오기"로 거래처를 만들고, CRM 고객사에 ERP 거래처 코드를 연결(자동 동기화 없음) | 그대로 |
| Q2 | **기회 ↔ ERP** — 기회가 견적 단계가 되면 "견적 요청"(관심 품목·수량·희망가) → ERP가 가져가 견적 초안. ERP 수주를 CRM이 읽어 해당 기회에 "수주 확인" 제안 → 사람이 수주 처리 | 그대로 |
| Q3 | **단계·확률** — 6단계 고정(발굴 10% · 자격 20% · 제안 40% · 견적 60% · 협상 80% · 수주 100% / 실주 0%), 기회별 확률 조정 가능, 매출 예측 = Σ(금액 × 확률) | 그대로 |
| Q4 | **고객 문의** 포함 — 일반 문의(납기·견적·기술)는 CRM에서 답변·종결, 품질 문의는 "QMS 클레임으로 전환"(QMS가 가져가 접수, QMS 소유 유지) | 포함 |
| Q5 | **캠페인·리드 출처 분석** 포함(대량 메일 제외) | 포함 |
| Q6 | 범위 확정 — 포함 17 + Q 4, 제외 2(메일·캘린더 연동, 대량 마케팅) | 제안대로 |
