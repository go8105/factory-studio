## 0. HR의 자리 — 사람 원천

앞선 설계에서 이미 정해진 것:

| 솔루션 | 사람 마스터 | HR과의 관계 |
|---|---|---|
| MES `worker`·POP `operator`·CMMS `technician` | 각자 소유(작업자 바코드·정비원 코드) | HR 사원 코드 스냅샷 |
| GW `person`·CRM `sales_rep`·ELB 신청·승인·`approver`·QMS CAPA·RWS `expert` | 각자 소유 | `hr_employee_code` 스냅샷(DSN-28 Q3-1) |
| ERP `department`·`employee` | ERP 자체(DSN-11 Q2, 중복 정상) | 급여 전표만 HR 결과를 읽음(F94) |
| EIP `person_link` | 로그인 사용자 ↔ HR 사원 코드 | 사람별 할 일 |
| core `holiday` | 공통 휴일 달력 | HR 근태가 날짜로 읽음 |

## 3. 기능 규칙 (범위 24)

공통: **HR은 사람의 원천이다** — 사원·부서 코드를 발급하고, 다른 솔루션은 가져가 스냅샷한다(FK·자동 동기화 없음). 민감 정보(주민번호·계좌·주소·가족)와 신고(4대보험·원천세·연말정산)는 없다(D79). 세율·보험료율은 합성 고정값.

| 묶음 | 기능 ID | 규칙 |
|---|---|---|
| 조직·사원 (Q1) | F01~F05 | 부서 계층·직위·직책(부서장 표시). 사원 현재 부서·직위·직책·상태는 **확정 발령으로만** 바뀐다(입사·이동·승진·직책·휴직·복직·퇴직, 확정 후 불변). `employees()`·`departments()` 제공 → 각 솔루션 "HR에서 가져오기", 퇴직은 조회 때 표시 |
| 자격·교육 (Q6) | F06 | 자격·교육 이력, 만료 30일 전 경고(조회) |
| 근태 (Q2) | F11·F12·F14·F15 | 근무 형태(일근·교대) + core 휴일로 월 근태 자동 생성 → 지각·결근·연장 등 예외만 수정. 야간 22~06시, 휴일 = core 휴일·비근무일 근로. 월 마감 확정(월당 1건) 후 수정 불가, 재마감은 새 버전 |
| 휴가 (Q3) | F13 | 연도별 연차 발생, 잔여 = 발생 − 승인 사용(조회). 신청 → 부서장 직책 사원 승인 → 일 근태 LEAVE. 잔여 초과 거부 |
| 급여 (Q4·Q5) | F21~F28 | 항목(지급·공제, 계산 방식), 사원별 기본급·고정 수당(적용 시작 월 이력). 월 계산 = 기본급 + 고정 수당 + 연장·야간·휴일(통상시급 × 배율) + 상여(지정 월 기본급 × 지급률) − 공제(과세 지급 × 합성 비율). 입력은 같은 월 **확정 근태 마감**. 확정 후 불변·재계산은 새 버전. 급여대장·명세서 인쇄. ERP에는 `payroll_runs(month)` = 부서·항목별 합계만(개인 금액 없음). 퇴직금 추계 = 최근 3개월 평균 임금 × 30일 × 근속 연수(조회) |
| 평가 (Q6) | F31 | 연도별 평가 기간, 사원 목표·자기 평가 → 평가자(기본 부서장) 등급 S~D·의견 → 확정 후 불변 |
| 분석·본인 (Q7) | F41~F44 | 인원 현황·인건비(부서·월·항목)·근태(연장·연차 사용률) 조회. 급여 화면은 HR 관리자만, 본인 조회는 EIP 사람 연결의 사원 코드와 같은 것만 |

## 6. 교차 조회

**HR이 제공**

| 함수 | 돌려주는 것 | 쓰는 곳 |
|---|---|---|
| `employees(status?)` | 사원 코드·이름·부서 코드·직위·재직 상태 | **모든 솔루션 "HR에서 가져오기"**(MES 작업자·POP 작업자·CMMS 정비원·GW·CRM·ELB·QMS·RWS 전문가), EIP 사람 연결 |
| `departments()` | 부서 코드·이름·상위·부서장 사원 코드 | ERP 부서·ELB 승인자 지정 |
| `payroll_runs(month)` | 확정 급여의 부서 코드·항목별 합계 | **ERP F94 급여 전표** |
| `monthly_summary(month)` | 인원·입퇴사·인건비·연장 근로·연차 사용률 | EIP |
| `pending_tasks(hr_employee_code)` | 휴가 승인 대기·평가 대기 | EIP 할 일 |
