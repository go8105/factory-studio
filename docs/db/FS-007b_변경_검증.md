# FS-007b 모듈별 DB 명세와 ERD

작성: 2026-09-21. 설계 산출물 작성·정적 검증 완료, 사용자 검토 대기. 제품 개발 승인 아님.

## 이번 변경

FS-006b의 게스트 주체·회수, 필수 생산계획 연결, 단일 품목 BOX/PALLET, PALLET 전량 출하 계약을 메타데이터 v0.3.0에 반영했다. 공통 요청 결과는 mes.request_receipt에서 core.request_receipt로 이동했다. 출하 헤더와 라인 소속은 복합 FK로 연결하고, 누계·동시성 규칙은 서비스 정책으로 구분했다.

| 모듈 | 테이블 | 컬럼 |
|---|---:|---:|
| CORE | 17 | 159 |
| MES | 14 | 130 |
| ERP | 10 | 87 |
| FEMS | 2 | 27 |
| LEARN | 6 | 57 |
| MAP | 3 | 24 |
| BEMS (후속 예약) | 2 | 26 |
| 합계 | 54 | 510 |

외래키 113개, 제약·인덱스·서비스 정책 375개다. 54개 전체가 첫 개발 단계의 구현 범위라는 뜻은 아니다. QMS/WMS는 아직 별도 테이블 설계가 없다.

## 살펴보는 순서

1. `../architecture/erd/EIP_모듈별_ERD.html`을 열고 EIP 전체 구조에서 MES/ERP/FEMS를 선택한다.
2. 테이블을 선택하면 전체 컬럼과 외래키를 오른쪽에서 확인한다. 확대와 공간·세대 FK 표시를 지원한다.
3. `DB설계서.xlsx`의 목차에서 모듈을 선택한다. 각 모듈은 테이블/컬럼/관계/규칙 네 시트로 나뉜다. 전체 31시트다.
4. ERD는 데이터 참조 관계다. 업무 순서도는 별도 화면 설계에서 다룬다. 다른 모듈 테이블은 점선 테두리로 구분한다.

HTML은 외부 라이브러리 없이 동작하도록 작성했다. 전체와 7개 모듈의 Mermaid 원본도 같은 폴더에 있다. 백자/먹색/쪽빛 기준을 적용했다.

## 실제 수행한 검증

- 메타데이터: 테이블/컬럼/참조키/타입/범위 정적 검사 통과, 오류 0개.
- Excel 재개방: 31시트, 1,191개 데이터 행의 셀을 생성 원본과 대사. 내부 링크 172개 대상 검사. 오류 셀 및 지원되지 않는 수식 문자열 없음.
- Excel 시각 확인: 31개 시트 상단 PNG를 확인했다. 모든 행의 화면 표시를 전수 검사한 것은 아니다.
- ERD: DOM 대체 객체를 이용한 9개 보기 생성, 테이블 상세 선택, 전체 FK 113개 표시 검사. EIP/MES/ERP/FEMS SVG를 PNG로 렌더해 확인했다.
- 실제 브라우저 상호작용, Mermaid 렌더러 파싱, Excel 네이티브 앱 동작은 미검증이다.
- PostgreSQL 생성·마이그레이션·락/동시성/성능·AC-65~80 실행은 하지 않았다. 서비스 정책을 DB 검증 통과로 해석하면 안 된다.
