# FS-015 시드 생성기 구현·검증 보고

기준: `sv-20260923-1`, T0=`2026-09-23`, schema.json v0.9.1. 스키마 메타데이터는 변경하지 않았다.

## 결과

- 단일 `codebook.json`을 MES·ERP·FEMS 생성이 함께 읽는다. 난수 호출은 없다.
- PostgreSQL 18.6의 빈 검증 DB에 템플릿 **7,469행**을 실제 INSERT했다. CHECK·FK·UK 위반은 0건이다.
- 복사는 템플릿 core 생성분 6행을 제외한 업무 데이터 **7,463행**을 `INSERT ... SELECT`로 옮긴다. guest workspace·generation·module 6행을 합친 결과도 7,469행이다.
- V1~V12 자동 검증과 같은 `(seed_version,T)` 2회 바이트 비교가 통과했다.
- 서로 다른 T `2026-10-07`, `2027-01-05`로 복사하여 연월·ISO 주차·연도·적용월 재계산을 확인했다.

## 복사 구현 판단

| 항목 | 결정 | 실행 근거 |
|---|---|---|
| ID 재매핑 | 자식 FK가 참조하는 부모 테이블만 임시 매핑. leaf의 id는 생략 | 6,540행 energy_reading 등 leaf에 불필요한 매핑을 만들지 않고 FK 전부 통과 |
| identity | 부모 새 id를 sequence에서 선발급하고 `OVERRIDING SYSTEM VALUE`로 INSERT | 부모·자식 복합 범위 FK를 한 트랜잭션에서 유지 |
| 실행 단위 | PL/pgSQL 함수 1회 호출 대신 테이블별 INSERT 문장 | `statement_timeout`이 전체 복사 1문장에 묶이지 않고 각 테이블 문장에 적용됨. 실패 시 바깥 트랜잭션 전체 롤백 |
| 달력 | 시각·일자는 T−T0만큼 이동하고 FS-005g §1.2 문자열은 T에서 재계산 | 두 T의 월 경계와 2027년 연도 전환 검증 통과 |

복사 1건을 최종 코드로 10회 측정한 결과 중앙값 **0.4555초**, 최대 **0.4758초**였다. 목표 2초 이내다. 로컬 단일 컨테이너·단일 진입 측정이며 guest_pool 잠금 대기와 네트워크/API 시간은 포함하지 않는다.

템플릿의 SITE·EQUIPMENT 목표는 생성된 월별 계측·배분 실적의 95%를 계산하며, ITEM 기준선은 W01~W06의 전 공정 설비 에너지 합을 최종 검사 양품으로 나눠 산출한다. 고정 예시값은 사용하지 않는다.

## FS-005g §10.5 미대조 NOT NULL 채움 규칙

| 종류 | 일반 규칙 |
|---|---|
| `created_at` | 생성 기준일 T 00:00 Asia/Seoul을 UTC timestamptz로 저장. 복사 시 T−T0 이동 |
| 통화 | 모든 1차 거래·가격·요금은 `KRW` |
| 명세·규칙 행 번호 | 부모별 문서 순서로 1부터 연속 부여 |
| 견적 상태 이력 | 상태가 성립한 업무 시각을 `changed_at`에 넣고, 전이 의미를 비공백 `reason`으로 기록 |
| 출하 | confirmed 출하는 해당 업무일의 `shipped_at`, 상태는 문서 지정값 |
| 매출 | 출하 다음 인식 규칙의 `recognized_at`, `currency=KRW`; 취소되지 않은 행의 취소 필드는 NULL |
| 확정 시각 | confirmed 행은 해당 업무일 10:00 또는 문서의 공정 종료 후 30분. draft는 NULL |
| 취소 필드 | cancelled 사례만 취소 시각·비공백 사유를 함께 기록. 그 외 NULL |
| 소명 | 부모 확정시각을 `applied_at`으로 쓰고 `SEED:RA-*`/`SEED:PA-*` 키를 부여 |

## 자동 검증

`backend/tests/test_seed.py`가 실제 PostgreSQL DB를 초기화해 템플릿을 두 번 만들고, 전체 행의 정렬 JSON 바이트를 비교한다. 이어서 두 달력 T와 10회 성능 T를 복사해 각 세대에 V1~V12를 다시 실행한다.

V1 수량, V2 결정성·달력, V3 코드 사전, V4 설비 점유, V5 공정 수량, V6 패킹 한도, V7 생산 기록, V8 배분 합, V9 소명·세액, V10 시각·달력, V11 스키마 격리, V12 DB 밖 시드 규칙을 검사한다.

최종 실행 환경은 Python **3.14.7**(`uv run`), Node **24.21.0**, PostgreSQL 서버·컨테이너 psql **18.6**이다. 다음 검증을 실제 실행했다.
