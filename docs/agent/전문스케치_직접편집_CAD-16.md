# CAD-16 전문 스케치·직접 편집 결과

2026-10-08 · 사용자 CAD-16 착수 승인. [계약](../modules/cad-cam/전문스케치_직접편집_설계_CAD-16.md) 범위 완료. CAD-17 미착수. 추가 음성 발표 요청은 [별도 제안](../modules/cad-cam/음성발표데모_제안_CAD-V01.md)이며 구현 미착수다.

## 변경과 사용법

- E1 `/cad-cam`: 형상을 선택하거나 스케치 초안을 만든 뒤 **전문 스케치**. E2 `view=part`: 기본 돌출/돌출/파내기의 **전문 스케치 편집**. 같은 창에서 점·원호 경유점 드래그, Shift 다중 선택, 끝점/격자 스냅, 연속 선/3점 원호를 작성한다.
- 거리·원호 길이/반경 측정, 점 좌표, 거리/수평/수직/일치/반경/고정 구속. 구속 해석은 외곽만; 내부 경계는 좌표 치수로 편집한다. 구속된 점 변형/자르기/연장은 먼저 명시적으로 구속을 해제해야 한다.
- 선택점 이동·회전·U/V축 반사, 전체 닫힌 와이어를 내부 경계로 복사. 기존 E1 홈 복제도 유지. 원·둥근 사각형·슬롯은 원호를 보존해 profile로 변환한다.
- 닫힌 와이어의 선택 엔티티 자르기로 열린 와이어를 만든다. 열린 와이어의 첫/마지막 직선 비율 자르기·끝점 연장, 엄격 볼록 직선 윤곽 오프셋. 일반 교차 대상 자동 trim/extend, 오목/원호 offset은 미지원 메시지로 거부한다.
- 외곽+최대8 내부 닫힌 경계. E1 파내기의 내부 경계는 남기는 섬, E2 돌출의 내부 경계는 구멍. 접촉/겹침/포함/외곽 이탈을 거부하고 기존 Manifold 공구 여유·안전 높이 이동·격자 제거·STL/STEP에 연결한다. 여러 외곽/중첩 섬은 미지원.
- 창 내부50단계 undo/redo; 적용은 부모 초안/모델 이력 한 단계. 입력의 기본 undo를 보호하고 모달 뒤의 Delete/저장 같은 부모 명령을 차단한다. Esc/실패는 확정 설계를 유지한다. PC 독립 패널 스크롤·고정 적용 버튼, 모바일 세로 배치.
- E2 새 필렛/모따기에서 실제 직선 모서리를 클릭 또는 목록으로 선택 → 현재 피처에 사용. 새 돌출/파내기에서 실제 축 정렬 면 선택 → 작업면에 사용. 기하 참조의 끝점/길이 또는 면 경계(내부 경계 포함)/법선/면적을 매 재계산 확인한다. 유일하지 않거나 변경된 참조는 실패한다. 삭제 후 새 피처로 재선택하며, 현재 완성 형상의 참조를 과거 이력 중간 피처에 붙이지 않는다. 기울어진 면/곡면·면 자유 이동·범용 위상 추적은 미지원.
- JSON v2/v3·localStorage 키 유지. E1 100KB/E2 250KB 확정 전 크기 검사 및 저장 시 compact 전환으로 재열기 상한을 보존한다. DB/백엔드/비누 권한은 변경하지 않았다.
