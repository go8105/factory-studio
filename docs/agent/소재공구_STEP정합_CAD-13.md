## 제공 기능

NC 경로 검토 화면에 소재 이름·직육면체 최소 XYZ/크기, 평엔드밀 공구표(T/지름/날 길이/H·D 참조) 추가/삭제·초기 활성 T, 실제 STEP 파일 읽기, STEP→G54 Z축 회전/XYZ 이동·치수 표시·좌표 확인을 추가했다. STEP 단위는 OCCT가 mm로 변환하며 임의 배율을 적용하지 않는다. NC는 원본 G54 끝점 좌표를 유지한다. 소재 윤곽·STEP 목표·NC 경로를 겹쳐 표시하고 셀 높이 결과를 색으로 표시한다.

상면 높이장으로 제거/잔삭/과절삭 체적·최대 깊이·급속 소재 접촉 후보 행을 계산한다. 후보 버튼은 원본 NC 행/강조 경로로 이동한다. 목표의 격자 체적과 실제 BRep 체적 차이(%)도 표시한다. 작은 형상 전체가 격자에서 누락되면 비교를 거절한다. 공차 기준0.1mm는 비교 임계값이며 실제 치수/표면 품질 공차가 아니다.

소재 예제 NC와 STEP 예제 버튼을 제공했다. 수평20×20mm·목표높이5mm, 소재높이8mm·T1 지름4/날15 예제다. NC 예제→경로 해석→STEP 예제→정합/상면 확인→소재 검토 실행 순서로 재현한다. STEP/NC 파일은 [examples](../../prototypes/cad-cam/examples/cnc_CAD13_2026-10-07_target.step), 생성기는 `experiments/nc-cad13-fixtures.mjs`에 둔다. 관리자 비누·연구노트/기존 E1/E2 권한과 파일은 유지한다.

소스/SHA-256·소재/공구/변환/격자/분석을 JSON에 포함한다. STEP 원본은 내보내기 JSON에 넣지 않고 이름·해시·체적·경계를 기록한다. 설정/NC 변경은 이전 분석 무효화, 정합 재확인이 필요하다. 파일은 브라우저 메모리/Worker에서만 처리하며 서버·DB 저장은 없다. STEP/소재 Worker는 revision·인스턴스 방어·30초/수동취소·terminate를 적용했다.

실제 브라우저는 localhost5243/8043 합성 관리자 fixture로 검증했다(운영 계정/DB 아님). 파일로 NC27이동/6이벤트, STEP체적2000/경계20×20×5mm를 확인했다. 정합 미확인은 거절, 확인 뒤 제거1200/잔삭0/과절삭0/격자20×20·체적오차0%였다. 원본 끝에 급속 X10Y10→Z4를 넣으면 접촉 후보34행 하나·제거량1200 유지, 버튼 선택 시 해당G0/끝점4mm가 표시됐다. NC 변경은 결과 없음/정합 미확인으로 바뀌었고, 회전90도 후 범위 밖 목표와 T2로 공구표 변경 후 NC T1 미등록도 거절됐다. 정상 입력 복구 후 결과를 다시 확인했다. 공구표는 JSON 편집 대신 숫자 입력칸이다.

1440폭/390폭에서 iframe body.scrollWidth=clientWidth(1425/360)로 가로 넘침 없음, 모바일에서도 결과/3D 표시 확인. 임시 viewport 복원. [화면](assets/cad-13/stock-review.png)·[모바일](assets/cad-13/mobile.png).

## 제약과 미검증

- 단일 Solid STEP 참조. 비교는 수평/수직 면·바닥부터 이어지는 단일 상면, 평엔드밀·수평 이송/수직 플런지만. 곡면/경사·언더컷·중공/다층·떠 있는 부품·볼/테이퍼 공구·경사 직선은 미지원. 격자/삼각형 근사이고 원호 현 오차0.05mm·작은 특징 누락 가능. 전체 체적 오차0도 국소 누락이 없다는 보증이 아니다.
- H/D는 공구표 참조 기록만, G43/H·G41/42/D 보정 해석은 계속 차단. M6/M30 자동 장비 이동·실제 급속 궤적·홀더/지그/장비 충돌·기계 안전·Ra/실물 품질은 검증하지 않는다. 접촉0·과절삭0은 안전 판정이 아니다.
- 전체 시간/kWh·재질별 절삭력/전력·효율/최적 경로·실측 보정은 CAD-14/15 범위. 이번에 구현하지 않았다.
- STEP/소재 Worker 실제30초 만료·stale 응답 강제 주입·대형 STEP 성능/최대 메모리·장비 실행·DB/운영 배포 미실행. STEP 예제 수동취소 시도는 읽기가 먼저 끝나 취소 버튼이 비활성이라 성공으로 기록하지 않는다. 분석 JSON 실제 다운로드/재열기는 기존 IAB 이벤트 제한으로 이번에도 미검증이다.
- 기존 큰 chunk·OCCT WASM 약23MB 경고 유지. 부품 설계 Worker와 별도 STEP Worker라 다시 읽을 때 초기화 비용이 있다. 차후 캐시/Worker 재사용은 검증 후 별도 작업.
