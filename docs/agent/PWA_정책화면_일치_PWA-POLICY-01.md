## 남은 제한과 다음 작업

- 실제 회사 정책 관리 화면·법정 연차 산정·여러 휴게/교대/야간·비서울 시간대 및 정책 변경의 과거 잔여 재산정은 이번 범위 밖이다. 서버 정책은 읽기만 하며 관리자 임의 DB 수정 안내도 하지 않는다.
- main 병합·원격 push·운영 배포는 미실행이다. 공유 main의 기존 Flow7 실패가 있어 출시 전체 검증을 충족했다고 볼 수 없다.
- 다음 GW는 기존 `GW확장_상세설계검증_GW-EXT-A.md`가 아직 ‘전체 확인 대기’이고, 신규 회사 멤버십/초대 구조가 이후 HR/Flow의 `core.company` 구현과 달라 재설계 대조가 필요하다. 기존안을 그대로 적용해 중복 인증/회사 표를 만들지 않는다. 회사 간 접근·역할 가장·권한 회수·결재 위임·개인/체험 보존 인수 기준을 먼저 확정한다.
- AGENTS.md §1: “작업 ID 하나씩 수행하고 결과를 보고한 뒤 사용자 확인을 기다린다. 확인 전 다음 ID를 시작하지 않는다.” §2: “사용자의 전체 설계 확인 후 제품 개발을 시작한다.” 이번 첫 ID 결과 보고 뒤 GW 회사 인증의 최신 설계 확인으로 이어간다. 이전 도움말 배포 승인을 새 회사 인증/실설비 운영 승인으로 확대하지 않는다.
