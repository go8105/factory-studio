## STEP 점검과 보정

- 현재 열렸던 file://…/docs/ui/previews/UI-DESIGN-01.html은 STEP·분석 기능이 없는 구조 시제품이다. 상단 설명 강화·실제 NC 화면 링크 추가.
- 실제 공개 운영 NC 화면에서 STEP 예제를 클릭했다. 첫6초 ‘STEP 커널 읽기 중’, 별도32초 관찰에서는 ‘30초 상한 초과/STEP 읽기 실패’ 재현. 이 관찰 내 HTTP/스크립트 오류0. 특정 장비·전체 네트워크 원인을 확정한 것은 아니다.
- 기존 제한은 Worker 스크립트/큰 WASM 커널 준비까지30초에 포함했다. 준비90초 / STEP 형상읽기30초로 분리, 다운로드·초기화·형상읽기 진행 메시지·HTTP실패 안내 추가. 소재 계산30초는 유지. 실패/취소 후 예제/파일 재선택 가능. 90초 실제 만료는 미검증.
- 로컬 실제 빌드 Chrome에서 잘못된 STEP 실패→STEP예제 재시도 성공→G54/단일상면 확인→소재검토 통과. WASM fetch를32초 지연한 브라우저에서32.491초 후 STEP 읽기 완료(기존30초 실패 경계 초과 환경). 운영 수정배포/운영 수정후 재시도는 미실행.

## 카드·호출 구현

- ‘헤이 와이씨’/‘헤이 와이시’/‘Hey YC’/‘헤이YC’ 기본호출 추가. 기존 휴디는 전환별칭, 내부 클래스/경로명 유지. 화면 YC·와이씨, 예제버튼 YC로 변경. 최종인식/번호/중복차단/30초창/TTS 자기음성 차단 유지.
- 제안 시 현재 report의 후보수 그대로 dialog 카드 표시(합성 발표3, 일반최대13). 정지 3D뷰어 캡처·실제예상초/kWh범위·G4근거·차단/우열불가 표시. 경로가 같은 이유 명시. 임의 Ra·향상률·절삭속도 변경·적응경로를 만들지 않았다.
- 선택은 proposalTimeline의현재입력/차단 검증 후 나머지카드숨김·선택카드확대·기존3D뷰어/재생패널 이동. 새 WebGL renderer를 만들지 않아3중재생/복제부하 없음. 오른쪽 YC패널도이동해마이크·텍스트fallback 접근유지.
- 전체제안보기/닫기/Esc/탭숨김은 정지, 닫기/무효화는 원래자리복원. 입력·report 변경시이전카드없음. 반복제안close이벤트가 새 dialog를지우지않도록보호. 사용자화면/자료의배치를참고하되프로젝트색상·라이브러리·권한유지.
