# 로봇 연동 CNC 가공 셀 — FS-FACTORY-CNC01

작성: 2026-09-28 / 브랜치: codex/vision-ai / 기준 커밋: aac8d26

## 구현 범위

첫 설비를 로봇 연동 CNC 셀로 교체한다. 원소재 받침·관절 로봇·그리퍼·CNC 인클로저·양쪽 슬라이드 문·지그·주축·배출 받침을 Three.js 형상으로 구성했다. 가공 후 소재는 포켓과 두 체결 구멍을 가진 형상으로 전환한다. 기존 assembly-cell.glb는 로딩하지 않으며 포장·비전 모델은 유지한다.

공장 제목은 정밀 부품 가공 공장, 첫 설비 라벨은 01 CNC 가공, 현장 표지는 CNC 가공 → 비전검사 → 포장이다. Factory Studio 제품명은 유지한다. 사용자 참고 문서는 `/help/portal/cnc-cell`이며 CNC 패널에서 연결한다.

## 상태와 소재 처리

- 순수 상태 전이: `frontend/src/factory/cnc.ts`. React 시간 관리: `useCnc.ts`. 3D 형상: `CncCell.tsx`. 조작 패널: `CncPanel.tsx`.
- 준비 → 집기 → 투입 → 로봇 퇴피 → 소재 고정 → 문 닫기 → 가공 → 주축 정지 → 문 열기 → 고정 해제 → 꺼내기 → 배출 완료. 시작당 한 개, 중복 시작 차단. 완료는 마지막 단계에서 한 번만 증가한다.
- 원소재/가공품은 단일 객체로 표시하고 받침·그리퍼·지그·출력 중 한 곳에 둔다. 그리퍼 이동은 문 앞 경유점을 사용한다.
- 모의 인터락: 문 닫힘·고정·퇴피 상태의 가공 단계에서만 주축 가동. 실제 로봇 동역학·안전 PLC·충돌 시뮬레이션 아님.
- 일시정지/오류는 단계·시간·소재 위치 유지. 오류 중 시작/재개/종료 차단 → 명시적 오류 해제 → 일시정지 → 명시적 재개. 종료는 진행 소재 한 개를 보류하고 준비로 돌아간다. 오류와 보류는 제품 NG가 아니다.
- 전역 시연 정지·외관 보기·그래픽 대기 중 타이머 진행 차단. 탭 숨김은 CNC 일시정지, 탭 복귀만으로 재개하지 않는다. 화면 이탈 시 RAF 정리 및 메모리 상태 소멸.
- 프레임당 최대 100ms 진행. 소프트웨어 WebGL이나 느린 장치에서는 시연이 느려질 수 있으며 실시간 장비 사이클타임 측정으로 표시하지 않는다.
- 완료/보류 수는 CNC 시연 전용. 비전검사·C++·MES·WMS와 수량 자동 연계 없음. 기존 비전 합성 통계와 혼합하지 않는다.

## 화면과 이동

조감도 공정 버튼 또는 3D 설비 선택으로 패널을 연다. CNC 가까이 보기는 첫 설비에 초점을 맞춘다. 넓은 화면은 CNC 장면과 패널을 나란히 배치하고 좁은 화면은 세로로 배치한다. 1인칭 설비 선택/이동 방식은 유지한다. 로봇 받침·문 이동 영역을 반영해 첫 설비 충돌 영역을 확대하되 앞 통로는 유지한다.

## 후속

6단계 중 2단계 범위. 다음은 WMS 공통 설계와 최소 입고·재고·출고, LOT 연계. 독립 솔루션 소유 경계와 스키마 간 FK 금지 유지. 기존 MES 시드·DB·API 수정 없음. 운영 배포는 사용자 담당이며 이번 작업에서 push·main 병합·배포하지 않는다.

## 최종 검증 결과

프런트 456개/52파일 통과, typecheck(빌드)·lint·format·build 통과. 전체 Chromium은 21통과·1제외·1실패였고, 편집 중 HMR로 체험이 초기화된 1인칭 검사를 소스 변경 없이 재실행해 통과했다(그래픽 손실 포함 재실행 2통과). 고유 22개 브라우저 시나리오 확인. 실제 C++ API 검사는 이번에 제외했으며 DB·백엔드·실장비·운영·Safari는 미검증. CNC 완료 1280px·모바일 390px 화면 직접 확인. 문서 링크·diff 공백 검사 통과.

기존 빌드의 3D 청크 크기 및 THREE.Clock 사용 중단 예정 경고는 유지된다. 백엔드 변경은 없다.
