## 구현 결과

[설계 계약](../modules/cad-cam/시간소비모델_설계_CAD-14.md). `/cad-cam?view=nc`에서 현재 NC의 소재 검토 완료 → 상태표 → 장비 축 제한/상태별 전체 kW/이벤트 시간 → 시간·kWh 계산을 연결했다. 직선/원호 가감속은 독립 구간 정지 모델이며 실제 CNC look-ahead/jerk를 재현하지 않는다. 전체 장비 전력에 기본/주축/펌프 전력을 중복 합산하지 않는다.

제거 발생/미검출·급속·대기·주축/쿨런트 전환·공구 교환·종료별 상태 입력. 회전수/방향/공구/쿨런트와 이벤트 전후 상태를 구분한다. 동일 키의 F·축 방향·제거율은 별도 부하 추정 없이 입력 전력 범위로 포괄한다. G0 소재 접촉 후보/미지원 NC/종료 미정/이동과 주축 변화 혼합은 차단. 공구 교환·종료의 자동 동작은 사용자 이벤트 입력에 한 번만 포함한다.

빈칸 null·전체 합계 미정·알려진 소계 분리, 명시적 0초/0kW 구분. 사용자 가정/측정 입력의 출처·날짜·조건, 별도 검증 운전 총 시간/kWh 비교를 제공하되 자동 보정하지 않는다. 합성 값은 명시 버튼으로만 채운다. 원문/표시점/소재 높이 배열은 에너지 Worker에 중복 전송하지 않는다. 상태200종·Worker30초·revision/인스턴스/취소·입력 무효화·200구간 표/전력 막대→NC 행 선택·JSON 확장.
