# 회사 공동 근무 W1-HR-TIME 구현 결과

2026-10-10. 사용자 승인: 회사 공동 사용, 버튼 출퇴근, 한 시간 단위 시간차, hugh-D Company 관리자 1명·직원 1명. 비밀번호는 PC 터미널에서 직접 입력한다.

## 사용 준비

로컬 DB에 예제 회사와 사원 2명, 계정 연결을 생성했다. 회사 공간은 기존 개인/게스트 공간과 분리한다.

| 아이디 | 회사 권한 | 근무 권한 | 현재 상태 |
|---|---|---|---|
| hugh-admin | OWNER | ADMIN | 최초 비밀번호 설정 대기·로그인 비활성 |
| hugh-staff | MEMBER | STAFF | 최초 비밀번호 설정 대기·로그인 비활성 |

PC 터미널에서 아래 명령을 실행한다. 관리자와 직원의 비밀번호를 각각 10자 이상으로 입력하고 확인한다. 입력 내용은 화면에 표시되지 않는다. 이미 활성화된 계정은 덮어쓰지 않는다.

```sh
cd /Users/hwang-kyoungho/projects/factory-studio
uv run --project backend --env-file .env python tools/create_work_company.py --activate
```

로그인한 다음 [내 근무](http://localhost:5173/hr/work)를 연다. HR 전체 메뉴의 H-16 내 근무 / H-17 근무 체험에서 접근하거나 내 공간 즐겨찾기에 추가할 수 있다. GW 전체 메뉴에도 바로가기를 제공한다. [체험 화면](http://localhost:5173/hr/work-demo)은 게스트도 이용하며, 합성 기록은 회사 DB에 저장하지 않는다.

## 구현한 흐름

- 출근·퇴근 버튼: 서버 시각 저장, 중복·동시 출근 방지, 야간 퇴근 지원, 실패 요청은 같은 요청 키로 재시도.
- 휴가: 연차·오전/오후 반차·1시간 단위 시간차. 휴게시간과 주말/공휴일 제외, 중복 기간·잔여 초과 차단. 출장은 목적지를 입력하며 연차를 차감하지 않는다.
- 직원은 본인 기록만 조회한다. 관리자는 회사 직원 기록 조회, 휴가 승인/반려, 이유를 남기는 기록 정정, 종료된 월 마감을 수행한다. 본인 신청은 본인이 승인하지 못한다.
- 승인된 휴가 취소는 취소 승인까지 잔여를 유지하고 관리자 승인 때 한 번만 반환한다. 마감된 월 기록은 수정하지 않는다.
- PWA manifest·192/512 PNG 아이콘·홈 화면 실행 경로 제공. 오프라인 안내만 캐시하며 API/인증/근무 응답과 출퇴근 제출은 캐시하거나 대기열에 넣지 않는다.

예제 정책은 09~18시, 휴게 12~13시, 올해 연차 15일(120시간). 오전 반차 09~14시(휴게 포함), 오후 반차 14~18시. 향후 연도 연차 자동 부여·회사 정책 편집·추가 직원 초대 화면은 이번 초기 2인 구성에 포함하지 않는다. 관리자 자신의 휴가를 승인하려면 별도 승인자가 필요하다.

## 검증 및 적용

- 회사 근무 API 테스트 9개 + 준비/활성화 테스트 1개 통과. 권한·위조 회사/사원·동시 출근·멱등·승인 취소·잔여·마감·정정 확인.
- 전체 backend 회귀 최초 실행: 991 통과 / 1 건너뜀 / CHECK 정규화 비교 1 실패. 후속 revision hr_time_check로 보정 후 스키마 검증 9개 + 활성화 검증 1개 통과. 기존 적용 revision의 SQL은 변경하지 않았다.
- frontend 전체 580개 통과. 관리자 정정 시 초/밀리초 보존, 실제 게스트 차단·합성 승인·2시간 차감·오프라인 제출 차단 포함. typecheck/eslint/prettier/build 통과.
- 성능 회귀 1개 통과. 도구 테스트 133개 통과. 실제 181테이블/433FK 및 목표 369테이블/887FK 정적 검증 오류 0. DB 설계서와 실제/목표 ERD 갱신.
- 별도 테스트 DB에서 이전 head로 downgrade 후 이전 명세 대조, 최종 head 재적용/대조 모두 오류 0. 로컬 기존 DB 백업 후 head hr_time_check 적용·명세 대조 오류 0.
- Chrome 배포 빌드+별도 테스트 DB 실제 API에서 직원 로그인→출근→퇴근, 관리자 로그인→직원 기록 조회→이력 정정 확인. 390px에서 가로 넘침 없음. 화면 증거는 전부 합성 테스트 DB다.
- PWA API GET/POST 캐시 우회와 네트워크 실패 시 오프라인 안내 동작 검증. manifest/SW/아이콘 HTTP200·정확한 192/512 크기 확인.

운영 사이트에는 이번 기능을 아직 배포하지 않았다. 휴대폰 설치는 HTTPS 운영 반영 후 Android/iPhone 기기에서 별도 확인해야 한다. 로컬 회사 계정은 운영 DB로 자동 복제하지 않는다. 기존 개인 AUTO 근태/급여와 회사 실제 원장의 통합도 별도 단계다.
