## 권한과 저장의 핵심 차이

- GW 합성 담당자는 인증 계정과 별개다. HR에서 가져온 사람 코드도 실제 로그인 계정 연결을 대신하지 않는다.
- Flow의 회사 소유자(core membership OWNER), 보드 소유자/편집자, HR의 회사 관리자(work_role ADMIN), 플랫폼 ADMIN은 서로 다른 권한이다. HR 권한 변경은 회사 membership OWNER를 자동 부여하지 않는다. 회사 소유자는 관리/복구 권한이 있어도 일반 업무 편집은 보드 역할을 따진다.
- PWA 총 관리자(운영상 admin)는 모든 회사 사용자 관리가 가능하지만 회사 소속·근무 사원 연결 없이 근무 기록을 쓰지 못한다. 회사 등록의 첫 관리자에는 플랫폼 ADMIN을 부여하지 않는다.
- CAD 설계는 공간·세대별 브라우저 저장/파일 다운로드, NC와 공장 시연은 메모리/다운로드, GW는 개인 공간 서버 원장, Flow·내 근무는 회사 공유 서버 원장이다. 근무 체험은 메모리 합성 예제로 승인된 실제 신청의 취소 승인과 다르게 즉시 취소한다.
- Flow ‘삭제’는 보관이다. 부모와 함께 보관된 하위 업무는 같은 보관 시각의 묶음만 함께 복구하며 이전에 따로 보관한 자식은 그대로 둔다. 댓글 삭제 표시에는 사용자 복구 버튼이 없다.
