# UI-DESIGN-02 적용 결과

2026-10-09. 사용자의 “추천안 대로 진행”으로 전체 구조 확인 후 구현. [승인된 검토안](../ui/UI개선_전체검토안_UI-DESIGN-01.md). 로컬 main, 운영 배포 없음.

## 무엇이 바뀌었나

- **랜딩 / Taste**: 임의 영문 번호와 “올인원” 제목을 실제 기능 설명으로 대체. 별칭 체험·로그인은 왼쪽, 제조 업무/CAD·CAM/공장 설명과 최신 공개 합성 NC 화면은 오른쪽. 기존 게스트·로그인 요청/멱등·오류·별칭·개인정보 안내 보존. 기존 shared/styles는 수정하지 않고 Entry.css에 범위 한정.
- **CAD 셸**: 헤더와 뷰 전환 간격 축소, 도움말 위치·초점 정돈, iframe 최소 높이 감소. iframe의 저장 scope·관리자 제한·microphone 정책 보존.
- **NC / Impeccable**: 기존 DOM 노드를 이동해 이벤트·값·분석 참조를 유지. 준비4단계/중앙 경로·재생/오른쪽 휴디·품질 제안·시간·소재 결과. 상세 입력과 근거 접기, 데스크톱 열 높이를 작업 공간에 맞추고 모바일 순차 배치. 기존 입력 변경 무효화·품질 차단·후보 번호·원본 보존 유지.
- **E1/E2**: 기존 도구/캔버스/속성 구조에 공통 초점·버튼·입력·색/패널 구분. E2 실행 취소/다시 실행을 생성 도구와 분리하고 변경 적용을 강조. 캔버스 크기 변경 시 넘침 방지. 편집 커널이나 공정 기능 변경 없음.
- **3D 공장**: 상단 보기/탐색, 하단 시연 재생/초기화, 선택 설비 상세를 뷰포트 옆에 배치. 공정 목록 제목과 패널 간격 정돈. 기존 3D 모델·시연 상태·키보드·CNC 조건/오류 복구 보존.

## 검증

- CAD **142개**, 프런트 **551개/68파일** 통과. 병행 MES 테스트가 포함된 전체 프런트 결과이며 해당 MES 수정은 이번 커밋에서 제외.
- 전체 build·공개/비공개 CAD 자산 격리, 대상 ESLint·Prettier·git diff 검사. 기존 큰 번들 경고 유지.
- NC DOM 재배치 뒤 입력값·노드 참조·click listener 보존 테스트 추가.
- 실제 Chrome(headless) 합성 NC→STEP→소재→에너지→3후보→휴디 텍스트3번→재생/정지. 좌측 접기/펼치기 이후 실제 분석 결과 확인. 최종 데스크톱 NC 열 높이780px/뷰포트900px·문서900px로 불필요한 전체 페이지 확장 없음.
- Chrome 랜딩 로그인 표시·공장 렌더/내부/일시정지/CNC 패널, E1/E2 작업 공간과 390px 넘침 확인. E2 canvas의 크기 변경 순간 넘침은 max-width로 보정. 테스트 스크립트의 숨겨진 첫 canvas·아직 읽는 STEP·접힌 텍스트 폼 선택 오류는 올바른 준비/선택 순서로 수정해 재검증.
- 공장 브라우저 회귀4종: 장면·CNC 1개 완료/정지/오류 복구·모바일 정지/검사실 통과. 외관/내부/모바일 전환은 소프트웨어 WebGL 캡처에서30초 제한 초과→60초로 재실행33.3초 통과. 동일 테스트의 제한을60초로 명시. 모바일 재확인25.6초 통과. 기능 단정을 위해 시간을 무제한으로 늘리지 않았다.
