## 범위

`GET /api/v1/fems/dashboard?month=YYYY-MM` 하나로 F-01 전체를 채운다. 조회 시 계산, 저장하지 않는다. FEMS 진행 7/14(F-01·F-02·F-03·F-04·F-10·F-11·F-14). FEMS 진입(`/fems`)은 이제 F-01이다.

## 계산 규칙

| 항목 | 규칙 |
|---|---|
| 기간 | 월 단위. 기본은 최근 계측일이 속한 달의 1일 ~ 그날(당월 누계). 과거 달은 달 전체 |
| 총 소비 (TOE) | 최상위 계측기 소비량 × 연도별 **PRIMARY** 계수, 에너지원별 환산 **후에만** 합산(AGENTS §3). 용수(UTILITY)는 대상 아님. F-04와 같은 함수(`_converted`)를 계수 종류만 바꿔 쓴다 |
| 목표 대비 | 사업장 TOE 목표(에너지원 NULL, FS-005g 5.5) 대비 달성률 = 실적 ÷ 목표 × 100. 100 이하 "목표 이내", 초과 "목표 초과". 목표 없으면 "미설정"이고 달성률을 계산하지 않는다(FS-008a F-07) |
| 예상 요금 | 요금 부과 대상(`is_billable`) 에너지원별 `기본요금 + 당월 누계 사용량 × 단가`, 원 단위 반올림. 그 달에 적용되는 요금제(F-14 기간)를 쓴다. 요금제 없으면 `TARIFF_MISSING`, 합계에서 빼고 `complete=false` |
| 배출량 | F-04 계산과 동일(테스트로 두 API 합계 일치 확인) |
| 에너지원별 구성 | TOE 환산값의 비중 막대. 용수는 막대에서 빼고 "환산 대상 아님 (340 m3)" |
| 일자별 추이 | 날짜별 TOE 합(사업장 시간대 날짜). 선 그래프, 십자선 안내 |
| 설비 상위 5 | F-03 합계에서 kWh만, 내림차순 5개. F-03 링크 |
| 품질 이상 | 하위 계측기를 포함한 모든 채널의 `quality<>'valid'` 건수 + 최근 5건. F-02 링크 |
| 빈 상태 | 계측값이 전혀 없으면 F-11 에너지원 등록으로 안내 |

시드 결과(9월 누계): 총 12.365 TOE, 목표 12.489 → 99.0% 목표 이내 / 8월 104.2% 목표 초과(FS-018e 비율표 효과), 요금 8,345,117원(전력 TR-ELEC-02), 배출 24.99 tCO2eq, 품질 이상 6건.
