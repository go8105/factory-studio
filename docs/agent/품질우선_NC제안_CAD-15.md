## 구현

[계약](../modules/cad-cam/품질우선_NC제안_설계_CAD-15.md). `/cad-cam?view=nc`의 시간·소비 분석 아래 품질 기준 → G4 대기 목록 → 목적/최소 유지 시간/영향 확인 → 원본과 후보 비교를 추가했다. 현재 NC/소재/전체 에너지 결과 필수, 기준 잔삭 높이·과절삭 깊이·격자 체적 오차 초과 또는 위험/근거 미확인은 소비 비교보다 먼저 차단한다. 셀 중심 형상 기준을 실제 공차/Ra·기계 안전 검증으로 표현하지 않는다.

초기 후보는 상태 변화 없는 단독 G4만, 공정 최소시간을 사용자가 확인한 대기 개별/조합 시나리오다. 모든 이동·F/S/T·주축/쿨런트/교환/종료 이벤트와 원본을 보존한다. 대기 없음/미확인/혼합 상태는 이유를 표시한다. 비절삭이라고 추측해 이송을 빨리 하거나 주축/쿨런트를 자동 정지하지 않는다. NC 자동 편집·적용/실행 파일 출력 없음.

같은 CAD-14 상태별 장비 전체 전력 범위와 불변 구간을 독립 합산한다. 후보 최대 + 사용자 추가 비교 여유 < 원본 최소일 때만 입력 범위의 소비 감소 후보. 범위 겹침·경계 같음·추가 여유 미정이면 우열 판단 불가. 실제 절감률/통계적 신뢰구간/단일 최적 후보를 선언하지 않는다. 원본·후보 시간/kWh·대기 시간/소비 감소·조건/근거/차단 이유·NC 행 연결·JSON 기록. 입력 변경 시 결과 무효화, NC/소재/장비 변경은 대기별 확인도 초기화한다. 목록200행 페이지·최대12선택/13후보.
