# FLOW-03 실제 Figma 동작 기준 인라인 생성 보정 (2026-10-11)

사용자가 열린 Figma Make에서 직접 확인하도록 요청한 뒤 동일 동작 반영을 승인했다. Figma의 부모 왼쪽 +는 팝업이 아니라 새 하위 업무를 부모 아래에 생성하고 이름 입력에 초점을 준다. 일반 요약 카드는 약96×72px, 진행률 카드는160×72px로 측정했다.

## 구현

- 업무 추가 모달 제거. 상단 새 업무·그룹별 업무 추가·부모 왼쪽 +·상세의 하위 업무 추가가 기존 task-create API로 기본 제목 행을 생성하고 인라인 편집을 연다.
- 새 그룹 생성 후 그룹명 인라인 편집 자동 시작. Enter/포커스 이탈 저장, Escape 이름 수정 취소. Escape는 이미 생성한 행을 삭제하지 않는다.
- 생성한 행이 보이도록 대상 그룹/하위 목록 펼침, 검색·상태·내 업무 필터 해제, 메인 테이블 전환. 날짜·담당자는 실제 지정 전 미정/미지정 유지.
- 즉시 mutation 잠금으로 연속 클릭 중복 전송 방지, 기존 멱등키·권한·API 저장/집계 유지. 업무명 저장 실패 시 입력 유지/재시도, IME 조합 중 Enter 저장 방지.
- 요약3카드96×72px, 진행률160×72px·숫자20px·8px간격. UI 외 DB/API 변경 없음.
