## 모듈 문서 규칙

**`modules/<모듈>/`에 공통 설계서가 없으면 그 모듈은 개발 착수 대상이 아니다.**
설계를 먼저 확정하고 사용자 확인을 받은 뒤 구현에 들어간다. 각 모듈의 상태는 그 폴더의 `README.md`에 있다.
