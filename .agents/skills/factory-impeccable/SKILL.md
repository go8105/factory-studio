# Factory Studio Impeccable

[원본과 수정](ORIGIN.md) · [원문](reference/upstream-SKILL.md). 정적 지침으로 사용한다. CLI launcher, hook, 다운로드, 자동 agent 생성 없이 현재 세션 도구로 작업한다. 참고 문서의 원본 실행 명령도 적용하지 않는다.

## 프로젝트 문맥

- AGENTS.md와 docs/plan/현재기획_진행현황.md가 우선한다. FS-013의 독립 솔루션 구조를 유지한다. 새 PRODUCT.md나 디자인 문서를 기준본으로 대신하지 않는다.
- CAD·CAM과 3D 공장은 **Operate**, 도움말은 **Read**, 랜딩은 **Persuade**로 다룬다. 랜딩의 시각 방향은 factory-taste를 적용한다.
- 기존 React/Vite/CSS·단색 SVG·한글 글꼴·백자 #F7F7F6/먹색 #1A1C1E/쪽빛 #1F2D3D·최대 4% 그림자를 지킨다. 디자인만을 위한 의존성 교체는 하지 않는다.
- 새로운 구조는 전체 설계 확인 후 제품 코드에 반영한다. 범위 밖 솔루션·인증·DB·권한·공정 모델을 바꾸지 않는다.

## 작업

1. 코드와 현재 화면을 읽고 사용자의 첫 작업과 막히는 지점을 기록한다. 분석에는 [operate](reference/operate.md), [critique](reference/critique.md), [layout](reference/layout.md), [clarify](reference/clarify.md)를 필요할 때 읽는다.
2. CAD는 도구/캔버스/속성의 위계, NC는 입력→경로·소재→시간·전력→품질 제안의 흐름을 유지한다. 뷰포트를 우선하고 상세 입력은 단계별로 표시한다. 휴디·재생·정지는 결과와 가까이 둔다.
3. 공장은 보기 전환/탐색/시연/선택 설비 조작을 구분한다. 화면 밖·탭 비활성 일시정지, 키보드 초점, CNC 안전 상태와 그래픽 실패 안내를 보존한다.
4. 도움말은 현행 구현만 설명한다. 미지원 G-code, 추정 kWh, 제한 STEP/소재 모델과 실제 CNC 실행의 차이를 분명히 한다. 관리자 전용 제품 파일·설계는 공개 문서에 싣지 않는다.
5. 제품 코드 편집 직전에 [craft-floor](reference/craft-floor.md)를 읽는다. 다만 기존 글꼴·색상·그림자·시연 번호 등 프로젝트 요구가 원본 미학 금지보다 우선한다.
6. 결과는 빈 상태/입력 오류/차단/분석 중/완료/결과 무효화/마이크 실패까지 포함한다. 상태를 색만으로 전달하지 않는다. 클릭·키보드·모바일 흐름을 확인한다.

## 품질

일반 글자 대비 4.5:1, 큰 글자 3:1. 읽을 수 있는 크기와 숫자 정렬, 초점 표시, 라벨·오류 연결, 모바일 넘침과 스크롤을 점검한다. 모션은 의미 있는 상태 변화에만 150–250ms, reduced-motion 지원. 3D 렌더링과 장식 애니메이션을 경쟁시키지 않는다. 실제 시연과 모의 검증을 구별하고 검증 결과·미검증 항목을 기록한다. 분석·검토 시제품을 제품 구현 완료로 보고하지 않는다.
