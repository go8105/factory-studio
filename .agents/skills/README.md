# Factory Studio 디자인 스킬

이 저장소 전용 Codex 호환 스킬이다. 다음 턴부터 프로젝트 스킬로 사용한다. Claude 전용 커맨드나 별도 런타임을 설치하지 않았다.

- [factory-taste](factory-taste/SKILL.md): 랜딩 페이지의 제품 중심 문구와 절제된 구성.
- [factory-impeccable](factory-impeccable/SKILL.md): CAD·CAM·3D 공장 작업 UI와 도움말.

원본 revision·라이선스·수정은 각각 ORIGIN.md에 기록했다. 참고 문서의 원본 CLI·hook·서브에이전트 호출은 실행 지시가 아니다. AGENTS.md와 현재 기획이 항상 우선한다.

호출 예: “factory-taste로 랜딩을 개선해줘”, “factory-impeccable로 NC 화면을 점검해줘”. 새 구조 구현은 UI-DESIGN-01 전체 검토안의 사용자 확인 후 진행한다.
