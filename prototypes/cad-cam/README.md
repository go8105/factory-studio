# Form Studio — 직접 편집하는 웹 CAD·CAM 시제품 (CAD-01)

사용자가 직접 스케치를 그리고 치수를 바꾸며 부품을 설계하고, 그 설계로 소재 제거를 재생하는 독립 웹 편집기다. 미리 만든 제품의 작동 애니메이션이 아니다. Factory Studio 운영 frontend/API/DB와 분리된 검토 시제품이며 17개 솔루션 개발 재개·운영 배포를 의미하지 않는다.

## 실행

Node.js 22.12 이상이 필요하다. 실제 검증 환경은 Node 26.7.0이다.

```sh
cd prototypes/cad-cam
npm ci
npm run dev
```

브라우저: http://127.0.0.1:5241/ (이 컴퓨터에서만 접근).

```sh
npm test
npm run build
npm run format:check
```

`dist/`는 정적 웹 빌드다. 운영 서버에 게시하지 않았다. 로컬 자동 저장은 이 브라우저/주소의 저장소이며 장기 보관은 JSON 저장을 사용한다.

## 직접 사용하기

1. **사각형/원**: 작업면을 드래그한다. 사각형은 대각선, 원은 중심→반지름이다. 1mm 스냅을 적용한다. 드래그 대신 오른쪽 숫자로 시작해도 된다.
2. **돌출 만들기**: 첫 스케치의 폭/길이/반경/높이를 정한다.
3. **파내기 적용**: 새 스케치를 그리고 깊이를 정한다. 깊이는 기본 돌출 윗면에서 측정하며, 높이와 같으면 관통한다.
4. **치수 편집**: 탐색기/작업 이력/3D 형상을 선택한다. 복제·삭제·실행 취소·다시 실행을 제공한다. 새 설계와 연습 부품 전환도 실행 취소할 수 있다(동일 페이지 세션, 최대 50단계).
5. **가공 시뮬레이션**: 평 엔드밀 지름, 깊이 간격, 가로 간격, 이송 속도, 안전 높이를 설정하고 경로를 생성한다. 재생/정지/속도/진행률 탐색/처음으로를 제공한다.
6. **저장/열기**: `design.form.json`에 치수와 작업 이력이 저장된다. **STL**은 mm 기준 삼각형 메시를 내보낸다. STL에는 편집 이력이 없다.

## 구현 경계와 구조

- `src/model.js`: 사각형·둥근 사각형·원, 깊이별 2D 폴리곤 차집합, 형상/파일 검증, CAM 경로, 소재 제거 수학.
- `src/viewer.js`: Three.js 표시, 깊이별 단면에서 닫힌 표면 생성, STL 출력, 격자 소재 표시. B-Rep 정밀 CAD 커널은 사용하지 않는다. 원호는 폴리곤으로 근사한다.
- `src/main.js`: 편집 상태, 포인터 스케치, 숫자 입력, undo/redo, 로컬 저장, 파일 입출력, 작업 모드.
- `src/simulation.worker.js`: UI와 분리해 공구 원통이 지나간 소재 기둥 높이를 감소시킨다. 역방향 탐색 시 원소재에서 재계산한다. 요청 버전으로 오래된 결과를 배제한다.
- `tests/geometry.test.js`: JSON/부피/중첩/관통/경로 범위/부피 감소/실제 worker 되감기 검증.

**CAD 범위:** 단일 기본 돌출 + 최대 32개 상면 홈. 자유 선/곡면, 추가 보스 돌출, 임의 면 스케치, 구속 솔버, 조립, STEP 가져오기/내보내기는 없다. 부품 크기 최대 200×200×80mm. 홈은 기본 외곽 안에서 최소 0.1mm 벽을 남긴다. 서로 겹치는 홈은 지원한다.

**CAM 범위:** 이미 기본 외형으로 준비된 소재의 상면 포켓 밀링이다. 외곽 절삭·소재 뒤집기·다축·사출 금형·비누 분쇄 동작을 시뮬레이션하지 않는다. 공구 중심을 반경만큼 안쪽으로 이동시키고 깊이별 왕복 경로와 윤곽 마무리 경로를 만든다. 급속 XY 이동은 안전 높이에서만 한다. 진입은 단순 수직 플런지이며 실제 가공 조건을 보증하지 않는다. 공구가 홈보다 크면 계산을 거부하고, 공구 반경보다 작은 사각 모서리는 잔삭을 안내한다. 최대 경로점 60,000개.

**소재 제거:** 평 엔드밀의 원통형 쓸림을 높이장 격자로 근사한다. 셀 크기는 `max(0.4mm, 폭/150, 길이/150)`을 기준으로 정하고 실제 크기를 화면에 표시한다. 표면의 계단과 부피 오차가 발생한다. 절삭력·재질·날 길이·홀더/고정구/장비 충돌은 계산하지 않는다. 이송 시간은 길이/속도 기반 추정(급속 3,000mm/min 가정)이며 가감속·공구 교환을 포함하지 않는다. 기계용 NC를 출력하지 않는다.

## 데이터

설계는 로컬 메모리·브라우저 저장소·사용자가 내려받는 파일에만 보관한다. 서버 API/계정/원격 저장/외부 폰트 요청은 없다. 참고 PDF와 개인·사업 정보는 포함하지 않는다. ‘포켓 연습 부품’은 프로그램 설명용 합성 예제이며 비누 그라인더의 확정 설계가 아니다.

## 검증 상태

작업 최종 검증 기록은 `../../docs/agent/CAD_CAM_편집기_CAD-01.md`를 참조한다. 실물 가공·정밀 CAD 파일 호환·Safari/실기기 검증과 운영 배포는 별도다.

## POC-03 관리자 비누 설계실

포털 `/cad-cam?view=soap`에서 MEMBER+ADMIN만 사용할 수 있다. 페이지·STL·ZIP은 인증 API로 제공하며 공개 빌드에 넣지 않는다. 일반 편집기의 설계 저장은 브라우저에 유지한다.

최신 모델은 유연한 외피/상부 커버/하단 스킨과 단단한 마찰판·가이드, 완전 분리 가루통으로 구성된다. `npm run poc:flex`로 9개 부품을 생성한다. 원본과 안내는 `private/soap-poc/`, ZIP 재생성은 프로젝트 루트에서 `python3 tools/package-soap-flex.py`이다.

포털 빌드: `cd frontend && npm run build` (Node 24). 공개 편집기는 `frontend/public/cad-cam-app`, 보호 자료는 `backend/private-assets/soap-poc`에 생성된다. 후자는 정적 공개 경로에 연결하지 않는다. 실행·권한 검증·배포는 [공통 설계](../../docs/modules/cad-cam/README.md)를 따른다.

누름/비틀림 화면은 동작 설명용이며 실제 탄성·분쇄·마모·방수 해석이 아니다. 이전 POC-01/02는 private 자료의 설계 이력이다.
