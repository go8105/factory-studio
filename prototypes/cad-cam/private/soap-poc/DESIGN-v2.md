# POC-02 · 접이식 비누 그라인더 재설계

## 확정된 방향
사용자 이미지/설명과 추가 답변: 접이식 케이스, 내부 회전 마찰판, 완전히 분리되는 서랍형 가루통.
이미지의 PP/ABS/TPU 표기는 재료 후보 설명이며 검증 성적서가 아니다.
고정 힌지를 비트는 대신, 뚜껑의 돌기가 비누를 잡고 아래 원판만 움직인다.
이 파일은 제작 검토용 디지털 설계이며 성능이 확정된 양산 도면이 아니다.

## 부품·조립
| 부품 | 주요 치수/동작 |
|---|---|
| 본체 body-v2 | 폭86×길이106×높이39 mm, 측면 손가락 창, 원판 받침과 서랍 통로 |
| 뚜껑 lid-v2 | 상부 고정 돌기24개, 힌지축 Y56/Z39, 열림0~110° |
| 회전판 rotor-v2 | 지름68, 바닥3, 마찰 돌기1 mm, 배출 슬롯1.2×4 mm, 회전 가능 |
| 가루통 drawer-v2 | 몸통72.8×99.8×10.2, 바닥2, 전면 손잡이 포함; 앞 방향115 mm 이동시 완전 분리 |
| 힌지 핀 hinge-pin-v2 | 지름3×길이60; 구멍3.8; 착탈형, 별도 빠짐방지 캡은 다음 검증 대상 |

시험 비누 가정은50×40×18 mm다. 모든 판매 비누가 들어간다는 주장이 아니다.
닫힘 높이는약43 mm이며 빈 상태도 같은 높이이다. '빈 케이스를 더 얇게 접기'는 아직 지원하지 않는다.
뚜껑을 손으로 눌러 비누를 잡고 측면 창의 원판 테두리를 조금씩 돌리는 시험 구조다.
비누가 닳으면 접촉이 약해지므로 가압판/스프링 또는 교체 스페이서는 추가 설계가 필요하다.
현재는 수동 가압·초기 두께의 마찰 원리 검증용이며 연속 사용 제품의 완성 기구가 아니다.
서랍 통로의 위/아래 지지면으로 직선 이동한다. 잠금/이탈 방지 래치는 아직 없다.

## 제조 검토
일반 FDM 노즐0.4 / 층0.2 mm 가정. PETG는 끼움·동작 검토 후보다.
이미지처럼 최종 PP 케이스·ABS 마찰부·TPU 힌지를 사용하려면 마찰 마모·비누 성분·세척·내구 검증이 필요하다.
현재 힌지는 연질 일체 힌지 대신 출력 검토가 쉬운 분리 핀 방식으로 모델링했다.
본체 서랍 위 천장과 뚜껑 힌지에는 서포트 검토가 필요하다. STL의 바닥 배치는 출력 성공 보증이 아니다.
원판은 평평한 면 아래, 가루통은 바닥 아래로 배치한다. 핀은 눕혀 출력/지지 조건을 검토한다.
서랍 편측 여유0.6, 원판 반경 여유0.4 mm는 시작 가정이며 출력 업체 공차에 맞춰 조정한다.
몸통은 서랍이 빠진 채 출력하고 서포트를 통로에서 완전히 제거한 뒤 조립한다.
물 배출구/측면 창/틈이 있으므로 방수 제품으로 주장하지 않는다. 씻은 뒤 완전히 말린다.

## 실물 검증
1. 비누 없이 힌지·핀·회전판·서랍의 끼움과 손걸림, 지지부 강성 검사.
2. 가루통 완전 분리/재삽입, 핀 빠짐, 서랍 이탈을 확인한다.
3. 동일 비누·동일 회전 횟수에서 수집 질량·막힘·필요한 힘·돌기 마모/혼입 기록.
4. 돌기가 깨지거나 플라스틱 혼입이 생기면 중단한다. 시험 분말은 신체 사용용이 아니다.
5. 닳은 비누의 가압/고정, 래치, 휴대 누출·세척을 다음 설계 게이트로 검증한다.

## 검증 범위와 소스
Manifold 정상 솔리드·단일 연결체·양의 체적, 내보낸 STL 폐곡면/방향 검사를 수행한다.
assembly-v2.json에는 뚜껑·원판·서랍의 표본 자세 간섭 결과가 있다. 연속 운동/변형/공차 해석이 아니다.
Node>=22.12. ZIP을 새 폴더에 풀고 `npm ci` 후 `node tools/build-soap-assembly.mjs`.
재생성 STL은 private/soap-poc에 생성된다. 웹 프로그램 전체는 ZIP에 포함하지 않는다.
