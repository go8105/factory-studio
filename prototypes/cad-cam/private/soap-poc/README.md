# POC-01 · 플라스틱 비누 마찰판 실험

디지털 시험편 설계. 실물 출력·절삭·마모·내구 성능은 아직 검증하지 않았다.
지원서의 플라스틱만으로 건조 비누를 분쇄하는 원리를 먼저 검증한다.
최종 휴대용 회전 제품·방수 제품·생산 도면이 아니다. 모든 치수는 새 시험 가정이다.

## 제작 순서
3D CAD 설계 → STL(mm) → 출력 업체/프린터 슬라이서 → FDM 출력 → 실험.
CAD는 설계 방법, 3D 프린팅은 제작 방법이다. CNC 가공 CAM은 이번 출력에 필요하지 않다.
웹 CAD-01의 CNC 소재 제거 재생을 FDM 출력 시뮬레이션으로 사용하지 않는다.

## 부품
- tray.stl: 84×64×14 mm, 바닥2.4, 외벽2.4, 판 받침 높이10.
- plate-A/B/C.stl: 78.4×58.4, 바닥3, 돌기 높이0.6/1.0/1.4 mm.
- 판당 35개의 방향성 쐐기 돌기, 피치8, 돌기 폭3×4, 인접 배출 슬롯1.2×4 mm.
- 조립시 판 바닥 Z=10, 테두리 편측 간극0.4. 체결/잠금 없음. 트레이를 고정하고 시험한다.
- 작은 비누 조각20×18×8 mm를 중앙에서 +X 방향으로 문지른다. 돌아올 때 들어 올린다.
- A의 돌기 끝은 트레이 림보다 낮다. 큰 비누는 림에 걸리므로 전체 비누 호환 시험이 아니다.
- 슬롯 위쪽에 0.3 mm 연결부가 있다. FDM 표현/마모를 슬라이서와 실물에서 확인한다.

## 일반 FDM 가정 (장비 확정 후 조정)
- 노즐0.4 / 층0.2 mm. PETG를 기능 시험 후보로, PLA를 초기 끼움 확인 후보로 제안한다.
- A/B/C를 동일 프린터·필라멘트·방향·벽/채움 설정으로 출력한다. 재료 비교는 별도 실험.
- 평평한 바닥을 빌드판에 둔다. 서포트 없이 설계했으나 슬라이서 층별 미리보기 확인 필수.
- 벽4줄 / 채움40%를 시작 가정으로 삼되 얇은 돌기 경로 누락이 없는지 확인한다.
- 온도·속도·건조·베드 조건은 실제 필라멘트/프린터 제조사 프로파일에 따른다. G-code 미제공.
- 치수·슬롯 개방·돌기 재현·평탄도·판 끼움부터 확인. 안 맞으면 억지 조립하지 않는다.
- PETG의 일반 기계부품 용도는 비누 절삭/내마모 적합성의 증거가 아니다.

## 실험 (측정표 CSV 사용)
1. 건조 조건/비누 종류/출력 설정을 기록한다. 우선 같은 비누로 세 판을 비교한다.
2. 트레이 고정. 손이 돌기에 닿지 않게 비누를 잡을 도구를 사용한다.
3. 같은 스트로크 길이30 mm, 편도20회, 유사한 누름 힘으로 시험하고 시간·수집 질량을 측정한다.
4. 각 판3회 반복, 순서를 바꾼다. 이후 서로 다른 비누5종으로 확대한다.
5. g/회·g/초, 막힘, 필요한 힘, 돌기 깨짐/마모·플라스틱 혼입을 기록한다.
6. 깨짐/혼입이 보이면 중단한다. 시험 분말은 신체 사용용으로 제공하지 않는다.
7. 정량 합격 기준은 필요한 1회 사용량/사용 힘을 정한 후 확정한다. 이 자료는 성능을 주장하지 않는다.

좋은 결과면 회전 본체·비누 고정·누름·배출·분해세척 구조를 다음 작업에서 설계한다.
양산 사출과 최종 수지는 마모/비누 성분/세척/DFM 검증 후 결정한다.

## 수정과 검증
소스: prototypes/cad-cam/tools/build-soap-poc.mjs. Node>=22.12.
해당 프로젝트에서 npm ci → npm run poc:build → npm test → npm run build.
생성기 치수를 수정한 후 재생성한다. 현재 웹 페이지는 형상/조립 검토용이며 파라미터 편집기는 아니다.
형상 보고서는 커널 정상 상태·단일 연결체·양의 체적·조립 겹침 없음 확인 결과다.
STL 검사로 폐곡면·방향·양의 체적 확인. 공차·출력 성공·강성·절삭 성능은 보증하지 않는다.

참고: https://help.prusa3d.com/article/petg_2059
https://help.prusa3d.com/article/pla_2062

ZIP 단독 재생성: 압축을 새 폴더에 풀고 `npm ci` → `node tools/build-soap-poc.mjs`.
새 STL은 `public/soap-poc/`에 생성된다. ZIP에는 웹 앱/테스트 소스 전체가 포함되지 않으므로
웹 실행과 `npm test`는 원래 프로젝트에서 수행한다.
