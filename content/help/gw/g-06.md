# G-06 결재선 템플릿

담당자를 등록한 뒤 이름과 결재 참여자를 지정합니다. 서로 다른 참여자 최대 30명을 1~3단계에 배치합니다. 단계는 1부터 연속이어야 하며 각 단계에는 결재 담당자가 필요합니다.

동일 단계의 결재·합의는 병렬로 진행됩니다. 모두 끝나야 다음 단계로 넘어가며 참고 의견은 진행을 막지 않습니다. 각 참여자의 단계를 따로 지정하세요. 위·아래 이동은 입력 순서만 바꿉니다.

템플릿 수정은 이미 기안된 문서를 바꾸지 않습니다. 초안에서 결재선을 다시 선택해야 반영됩니다. 상신하면 참여자를 고정합니다. 기존 v1 문서는 순차 결재선만 이용할 수 있습니다.
