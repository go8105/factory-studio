# G-03 결재함

담당자를 선택하면 현재 단계에서 직접 또는 위임받아 처리할 문서가 표시됩니다.

결재 담당자는 승인·반려, 합의 담당자는 합의·합의 반대, 참고 담당자는 참고 의견을 남깁니다. 같은 단계의 필수 결재·합의가 모두 끝나야 다음 단계로 넘어갑니다. 참고 의견은 필수가 아니며 진행 종료 시 생략됩니다. 합의 반대는 반려로 종결됩니다.

위임은 처리 시점의 기간·종류·KRW 한도를 검사합니다. 여러 원 담당자를 대리하면 처리할 참여자를 선택합니다. 처리 이력에는 원 담당자와 대리 담당자가 남습니다. 버전 충돌이 발생하면 ‘서버 상태 다시 확인’으로 최신 문서를 확인하고 재시도합니다.
