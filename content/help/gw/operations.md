# 회사 GW 운영 준비 · 보관·복구 기준

## 진입과 권한

회사 GW 공간을 선택한 뒤 **회사 운영 안내 → 운영 준비**로 이동합니다. 활성 GW 보안 관리자는 기준을 적용할 수 있고 보안 사건 조회 역할은 읽기만 가능합니다. 회사 소유자·총 관리자라는 이유로 GW 역할이나 비공개 문서 열람 권한을 자동 부여하지 않습니다. 일반 직원은 자신의 계정 보안 안내만 확인할 수 있습니다.

## 현재 표시와 제한

직원 본인 연결 수와 그중 인증 앱 등록 수를 서버가 계산합니다. 예정 인원은 용량 한도가 아닌 도입 계획입니다. 화면에 남은 조건이 표시되며, 백업·복원과 실환경 인수 연결이 끝나기 전에는 운영 준비 완료가 되지 않습니다. 실제 검사 없이 체크 표시를 눌러 준비 상태를 통과시킬 수 없습니다.

GW-READY-02 개발 브랜치에서 정책 저장을 구현 중입니다. 암호화 백업 실행·증거 등록, 보관 검토·보존 중지, 실제 운영 전환 화면은 아직 후속이며 이 화면에서 실행되지 않습니다. 로컬 검사와 실서버 반영을 구분합니다.

## 운영 기준 적용 순서

1. **내 계정 보안**을 새 탭에서 열고 앱 번호로 추가 본인 확인을 합니다. 5분 안에 적용해야 합니다.
2. **운영 기준 검토·적용**을 누릅니다.
3. 예정 직원/부서 수, 백업 간격, 허용 손실 시간, 복구 목표 시간, 문서/감사 검토 기한, 백업 보관 기간을 검토합니다.
4. **복구 책임자**는 같은 회사의 활성 직원 연결을 선택합니다. 본인이 준비한 책임자와 실제 보관 장소는 별도로 확인합니다.
5. **적용 사유**를 2~500자로 입력하고 변경 내용과 영향에 동의한 뒤 **새 버전으로 적용**합니다.

초기안은 직원10명/부서1개, 백업30분/허용손실60분/복구목표240분, 문서36개월/감사12개월/백업30일입니다. 기본안은 법정 보존 기간이나 실제 복구 성능 보장이 아닙니다.

## 입력 조건과 저장·취소

- 직원1~10000명, 부서1~1000개, 백업5~1440분, 허용손실1~1440분, 복구목표15~10080분, 문서/감사1~120개월, 백업7~365일의 정수입니다.
- 백업 간격은 허용 손실 시간보다 짧아야 합니다.
- 확정된 기준은 덮어쓰지 않고 새 버전을 추가합니다. 문서 기한은 검토 시점이며 원본을 자동 삭제하지 않습니다.
- **취소**·패널 닫기·Escape는 미저장 변경이 있을 때 버릴지 확인합니다. **계속 편집**은 입력을 유지합니다.
- 동시 변경 오류는 현재 서버 값과 입력을 비교해 다시 검토해야 합니다. 사유나 인증 비밀을 브라우저 영구 저장소에 저장하지 않습니다.
- 추가 본인 확인 오류는 계정 보안에서 다시 확인합니다. 다른 사람을 대신 인증하거나 준비 조건을 우회할 수 없습니다.

## 본인 긴급 복구 문서 준비

현재 GW 보안 관리자에게만 표시됩니다. **내 계정 보안**에서 앱으로 추가 본인 확인을 하고 5분 안에 돌아옵니다.

1. 발급 사유를 2~500자로 입력합니다.
2. 이전 문서와 미사용 승인 번호가 무효가 된다는 안내를 읽고 동의합니다.
3. **본인 긴급 복구 문서 새로 발급**을 누르고 파일을 내려받습니다. 파일에는 복구 비밀이 있으므로 별도 안전한 장소에 보관합니다.
4. 실제 보관을 확인한 뒤 **보관 확인하고 닫기**를 누릅니다. 화면에서 파일 보관 성공을 자동 확인하지는 않습니다.

문서는 365일 또는 계정 보안 버전 변경 전까지 유효합니다. 앱 재등록·복구 코드 재발급·비밀번호 변경·다른 세션 종료 등 보안 변경 뒤에는 새 문서를 준비하세요. 준비 여부와 만료일만 다시 볼 수 있으며 원문을 다시 내려받을 수 없습니다. 응답을 잃었다면 현재 준비 상태를 확인하고 새 사유로 다시 발급합니다. 같은 요청을 재전송해 원문을 복구하지 않습니다.

문서와 비밀번호는 서로 다른 장소에 보관합니다. 실제 사용에는 기존 비밀번호와 서버 운영자의 승인 파일도 필요하며, 직원이나 총 관리자에게 GW 역할을 자동 부여하지 않습니다. 자세한 순서는 [인증 앱·분실 복구](/help/portal/account-security)를 확인합니다.

## 발급량 제한과 관리자 추가 확인

계정별 정상 비밀번호 로그인 발급은 10분에 20회, 새 인증 앱 설정 키와 긴급 문서 발급은 각각 10분에 3회로 제한합니다. 실패 횟수 제한은 별도로 적용합니다. 제한을 만났다면 요청을 반복하지 말고 기다린 뒤 다시 시도하세요.

COMPANY 운영 모드의 직원 연결·역할·결재선·전결·위임·사용자 관리 변경에는 최근 5분 이내 앱 인증이 필요합니다. 운영 기준 적용과 긴급 문서 발급에는 검증 모드에서도 같은 추가 확인이 필요합니다. 일반 직원의 일상 업무마다 재인증을 요구하는 것은 아닙니다.
