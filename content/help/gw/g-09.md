# G-09 결재 위임

> **개인 체험과 회사 GW를 구분하세요.** 아래 담당자 선택 안내는 개인 체험 기준입니다. 회사에서는 로그인한 본인으로 처리하며 회사·객체 권한을 확인합니다. [회사 GW 시작과 권한 안내](/help/gw/company)를 함께 확인하세요.

담당자 역할을 선택한 뒤 자신의 권한을 다른 합성 담당자에게 위임합니다.

시작 시각은 포함하고 종료 시각은 포함하지 않습니다. 종류를 비우면 전체 종류입니다. 한도는 KRW 기준으로 포함합니다. 한도가 있으면 금액 없는 문서나 다른 통화 문서는 대리 처리할 수 없습니다.

자기 위임·연쇄 위임·같은 원 담당자의 겹치는 기간은 허용하지 않습니다. 기안자와 해당 문서의 다른 참여자는 대리 처리할 수 없습니다. 원 담당자의 직접 처리도 가능합니다.

위임받은 담당자로 결재함을 열고 여러 참여자를 대리하면 처리할 참여자를 선택합니다. 이력에는 실제 담당자·원 담당자·위임 번호가 남습니다. 해제 이후 대리 처리할 수 없으며 이미 처리한 기록은 보존됩니다. 정책 v1에는 위임을 적용하지 않습니다. 합성 업무 체험이며 실제 계정 권한이나 전자서명 기능이 아닙니다.
