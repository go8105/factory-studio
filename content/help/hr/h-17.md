# 근무 체험 · 합성 데이터

## 무엇을 체험하나요

앱 런처 → **HR 인사·급여** → 회사 근무 → **근무 체험**에서 출퇴근과 신청 화면을 연습합니다. 게스트도 이용할 수 있습니다. 예제 직원과 회사 표시, 출퇴근 시각, 잔여 연차는 합성 데이터이며 실제 직원 기록이 아닙니다.

## 처음부터 따라하기

1. **체험 역할**을 ‘직원’으로 둡니다. **출근하기**를 누르면 합성 09시 출근과 ‘근무 중’이 표시됩니다. **퇴근하기**는 합성 18시 퇴근을 표시합니다.
2. 종류를 **시간차**, 시작일을 같은 날, 시간은 09:00–10:00으로 고르고 사유에 ‘예제 시간차’를 입력합니다. **신청하기** 뒤 승인 대기 내역을 확인합니다.
3. 체험 역할을 **관리자 · 합성 신청 승인**으로 바꾸고 **승인**을 누릅니다. 기본 120시간에서 1시간 차감된 119시간을 확인합니다.
4. **신청 취소**를 누르면 합성 건은 즉시 취소됩니다. 실제 회사의 승인된 신청은 취소 승인 절차가 필요합니다.
5. **실제 근무로**는 [내 근무](/help/hr/h-16)로 이동하며 회사 기록을 사용하려면 회원 로그인과 회사·사원 연결이 필요합니다.

## 입력과 저장의 차이

시간차는 휴게시간을 제외한 1시간 단위로 고릅니다. 연차·반차·출장도 입력 형태를 살펴볼 수 있지만 체험 계산은 단순 예제입니다. 여러 날 연차, 휴일 제외, 중복 신청·잔여 검증과 자기 승인 차단을 실제 회사 서비스와 동일하게 검증하지 않습니다. 체험 관리자가 자신의 합성 신청을 승인할 수 있는 것은 역할 시연용입니다.

체험은 화면 메모리에만 있습니다. 새로고침하거나 화면을 나가면 출퇴근·신청 기록이 사라집니다. 서버 저장·회사 공동 사용·보관/복구·월 마감·기록 정정 체험은 없습니다. 출근 시각을 실제 현재 시각으로 해석하지 마세요.
