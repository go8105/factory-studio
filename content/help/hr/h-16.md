# 내 근무 · 출퇴근과 신청

## 목적과 시작

회사 직원이 출퇴근을 기록하고 휴가·시간차·출장을 신청하는 화면입니다. 앱 런처 → **HR 인사·급여** → 회사 근무 → **내 근무**로 들어갑니다. [근무 체험](/help/hr/h-17)은 회사 기록과 분리된 합성 화면입니다. 기존 HR의 **근태·휴가** 메뉴와도 별도 원장입니다.

회원 로그인과 활성 회사 소속·사원 연결이 필요합니다. 회사가 없으면 관리자에게 연결을 요청하세요. 게스트는 실제 회사 기록을 조회·저장할 수 없습니다. 직원은 자신의 기록과 신청을 봅니다. 회사 관리자는 소속 회사 직원의 기록·신청을 보고 다른 직원의 신청 승인·반려, 기록 정정, 월 마감을 합니다. 총 관리자 역할만으로 본인의 회사 근무 계정이 자동 생성되지 않습니다. [사용자 관리](/help/hr/h-18)를 참고하세요.

## 휴대폰에서 시작

인터넷에 연결하고 제품에 로그인한 뒤 내 근무를 엽니다. Android는 브라우저 메뉴의 **앱 설치**, iPhone Safari는 **공유 → 홈 화면에 추가**로 설치합니다. 설치 항목은 브라우저·기기에 따라 달라질 수 있습니다. 설치 후에도 같은 서비스의 로그인과 회사 소속 확인이 필요합니다.

설치용 이름·아이콘·시작 주소와 오프라인 안내 파일이 구현돼 있습니다. 이번 확인은 데스크톱 Chrome 화면과 코드 확인이며 Android·iPhone 실기기 설치는 검증하지 않았습니다. 설치 성공이나 백그라운드 동작을 보장하는 안내가 아닙니다.

## 출근부터 퇴근까지

1. 상단 **회사**에서 소속 회사를 확인합니다.
2. **출근하기**를 누르고 ‘처리했습니다.’와 ‘근무 중’, 출근 시각을 확인합니다. 실제 기록은 서버 시각이며 휴대폰에서 임의 시각을 입력하지 않습니다.
3. 업무 종료 때 **퇴근하기**를 누릅니다. 출퇴근 기록의 퇴근 시각을 확인합니다.
4. **조회 월**을 바꿔 기록을 확인합니다. 같은 한국 날짜의 추가 출근과 출근 없는 퇴근은 차단됩니다. 전날 미퇴근이 있다면 먼저 상태를 확인하세요.

휴대폰 위치·GPS·생체 인증·자동 출퇴근 판정은 구현돼 있지 않습니다. 화면의 시각과 기록만 확인하세요.

## 휴가·시간차·출장 신청

1. **종류**에서 연차·오전 반차·오후 반차·시간차·출장을 고릅니다.
2. **시작일**, 필요하면 **종료일**, 시간차·출장의 **시작 시간 / 종료 시간**을 입력합니다. 출장은 **행선지**도 필요합니다.
3. **사유**를 2~500자로 입력하고 **신청하기**를 누릅니다.
4. 신청 내역에서 ‘승인 대기’와 계산된 차감 시간을 확인합니다. 회사 관리자가 승인하면 상태가 ‘승인’으로 바뀝니다. 자기 신청은 관리자도 승인·반려할 수 없습니다.

시간차는 같은 날 근무시간 안에서 휴게시간을 뺀 1시간 단위입니다. 기본 정책은 09~18시·휴게 12~13시·1일 8시간이며 오전 반차는 09~14시, 오후 반차는 14~18시입니다. 연차는 근무일의 하루 전체 시간, 출장은 연차 차감 0입니다. 서버는 주말·등록 휴일·회사 정책과 잔여 시간을 확인합니다. 기간은 같은 연도 안에서 최대 31일 범위이며 기존 승인 대기·승인·취소 승인 대기 신청과 겹칠 수 없습니다.

**현재 제한:** 신청 화면의 연차·반차 입력 시각과 요약 문구는 위 기본 정책으로 고정돼 있습니다. 다른 근무 정책의 회사는 서버 계산과 표시가 다르거나 신청이 거부될 수 있습니다. 사유나 시간을 바꿔 우회하지 말고 관리자에게 정책·화면 일치 확인을 요청하세요. 법정 연차 자동 산정 기능으로 해석하지 않습니다.

## 취소·정정·마감

- 승인 대기인 본인 신청의 **신청 취소**는 즉시 취소합니다. 승인된 신청은 ‘취소 승인 대기’가 됩니다. 관리자가 취소를 승인하면 취소, 반려하면 기존 승인 상태를 유지합니다. 합성 체험의 즉시 취소와 다릅니다.
- 회사 관리자는 **기록 정정**에서 출근·퇴근 시각과 2~500자 **정정 사유**를 입력하고 **이력 남기고 정정**을 누릅니다. **정정 닫기**는 입력을 닫고 정정 요청을 보내지 않습니다. 정정 이력은 남으며 원장을 삭제하는 기능은 없습니다.
- 회사 관리자는 종료된 **조회 월**의 퇴근 누락·미처리 신청을 먼저 확인하고 **해당 월 마감**을 누릅니다. 마감 월의 출퇴근·신청·정정 변경은 차단됩니다. 이 화면에는 마감 해제·삭제·휴지통 복구가 없습니다.

## 저장·오류·오프라인

인터넷이 연결돼야 서버에 기록합니다. 오프라인에는 기록·신청 버튼이 차단되고 안내 화면만 열릴 수 있습니다. 개인 근태·인증 응답은 오프라인 캐시에 저장하지 않습니다. 오프라인 입력 큐·자동 재전송·백그라운드 동기화·푸시는 구현돼 있지 않습니다.

응답 유실 때는 안내의 **다시 시도**로 같은 요청의 처리 결과를 확인하세요. 새 신청을 반복하지 마세요. 입력 오류는 기간·근무시간·잔여·겹침·사유를 확인하고 수정합니다. 마감 오류는 관리자에게 확인합니다. 세션 만료 때는 다시 로그인하고 확정 저장된 내역을 확인합니다. 미저장 입력은 복구를 보장하지 않습니다.

실제 회사 운영 계정으로 출퇴근·승인·마감을 실행하지 않았습니다. 합성 화면 확인과 자동 검사에서 확인한 범위는 제품 문서의 검증 기록을 따릅니다.
