# 사용자 관리 · 총 관리자와 회사 관리자

## 목적과 진입

앱 런처 → **HR 인사·급여** → 회사 근무 → **사용자 관리**에서 회사 계정을 관리합니다. 회사 관리자는 내 근무의 **사용자 관리** 링크로도 들어옵니다. 게스트·일반 직원은 관리 작업을 할 수 없습니다.

아이디 **admin**은 운영상 총 관리자 계정으로 사용하는 아이디입니다. 실제 권한은 서버가 확인하는 플랫폼 관리자 역할에 따르며 아이디 문자열만으로 권한이 생기지 않습니다. 총 관리자는 모든 회사의 사용자 관리와 회사 등록을 할 수 있습니다. 회사 관리자 계정은 소속 회사의 사용자만 관리하며 총 관리자 권한을 받지 않습니다. GW 상단의 합성 체험 담당자·게시판 운영 담당자와도 다릅니다.

## 회사를 처음 등록하기

총 관리자로 로그인한 뒤 **+ 회사 등록**을 누릅니다. 회사명·근무 시작·하루 근무 시간(분)·휴게 시간(분)과 첫 관리자의 아이디·직원 이름·사원 코드·올해 연차 부여 일수를 입력합니다. 비밀번호는 관리자가 직접 설정하고 동일하게 두 번 입력합니다. **회사·첫 관리자 등록** 후 회사와 첫 회사 관리자 계정이 함께 생깁니다. 첫 관리자의 근무 권한은 회사 관리자이며 총 관리자 권한은 아닙니다. **회사 등록 취소**는 등록 전 입력 화면을 닫습니다.

회사는 한국 시간 기준입니다. 기본 예제 정책은 09시 시작·480분 근무·60분 휴게입니다. **내 근무**의 신청 화면은 기본 시각을 고정해서 사용하므로 다른 정책의 회사는 [현재 제한](/help/hr/h-16)을 먼저 확인하세요. 이 도움말에는 실제 계정 비밀번호나 직원 개인정보를 기재하지 않습니다.

## 직원을 추가하고 근무 시작하기

1. **관리할 회사**를 고른 후 **+ 사용자 추가**를 누릅니다.
2. 아이디(소문자·숫자로 시작, 총 3–40자, 이후 영문 소문자·숫자·점·밑줄·하이픈), 직원 이름(2–100자), 사원 코드(영문·숫자로 시작, 최대 30자, 이후 밑줄·하이픈 가능)를 입력합니다.
3. **올해 연차 부여 일수**는 0–366일, **근무 권한**은 직원 또는 회사 관리자로 고릅니다. 사원 코드는 회사 내 중복되지 않아야 하며 아이디는 이미 사용 중이면 등록할 수 없습니다.
4. 비밀번호를 10–256자로 동일하게 두 번 입력하고 **사용자 추가**를 누릅니다. 로그인 계정·사원·근무 연결과 올해 연차를 함께 구성합니다.
5. 직원은 자신의 계정으로 로그인해 [내 근무](/help/hr/h-16)의 회사·이름을 확인한 뒤 출퇴근·신청을 시작합니다. 비활성 예제 계정은 비밀번호 설정 전 로그인할 수 없습니다.

## 기존 계정의 버튼

**계정 관리**로 대상을 선택합니다. **아이디 변경**은 입력한 새 아이디를 적용합니다. **근무 권한 변경**은 직원/회사 관리자 변경입니다. **사용 중지**는 계정을 비활성화하며 근무 기록을 삭제하지 않습니다. **비밀번호 설정·사용 재개**는 새 비밀번호를 설정하고 비활성 계정을 활성화합니다. **관리 닫기**는 입력 화면을 닫습니다. 목록에서 비밀번호를 다시 확인하는 기능은 없습니다.

아이디·비밀번호·권한 변경과 사용 중지는 대상의 기존 로그인을 종료하므로 대상은 다시 로그인해야 합니다. 자기 계정 변경, 마지막 활성 회사 관리자를 없애는 변경, 여러 회사에 연결된 계정 변경은 차단됩니다. 현재 로그인한 관리자 변경은 다른 관리자에게 요청하세요. 계정 영구 삭제나 휴지통 복구는 제공하지 않습니다. 사용 중지의 복원은 비밀번호 설정·사용 재개입니다.

## 오류와 확인 범위

아이디 중복·형식·사원 코드·비밀번호 일치·연차 범위 오류를 수정하세요. 관리할 회사가 없다면 회사 소속과 관리자 권한을 확인합니다. 응답이 불확실하면 **같은 요청으로 다시 확인**을 사용합니다. 새 사용자 추가를 반복하지 마세요.

이번 문서 확인 중 실제 운영 회사·계정을 만들거나 비밀번호·권한을 변경하지 않았습니다. 권한 경계와 저장 동작의 자동 검사, 합성 응답 화면 확인은 실제 직원 공동 사용 검증과 구분합니다.
