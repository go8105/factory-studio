# 공통 이용 안내

## 이 문서에서 안내하는 것
모든 화면에 공통으로 적용되는 오류 처리, 세션, 네트워크, 상태 안내 및 접근성 원칙입니다. 개별 화면 도움말에서는 반복을 줄이기 위해 이 내용을 생략합니다.

## 주요 동작
- **입력 오류 및 검증 안내**: 입력 오류가 발생하면 문제가 발생한 입력값과 함께 수정해야 할 항목을 구체적으로 안내합니다. 시스템 내부 정보는 표시하지 않습니다.
- **세션 만료 처리**: 이용 중 세션이 만료되면 로그인 화면으로 이동을 안내합니다. 다시 접속하면 마지막으로 확정 저장된 상태로 복구되며, 저장되지 않은 작성 중인 값은 임의로 저장 처리되지 않습니다.
- **네트워크 응답 불확실**: 네트워크 통신 문제로 처리 결과가 불명확할 때는 완료나 실패로 단정하지 않고 진행 상태를 재확인합니다. 동일 요청 재시도 시 기존 처리 결과를 대사합니다.
- **선행 데이터 및 모듈 부족**: 화면 이용에 필요한 선행 기준정보나 업무 데이터가 없거나 비활성 상태인 경우, 해당 데이터를 먼저 준비할 수 있도록 원인 안내와 함께 해당 화면 링크를 제공합니다.
- **솔루션 간 읽기 전용 조회**: MES·ERP·FEMS·QMS·WMS·BEMS는 각자 데이터를 소유합니다. 다른 솔루션의 값이 필요하면 읽기만 하고 그 시점의 값을 복사해 두며, 상대 데이터를 바꾸지 않습니다(예: QMS 검사 대기는 MES 완료 LOT을 읽고, MES 패킹의 "QMS 보류" 배지는 표시만 합니다. WMS는 MES 입고·투입과 ERP 출하·매입을 읽어 재고 원장에 반영할 뿐 MES·ERP를 바꾸지 않습니다. BEMS는 FEMS 사업장·제조 전력을 읽어 공용·잔여로 나눌 뿐 FEMS를 바꾸지 않습니다). 상대 솔루션을 끄면 조회 값은 "조회 불가"로 보이고 자기 업무는 그대로 할 수 있습니다.
- **계산 불가 상태의 정상 표시**: 생산량 0, 적용 계수 미등록, 모듈 비활성 등 계산에 필요한 값이 없는 상태는 시스템 오류가 아니므로 화면에 정상 상태의 하나로 표시됩니다.
- **접근성 및 화면 대응**: 마우스 없이 키보드만으로도 주요 동작을 수행할 수 있도록 지원하며, 좁은 화면(360px 기준)에서는 입력 서식과 안내 영역이 세로로 자동 재배치됩니다. 상태 변화는 색상 구분에만 의존하지 않고 텍스트나 형태로 함께 구별할 수 있도록 지원합니다.

## 그룹웨어 체험

GW의 상단 담당자 선택으로 합성 직원의 기안·결재·공지·일정·알림·채팅을 체험합니다. [업무 현황 안내](/help/gw/g-01)에 담당자별 체험 순서가 있습니다. HR에서 가져온 현재 조직과 상신 당시 조직은 따로 보관합니다. 공간 초기화 후 앱을 열면 새 세대의 체험 데이터를 복사합니다. 실제 직원 계정 연결과 공유 회사 공간은 별도 도입 범위입니다.

## 다섯 시스템의 시작 안내

- [CAD·CAM](/help/portal/cad-cam) → [3D 부품](/help/portal/part-design) → [NC 검토](/help/portal/nc-review) → [휴디 음성](/help/portal/hugh-d).
- [GW 공동 업무 체험](/help/portal/gw-guide): 합성 담당자 전환과 실제 계정 권한을 구분합니다.
- [Factory Flow 보드](/help/flow/f-02) · [내 업무](/help/flow/f-01): GW와 독립된 회사 협업 시스템입니다.
- [3D 공장](/help/portal/factory): 합성 시연이며 실제 설비 연결이 아닙니다.
- [내 근무·PWA](/help/hr/h-16) · [근무 체험](/help/hr/h-17) · [총 관리자/회사 관리자](/help/hr/h-18): 실제 공동 기록과 합성 체험을 구분합니다.

계획서·시제품·과거 완료 기록만으로 운영 검증이나 실제 장비 안전을 확인한 것으로 읽지 마세요.
