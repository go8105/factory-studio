# 프로젝트 보드 · Factory Flow

## 목적과 시작

**Factory Flow**는 회사 프로젝트와 협업을 관리하는 독립 시스템입니다. 앱 런처 → Factory Flow → **프로젝트 보드**(`/work-os/boards`)로 들어갑니다. GW의 공지 게시판·전자결재 메뉴와 다릅니다. 이전 GW 프로젝트 주소는 이 시스템으로 이동합니다.

실제 보드는 회원 로그인과 활성 회사 소속이 필요합니다. 회사가 없다면 [사용자 관리](/help/hr/h-18)를 확인합니다. 게스트는 상태 선택 한 건을 바꾸는 **합성 업무 체험**만 이용하며 보드 생성·저장·공유를 체험하는 것은 아닙니다. 화면을 나가면 합성 상태도 사라집니다.

## 권한

회사 구성원은 기본적으로 회사 보드 조회 권한입니다. 보드 **편집자**는 업무·하위 업무·그룹·자유 컬럼의 셀값·업데이트를 편집합니다. **소유자**는 보드 설정·컬럼 구조·공유 권한도 관리합니다. 회사 소유자는 보드 생성 정책·보관 복구·권한 관리를 할 수 있지만 일반 업무 편집에는 보드 편집자/소유자 지정이 필요합니다. 회사 소유자 자격은 HR 회사 관리자 근무 권한과 별개이며 HR에서 관리자 승격해도 자동으로 생기지 않습니다. 총 관리자 역할과 회사 근무 연결은 별도이므로 아이디 admin만으로 Flow의 회사 소속을 대신하지 않습니다. 보관된 보드는 복구 전 편집할 수 없습니다.

## 보드에서 업무 완료까지

1. **회사**를 선택하고 **내 보드**의 보드를 엽니다. 생성 권한이 있으면 제목 옆 **＋**(보드 만들기)에서 이름(최대 120자)과 프로젝트 WBS·팀 업무·이슈 관리·회의 후속 업무 템플릿을 고르고 생성합니다. 취소는 생성 전 창을 닫습니다.
2. 보드 제목 또는 목록의 별을 누르면 개인 **즐겨찾기**에 넣거나 뺍니다. 즐겨찾기는 공유 보드를 복제하지 않습니다.
3. 보드 소유자/편집 권한이 있으면 **＋ 새 그룹 추가하기**로 그룹을 만들고 표시된 이름을 편집합니다. 그룹의 펼침 표시를 누르면 접히며 **머리글 한 줄만** 남습니다. 그룹 메뉴에서 이름·색·순서 편집, 복제·보관·삭제·복구를 합니다.
4. 그룹의 **＋ 업무 추가**를 누르면 새 업무 행이 만들어지고 제목 입력 상태가 됩니다. 제목을 쓰고 Enter 또는 입력 밖으로 이동해 저장합니다. Escape는 제목 편집을 취소합니다. 생성 직후 제목을 취소해도 이미 만들어진 행 자체가 없어지는 것은 아닙니다.
5. 부모 행의 **하위 업무 추가**로 바로 아래 하위 행을 만듭니다. 제목만 먼저 쓰고 나머지를 행에서 채웁니다. 하위 업무 아래 또 하위 업무를 만드는 다단계 트리는 아닙니다.
6. **담당자·상태·중요도·일정·진행률**은 행에서 바꿉니다. 담당자는 활성 회사 구성원 중에서 선택합니다. 날짜는 시작이 종료보다 늦을 수 없고 진행률은 0~100입니다. 완료 상태는 100%, 취소 이외의 미완료 상태는 최대 99%로 정리됩니다.
7. 행 메뉴의 **상세 / 업데이트**로 내용을 확인합니다. 상세 편집 항목은 **제목 / 설명·참고 링크** 두 가지입니다. 제목 최대 250자, 설명 최대 10,000자이며 파일 첨부 입력란이 아닙니다. **저장**은 이 두 항목을 반영합니다. 창 닫기/Escape는 아직 저장하지 않은 상세 입력을 버립니다.
8. **업데이트**에서 댓글을 등록하고 변경 이력을 확인합니다. 내 댓글 수정·삭제만 가능하고 삭제한 댓글은 삭제 표시로 남습니다. 댓글 수정의 취소는 작성 입력을 닫습니다. 이전 댓글·이력은 **이전 댓글·이력 더 보기**로 읽습니다.

## 부모 자동 집계

보관되지 않은 하위 업무가 있으면 부모의 **상태·기간·진행률**을 하위 업무에서 자동 집계하며 부모 행에서 직접 수정하지 않습니다. 진행률은 취소를 제외한 하위 업무의 평균을 반올림합니다. 모두 완료면 완료, 모두 취소면 취소, 모두 대기면 대기이며 남은 업무가 모두 보류/검토면 해당 상태, 그 외에는 진행 중입니다.

부모 시작일은 하위 업무의 가장 이른 시작일, 종료일은 가장 늦은 종료일입니다. 기간에는 취소된 하위 업무의 날짜도 포함될 수 있습니다. 보관한 하위 업무는 집계에서 제외합니다. 하위 업무가 없어지면 자동 집계 표시가 없어집니다. 담당자·중요도는 자동 집계 항목이 아닙니다.

## 자유 컬럼과 행 입력

**열 관리**에서 기본 열 표시·순서를 바꿉니다. **중요도**는 기본적으로 숨겨질 수 있으므로 필요하면 표시를 켭니다. 보드 소유자 또는 회사 소유자는 **＋ 컬럼 추가**에서 텍스트·숫자·날짜·상태·체크박스·기간을 선택하고 열 이름·순서·너비(80~600)를 지정합니다. 상태 이름은 쉼표로 구분합니다. 만든 컬럼의 유형은 바꾸지 못합니다.

텍스트·숫자·날짜 셀은 입력 후 Enter 또는 입력 밖 이동 시 저장하고 Escape로 기존 값으로 돌아갑니다. 상태·체크박스는 선택 시 저장합니다. 기간은 시작·종료를 입력하고 **적용**해야 저장합니다. 기본 업무 상태와 자유 상태 컬럼은 별개이며 자유 컬럼은 부모 자동 집계 대상이 아닙니다. 열 메뉴의 삭제도 복구 가능한 표시입니다.

## 검색·필터·보기·공유

검색, 상태 필터, **내 업무만**, 업무 순서·마감일·제목 정렬로 표시를 좁힙니다. 메인 테이블·칸반·캘린더·간트는 같은 업무를 보여 줍니다. 캘린더·간트에서 기간 없는 업무는 날짜 표시가 제한됩니다. 간트는 기본 기간 표시이며 의존 관계·자동 일정 계산 기능은 없습니다. 보기 메뉴의 **보기 저장**으로 현재 보드의 개인 보기 조건을 보관합니다. 그룹 접힘을 회사 전체 설정이나 저장된 업무 변경으로 해석하지 않습니다.

**공유**는 같은 회사 구성원의 보드 설정·권한 영역을 펼칩니다. **편집자 지정 / 소유자 지정 / 조회만**으로 지정합니다. 외부 손님 초대·공개 익명 링크·다른 회사 공유 기능은 없습니다. 회사 소유자는 보드 설정의 **구성원 보드 생성 허용**을 관리합니다.

## 삭제·보관·복구

업무와 하위 업무의 **행 오른쪽 ··· → 업무 삭제 / 하위 업무 삭제**는 영구 삭제가 아니라 복구 가능한 보관입니다. 부모 삭제 시 하위 업무도 함께 보관됩니다. 보드 목록 아래 설정 메뉴의 **보관 항목 보기**를 켜고 해당 행의 **업무 복구**를 사용합니다. 부모와 함께 보관된 하위 업무는 부모 복구 시 함께 복구됩니다. 그 전에 별도로 보관했던 하위 업무는 보관 상태를 유지하므로 필요한 행을 따로 복구하세요.

보드는 **보드 보관 / 보드 복구**로 관리합니다. 그룹 보관·삭제 뒤에도 보관 항목 보기에서 복구합니다. 업무 상태의 **취소**는 상태값 변경이고 행 삭제·보관과 다릅니다. 이 화면에 영구 삭제나 보관함 비우기는 없습니다.

## 오류와 현재 제한

저장 실패 때 오류를 읽고 재시도로 서버 상태를 확인합니다. 다른 구성원이 먼저 수정한 버전 충돌은 새로고침 후 최신 값으로 다시 편집합니다. 조회 권한·보관 상태·회사 소속·활성 담당자를 확인하세요. 미저장 상세 내용이나 댓글은 새로고침 후 복원을 보장하지 않습니다.

날짜별 업무일지·제출/검토 트리(FLOW-02b), 첨부파일, 외부 공유, 대규모 가상 스크롤은 현재 미구현입니다. 제품 코드와 합성 실행 화면으로 확인하며 운영 회사의 실제 업무 쓰기는 이번 문서 검증에서 실행하지 않습니다.
