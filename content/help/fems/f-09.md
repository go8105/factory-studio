# 사업장·공간

## 이 화면에서 하는 일
회사의 물리적 생산 거점인 사업장과 사업장 내부의 세부 구역인 공간(건물, 층, 구역 등) 정보를 등록하고 관리하는 기준정보 화면입니다.

## 주요 동작
- **사업장 등록 및 수정**: 사업장 코드, 사업장명 등 기본 정보를 등록하고 수정합니다.
- **공간 계층 등록**: 상위 사업장을 지정하고 해당 사업장 소속의 세부 공간 코드 및 공간명을 등록합니다.
- **활성화 상태 전환**: 운영이 중단되거나 현재 사용하지 않는 사업장이나 공간은 삭제 대신 비활성화 상태로 전환하여 관리합니다.

## 이럴 때 막힙니다
- **참조 중인 항목 삭제 불가**: 하위 공간이나 설비 등에서 이미 참조하고 있는 사업장이나 공간은 삭제할 수 없습니다. 삭제 시도 시 참조 중인 데이터 건수가 안내되며, 삭제 대신 비활성화를 사용해야 합니다.
- **식별 코드 중복**: 이미 등록된 사업장 코드 또는 동일 사업장 내 공간 코드는 중복하여 등록할 수 없습니다.
