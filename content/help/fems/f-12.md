# 계측기·채널

## 이 화면에서 하는 일
물리적인 에너지 계측기 정보와 해당 계측기에 연결된 개별 측정 채널(에너지원, 측정 대상 설비, 계기 배수 등)을 등록하고 관리하는 기준정보 화면입니다.

## 먼저 필요한 것
- 계측 대상 설비 등록 정보
- 계측 대상 에너지원 등록 정보

## 주요 동작
- **계측기 및 채널 마스터-디테일 관리**: 좌측 목록에서 계측기를 선택하고, 우측 패널에서 해당 계측기에 속한 여러 측정 채널을 등록하고 관리합니다.
- **채널별 설비 및 에너지원 연결**: 각 채널마다 측정 대상 설비와 에너지원을 각각 지정합니다. 한 계측기가 전력과 가스 등 서로 다른 에너지원을 함께 측정하도록 구성할 수 있습니다.
- **계기 배수 설정 및 강조 확인**: 실제 측정값에 곱해지는 계기 배수를 설정하며, 기본값인 1이 아닌 경우 목록에서 눈에 띄게 강조 표시되어 오입력 여부를 쉽게 검토할 수 있습니다.
- **활성화 상태 전환**: 철거되거나 교체된 계측기 및 채널은 삭제 대신 비활성화하여 기존 계측 이력을 유지합니다.

## 이럴 때 막힙니다
- **선행 설비 또는 에너지원 부재**: 연결할 설비나 에너지원이 먼저 등록되어 있지 않으면 채널을 등록할 수 없으며, 해당 기준정보 화면으로 이동하는 링크가 안내됩니다.
- **계측 데이터가 존재하는 계측기·채널 삭제 불가**: 이미 수집된 계측값이 존재하는 계측기나 채널은 삭제할 수 없습니다. 삭제 시도 시 참조 중인 데이터 건수가 안내되며, 삭제 대신 비활성화를 사용해야 합니다.
- **식별 코드 중복**: 이미 등록된 계측기 코드 또는 채널 코드는 중복하여 등록할 수 없습니다.
