# 공정 경로

## 이 화면에서 하는 일
품목별로 거쳐야 하는 공정들의 순서(예: 사출 → 조립 → 검사)를 단계별로 구성하고, 버전 관리 및 게시를 통해 작업지시에서 사용할 수 있도록 확정하는 기준정보 화면입니다.

## 먼저 필요한 것
- 생산 대상 품목
- 경로를 구성할 단위 공정들

## 주요 동작
- **공정 경로 버전 작성 및 순서 지정**: 품목별로 공정 경로 버전을 생성하고 단위 공정들을 배치하여 작업 순서를 설정합니다. (여기서 설정한 공정 순서가 생산 현장에서 실제 작업 진행 순서가 됩니다.)
- **버전 게시**: 작성이 완료된 공정 경로 버전을 게시 처리합니다. (게시된 버전만 작업지시 화면에서 선택할 수 있습니다.)
- **버전 잠금 및 개정**: 이미 작업지시에서 사용 중인 공정 경로 버전은 잠금 처리되며, 공정 순서나 단계 변경이 필요한 경우 새 버전을 생성하여 개정합니다.

## 이럴 때 막힙니다
- **게시 완료된 버전 직접 수정 시도**: 이미 게시되었거나 작업지시에서 사용 중인 공정 경로 버전은 수정할 수 없으며, 변경 시 새 버전을 생성해야 합니다.
- **공정 순서 중복 또는 누락**: 공정 순서 번호가 올바르게 지정되지 않은 상태에서는 저장이 거부됩니다.
