# 공정 실행

## 이 화면에서 하는 일
LOT의 공정 경로 순서에 따라 각 공정 작업을 시작하고 종료 시각을 기록하며, 공정에 배정된 설비를 선택하여 생산을 진행하는 화면입니다.

## 먼저 필요한 것
- 발행된 작업지시에 연결된 LOT
- 공정에 배정된 유효한 설비
- 이전 공정이 있는 경우, 직전 공정의 완료 및 실적 확정 내역

## 주요 동작
- **순차 공정 시작**: 공정 경로에 지정된 순서대로 작업을 시작하며, 이전 공정에서 확정된 양품 수량만 다음 공정의 투입 수량으로 이어받습니다.
- **공정 배정 설비 선택**: 해당 공정에 미리 배정된 설비 목록 중에서 실제 가동할 설비를 선택합니다.
- **작업 시간 기록**: 공정 실행 시작 및 종료 시각을 기록하여 생산 소요 구간을 관리합니다.

## 이럴 때 막힙니다
- **공정 순서 위반**: 이전 공정이 완료되어 실적이 확정되지 않은 상태에서 다음 공정을 먼저 시작하려고 하면 진행이 차단됩니다.
- **설비 중복 점유**: 선택한 설비에서 아직 종료되지 않고 실행 중인 다른 작업이 있을 경우 공정 시작이 거부됩니다.
