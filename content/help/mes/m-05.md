# 공정 실행

## 이 화면에서 하는 일
LOT의 공정 경로 순서에 따라 각 공정 작업을 시작하고 종료 시각을 기록하며, 공정에 배정된 설비를 선택하여 생산을 진행하는 화면입니다.

## 먼저 필요한 것
- 발행된 작업지시에 연결된 LOT
- 공정에 배정된 유효한 설비
- 이전 공정이 있는 경우, 직전 공정의 완료 및 실적 확정 내역

## 주요 동작
- **순차 공정 시작**: 공정 경로에 지정된 순서대로 작업을 시작하며, 이전 공정에서 확정된 양품 수량만 다음 공정의 투입 수량으로 이어받습니다.
- **공정 배정 설비 선택**: 해당 공정에 미리 배정된 설비 목록 중에서 실제 가동할 설비를 선택합니다.
- **작업 시간 기록**: 시작·종료 시각은 서버가 기록합니다. 과거 시각을 직접 입력하지 않습니다.
- **실적 확정으로 공정 완료**: 실행 중인 공정의 양품·불량을 확정하면 공정이 끝납니다. 투입은 첫 공정이면 지시 수량, 이후는 직전 공정 양품이며 양품 + 불량이 투입과 같아야 합니다. 마지막 공정이면 LOT과 작업지시가 함께 완료됩니다.

## 이럴 때 막힙니다
- **공정 순서 위반**: 이전 공정이 완료되어 실적이 확정되지 않은 상태에서 다음 공정을 먼저 시작하려고 하면 진행이 차단됩니다.
- **허용되지 않았거나 사용 안 함인 설비**: 공정에 허용된 설비, 사용 중으로 등록된 설비만 고를 수 있습니다.
- **불량 사유 누락·수량 불일치**: 불량이 있으면 사유가 필요하고, 양품 + 불량이 투입과 다르면 확정되지 않습니다. 확정한 실적은 고칠 수 없습니다.
- **설비 중복 점유**: 선택한 설비에서 아직 종료되지 않고 실행 중인 다른 작업이 있을 경우 공정 시작이 거부됩니다.
