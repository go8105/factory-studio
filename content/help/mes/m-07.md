# 실적 확정

## 이 화면에서 하는 일
공정 실행이 끝난 후 생산된 수량(투입 수량, 산출 수량, 양품 수량, 불량 수량)을 입력하고 작업 실적을 최종 확정하는 화면입니다.

## 먼저 필요한 것
- 작업이 완료된 공정 실행 내역
- 해당 공정에 사용된 자재 투입 실적(자재가 필요한 공정인 경우)

## 주요 동작
- **생산 수량 입력 및 정합성 확인**: 투입 수량, 산출 수량, 양품 수량, 불량 수량을 입력하며, 화면에서 '양품 수량 + 불량 수량 = 산출 수량' 등식이 일치하는지 자동으로 검증합니다.
- **불량 사유 지정**: 불량 수량이 발생한 경우, 발생 원인에 맞는 불량 사유를 반드시 지정합니다.
- **현장 작업자 직접 판정**: 품질관리 시스템(QMS)이 설계 범위에서 제외되어 있으므로, 작업 현장에서 작업자가 양품과 불량을 직접 판정하여 등록합니다.
- **실적 최종 확정**: 실적 확정이 완료되면 수량과 결과가 잠기며, 이미 확정된 실적은 임의로 수정하거나 덮어쓸 수 없습니다.

## 이럴 때 막힙니다
- **수량 합계 불일치**: 양품 수량과 불량 수량을 합한 값이 산출 수량과 일치하지 않을 때
- **불량 사유 누락**: 불량 수량이 1개 이상 존재하지만 불량 사유를 입력하지 않았을 때
- **잘못된 수량 입력**: 수량에 음수나 허용되지 않는 단위 값이 입력되었을 때
- **이미 확정된 실적 수정 시도**: 이미 확정 처리가 끝난 실적에 대해 수정이나 취소를 시도할 때
