# 자재 투입

## 이 화면에서 하는 일
공정 실행 중인 LOT에 필요한 원자재 및 부품의 투입 수량을 등록하고 실제 투입 이력을 기록하는 화면입니다.

## 먼저 필요한 것
- 시작된 상태이며 아직 실적이 확정되지 않은 공정 실행
- 투입할 원자재 및 부품 품목 정보

## 주요 동작
- **BOM 기준 소요량 자동 제안**: 작업지시에 BOM이 연결된 경우, 로스율이 반영된 기준 소요량을 기본 투입 수량으로 제안하며 작업자가 실제 투입 수량으로 수정할 수 있습니다.
- **수기 자재 투입**: BOM 없이 발행된 작업지시의 경우 기본 제안값 없이 빈 입력창으로 제공되며, 투입 자재와 수량을 직접 입력합니다.
- **자재 투입 실적 등록**: 실제 투입된 자재 품목과 수량을 기록합니다. (자재 투입 기록은 생산 이력 추적용이며, 재고 원장 차감은 창고관리 시스템의 영역이므로 재고가 자동으로 차감되지 않습니다.)

## 이럴 때 막힙니다
- **실적 확정 후 자재 투입 시도**: 이미 실적 확정이 완료된 공정 실행에는 자재를 추가로 투입할 수 없습니다.
- **동일 공정 내 동일 자재 중복 등록**: 동일한 공정 실행에 같은 자재를 중복하여 등록하려고 하면 저장이 거부됩니다.
