# 패킹

## 이 화면에서 하는 일
최종 공정까지 완료되고 실적이 확정된 LOT의 양품을 박스(BOX)에 담고, 박스들을 팔레트(PALLET)에 적재하여 포장 단위를 구성하는 화면입니다.

## 먼저 필요한 것
- 최종 공정의 실적 확정이 완료되어 잔여 양품 수량이 남아 있는 LOT

## 주요 동작
- **수량 입력 기반 박스 포장**: 미패킹 LOT 목록에서 포장할 수량을 직접 입력하여 박스(BOX)를 생성합니다.
- **박스 및 팔레트 2단 계층 적재**: 생성된 박스들을 상위 포장 단위인 팔레트(PALLET)에 배정하여 적재합니다.
- **단일 품목 포장 원칙**: 한 박스에는 동일한 단일 품목만 담을 수 있습니다.
- **패킹 번호 자동 채번**: 포장 단위가 생성될 때 고유한 패킹 번호가 자동으로 발급됩니다.

## 이럴 때 막힙니다
- **확정 양품 수량 초과 포장**: 입력한 포장 수량이 해당 LOT의 최종 확정된 양품 수량 또는 미패킹 잔여 수량을 초과하면 저장이 거부됩니다.
- **전량 불량 LOT 포장 시도**: 양품 수량이 0인 전량 불량 LOT은 포장할 수 없습니다.
- **이종 품목 혼합 포장 시도**: 서로 다른 품목을 하나의 박스에 함께 담으려고 하면 포장이 제한됩니다.
