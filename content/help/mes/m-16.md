# 불량·사유 코드

## 이 화면에서 하는 일
공정 실적에서 발생한 불량과 현장의 비가동·비계획 입출고·폐기·재작업 사유를 표준 코드로 등록하고 관리하는 기준정보 화면입니다. 자유 텍스트 대신 정형화된 코드를 등록해 두면 실적 확정 및 현장 분석 시 체계적인 집계가 가능합니다.

## 주요 동작
- **불량 코드 관리**: 외관, 치수, 기능, 기타 구분별로 불량 코드를 등록합니다. 여기서 등록한 코드는 공정(M-13)에서 공정별 불량 코드로 지정되어 실적 확정(M-07) 시 선택 항목으로 나타납니다.
- **사유 코드 관리**: 비가동, 비계획 입출고, 폐기, 재작업 사유 코드를 등록합니다. 비가동 사유의 경우 예방보전 등 사전에 예정된 정지인지 여부(계획된 정지)를 지정할 수 있습니다(비계획 입출고 및 비가동 화면은 아직 제공하지 않습니다).
- **사용 여부 전환**: 등록된 코드는 삭제하는 대신 사용 여부를 '사용 안 함'으로 전환하여 과거 실적과의 참조 무결성을 유지하면서 화면 노출을 제어합니다.

## 이럴 때 막힙니다
- **코드 형식 불일치**: 코드는 영문 대문자나 숫자로 시작하는 1~30자여야 하며, 영문 대문자·숫자·하이픈(-)·언더스코어(_)만 사용할 수 있습니다.
- **사유 구분 변경 시도**: 사유 코드는 등록 후 구분을 변경할 수 없습니다. 구분을 잘못 선택한 경우 기존 코드를 사용 안 함으로 바꾸고 새로 등록해야 합니다.
- **필수 항목 누락**: 불량 코드 및 사유 코드 모두 코드와 이름은 필수 입력 항목입니다.

## 알아둘 점
- **계획된 정지 구분**: 계획된 정지는 비가동 사유에만 적용되며, 설비 가동률 산정 시 계획 정지와 돌발 비가동을 구분하는 기준이 됩니다.
- **사용 중인 코드 삭제 주의**: 과거 실적이나 공정에 이미 연결된 코드를 삭제하면 참조 무결성 제약에 의해 삭제가 거부될 수 있으므로 '사용 안 함' 상태로 관리하는 것을 권장합니다.
