# 공정

## 이 화면에서 하는 일
제조 현장에서 수행하는 단위 작업 공정(예: 사출, 조립, 검사 등)을 정의하고, 각 공정을 수행할 수 있는 설비들을 매핑하여 관리하는 기준정보 화면입니다.

## 먼저 필요한 것
- 공정에 배정할 등록된 설비 정보

## 주요 동작
- **단위 공정 정의**: 현장에서 수행하는 표준 가공·조립·검사 공정을 등록합니다.
- **공정별 설비 매핑**: 해당 공정을 수행할 수 있는 설비들을 연결하여 배정합니다. (공정 실행 화면에서는 여기서 배정된 설비만 선택할 수 있습니다.)
- **공정 경로 구성 준비**: 정의된 공정은 공정 경로의 각 단계로 조합되어 생산 흐름을 구성합니다.

## 이럴 때 막힙니다
- **공정 경로에서 사용 중인 공정 삭제 시도**: 공정 경로의 단계로 이미 등록되어 사용 중인 공정은 참조 삭제 제한 규칙에 의해 삭제가 거부됩니다.

- M-11 설비
