# 내 공간

## 이 화면에서 하는 일
자주 사용하는 업무 메뉴를 모아 바로 이동하고, 각 솔루션의 사이드바를 개인화하는 화면입니다. 앱 사용 여부·예시 데이터 초기화·게스트 만료 일정도 관리합니다.

## 주요 동작
- **메뉴 추가**: 솔루션과 업무 분류를 고르고 메뉴를 체크합니다. 이름·화면 ID·분류로 검색할 수 있습니다. 선택 목록에서 제거하거나 드래그·위아래 버튼으로 순서를 바꾼 뒤 **내 공간에 적용**합니다. 취소하면 임시 변경은 버립니다.
- **즐겨찾기 사이드바**: MES·ERP 등 각 앱에서는 등록한 메뉴를 같은 순서로 표시합니다. **전체 메뉴**로 전환하면 모든 화면을 찾아 별 버튼으로 등록할 수 있습니다. 선택 메뉴가 없어도 메뉴 추가 링크를 이용할 수 있습니다.
- **메뉴 구성 저장**: 회원 개인 공간에 저장되어 재로그인·다른 기기에서도 불러옵니다. 게스트 구성은 해당 임시 공간에만 저장됩니다. 예시 데이터 초기화 후에도 구성이 유지됩니다. 최근 사용 메뉴는 이 브라우저에만 보관합니다.
- **예시 데이터 초기화**: 실습 중 변경된 데이터를 초기 상태로 되돌리고자 할 때, 새로운 데이터 세대를 생성하여 깨끗한 예시 데이터로 재설정합니다. 초기화 시 기존 데이터는 복구할 수 없습니다.
- **솔루션 앱 활성화 설정**: 생산관리(MES), 경영관리(ERP), 에너지관리(FEMS) 솔루션 중 필요한 앱만 선택하여 켜거나 끌 수 있습니다. 사용을 끈 앱은 홈 화면에서 비활성화 상태로 표시됩니다.
- **게스트 이용 기한 확인**: 게스트로 진입한 경우 현재 작업 공간의 만료 일시와 남은 이용 시간을 확인할 수 있습니다.

## 이럴 때 막힙니다
- **다른 창에서 구성 변경**: 최신 구성을 불러온 뒤 다시 편집하세요. 이전 구성을 덮어쓰지 않습니다.
- **저장 결과를 확인할 수 없음**: 같은 요청 다시 적용 또는 최신 구성 불러오기로 확인하세요. 확인 전에는 새 편집·이동이 제한됩니다.
- **앱 사용 꺼짐**: 등록 메뉴는 유지되지만 해당 앱을 켜야 업무 화면을 이용할 수 있습니다.
- **데이터 초기화 작업 진행 중**: 데이터 세대 초기화 작업이 진행되는 동안에는 데이터 무결성을 보호하기 위해 업무 화면 진입이 일시적으로 제한됩니다.
