# NC 경로·시간·에너지 분석

## NC 업로드의 의미

**NC 경로 검토**에서 .nc·.ngc·.tap·.gcode·.cnc·.txt 파일을 읽습니다. 지원 범위는 제한된 숫자형 3축 밀링 G-code입니다. NC는 공구 이동 명령이므로 원래 CAD 설계 이력을 복원하지 않습니다. 파일은 브라우저 메모리에서 읽고 서버에 업로드하지 않습니다.

## 화면 구성

넓은 화면은 왼쪽 분석 준비, 중앙 경로·재생, 오른쪽 휴디·품질 제안·분석 근거로 나뉩니다. 준비 단계는 펼쳐 입력하며, 접어도 값은 유지됩니다. 좁은 화면에서는 준비→경로→결과 순서로 표시됩니다.

## 분석 순서

1. NC 파일을 열고 지원 여부·단위·좌표·경고를 확인합니다. 미지원 명령이 있는 결과를 완전한 분석으로 취급하지 않습니다.
2. NC 행을 선택해 해당 공구 이동을 3D 경로에서 확인합니다.
3. 공구와 소재를 입력합니다. STEP 목표 형상이 있다면 G54 좌표 정합·상면 조건을 확인한 뒤 소재 분석을 실행합니다.
4. 장비 축 속도·가속도, 상태별 전체 전력(kW), 이벤트 시간을 입력하고 시간·에너지 분석을 실행합니다.
5. 품질 조건과 대기 목적·최소 시간·근거를 입력해 개선 후보를 비교합니다.

## 형상 비교의 한계

평엔드밀과 제한된 상면·바닥 연결 형상 모델로 제거량·잔삭·과절삭·급속 접촉 후보를 확인합니다. 홀더·지그 충돌, 모든 곡면, 실제 보정·공정 안전을 검증하는 기능은 아닙니다. 정합이나 소재 조건을 바꾸면 이전 결과는 무효화됩니다.

## kW와 kWh 읽기

kW는 전력, kWh는 시간 동안 소비한 전기 에너지입니다. 화면은 입력한 장비 조건으로 예상 시간과 소비 범위를 계산합니다. 실측 전력계 결과나 보정된 장비 정확도가 아닙니다. 빈칸은 0이 아니라 **미정**이며, 알려진 소계만으로 전체 소비가 확인됐다고 볼 수 없습니다.

## 품질 우선 개선 제안

현재 제안은 근거가 확인된 단독 **G4 대기**의 시간 비교에 한정됩니다. 경로·이송 F·회전수 S·공구 T·냉각 조건을 자동으로 바꾸지 않습니다. 품질 기준 미달이나 근거 부족은 차단되고, 소비 범위가 겹치면 우열을 보류합니다. 후보 번호는 현재 결과 안에서만 유효하며 입력 변경 후에는 다시 분석해야 합니다.

## 후보 실행과 내보내기

후보를 선택해 실행하는 동작은 **검토 시뮬레이션 재생**입니다. 실제 CNC 장비를 구동하거나 NC 원본을 자동 변경하지 않습니다. 재생 중 NC 행·공구 위치·시간·누적 소비를 비교하고 정지할 수 있습니다. JSON 근거를 내려받아 분석 조건과 함께 보관하세요.

## 문제가 생겼다면

미지원 코드 → 지원 범위를 확인합니다. 미정 소비 → 누락된 장비 조건을 보충합니다. 차단 후보 → 품질·대기 근거를 확인합니다. 결과 무효화 → 현재 입력으로 분석을 다시 실행합니다. [휴디 음성 명령](/help/portal/hugh-d)도 동일한 차단 규칙을 따릅니다.

## 진입·지원 프로필과 정확한 조작

로그인 후 **CAD·CAM → NC 경로 검토**로 들어갑니다. 게스트·회원의 일반 기능은 같으며 회사 설계 공유·장비 전송 권한은 없습니다. **경로 예제 / 소재 예제 NC / 대기 검토 예제 NC / 휴디 발표 예제 NC**(합성)는 용도별 합성 입력입니다.

**초기 단위 / 초기 X·Y·Z**와 초기 상태 확인 체크를 입력한 뒤 **경로 해석**을 누릅니다. **해석 취소**는 계산을 멈추며 원문을 지우지 않습니다. **지원 명령**에서 LinuxCNC 기반 숫자형 부분집합을 확인합니다. G0/G1, G17의 G2/G3, G20/21, G90/91, G91.1, G94, G54, G4 P초와 별도 행 M 이벤트 등이 대상입니다. G43/H·G41/42/D, 다른 원점·평면·고정 사이클·매크로·서브프로그램은 차단합니다. 첫 미지원/오류 뒤 경로를 이어 완전한 프로그램으로 표시하지 않습니다. 해석 상한은 2MiB·50,000행·500,000표시점·30초입니다.

**소재 · 공구 · STEP 정합**에서 소재 이름·최소 좌표·크기, T 번호·지름·날 길이·초기 공구를 입력합니다. H/D는 참조이며 실제 보정 적용이 아닙니다. **공구 추가 / 공구 삭제**는 분석 설정만 바꿉니다. STEP 평행 이동·Z축 회전·격자 간격을 지정하고 정합/단일 상면 확인 체크 후 **소재 검토 실행**을 누릅니다. **소재 검토 취소**는 계산 중단입니다. STEP 최대 10MiB·커널 준비90초/형상·소재30초·20,000삼각형·40,000셀이며 격자보다 작은 형상은 빠질 수 있습니다.

**가공 시간 · 소비 에너지**의 장비/시나리오 이름·근거 설명·조건·축별 최고 속도/가속도를 입력합니다. **상태표 만들기** 후 상태별 **전체 전력 최소/최대 kW**, 이벤트 전체 시간·가정 확인 체크를 채우고 **시간·에너지 계산**을 누릅니다. **합성 장비 값 채우기**는 실측값을 가져오지 않습니다. **에너지 계산 취소**는 계산 중단입니다. 상태200종·30초 제한입니다.

**사용자 제공 측정값**(보정 아님)은 입력 출처 표시이며 계산 결과가 실측으로 바뀌거나 모델이 자동 보정되지 않습니다. **별도 검증 운전과 비교**에는 모델 입력에 쓰지 않은 운전 시간·kWh·기록 근거를 넣어 차이를 비교합니다. NC 시작~종료 범위이며 부팅·준비·프로그램 밖 대기는 제외됩니다. 장비 전체 kW에 주축·축·펌프 전력을 다시 더하지 마세요.

## 저장·복구와 확인 범위

**분석 JSON 저장**은 현재 분석과 입력 근거를 파일로 내려받으며 서버 저장이나 NC 원본 덮어쓰기가 아닙니다. 입력 변경 전에 필요한 근거를 저장하세요. 새로고침 후 분석 복원을 보장하지 않으며 NC 휴지통은 없습니다. 합성 NC/STEP·가정 모델 검사는 실기계 호환·안전·실측 품질·절감을 검증하지 않습니다.

[설계·가공](/help/portal/cad-cam) · [부품 설계](/help/portal/part-design) · [휴디](/help/portal/hugh-d).

## FANUC 검토용 NC 파일 출력

장비가 미정인 경우의 제한된 검토용 출력입니다. 분석 결과 아래 **NC 파일 출력 · FANUC 검토용**을 펼치세요.

1. 프로그램 번호(1~7999)와 출력 대상 번호를 입력합니다. **0은 원본**, 1부터는 현재 품질 조건으로 다시 계산한 후보입니다.
2. 초기 G54 좌표·단위·기본 상태·공구표를 실제 장비에서 별도로 확인해야 함을 확인합니다.
3. **검증·미리보기**를 실행합니다. 원본 해시와 최신 품질 조건을 확인하고, 출력 파일을 다시 해석해 경로·공구·주축·냉각·선택 대기 시간을 비교합니다.
4. **검증된 NC 저장**(.review.nc)과 **출력 검증 JSON 저장**으로 파일·프로필·해시·변경 행·초기 조건을 보관합니다.

파일은 ASCII 코드/CRLF, `%`와 O 프로그램 번호, **G4 P 밀리초 정수** 규칙으로 생성합니다. 원본 주석은 제외하고 G91.1은 증분 I/J 검토 가정으로 생략합니다. 입력 변경·탭 비활성·미지원 명령·품질 차단·밀리초보다 세밀한 대기 값은 다시 검증하거나 출력을 중단합니다. 원본 NC는 덮어쓰지 않습니다.

저장 파일을 다시 열 때는 **컨트롤러 프로필 → FANUC 검토용**을 선택하세요. LinuxCNC의 G4 P는 초 단위이므로 서로 바꾸어 읽으면 대기 시간이 달라집니다. 예제 버튼은 LinuxCNC 프로필로 돌아갑니다.

H/D 보정·기계 원점·지그/홀더·자동 퇴피와 장비별 M코드 검증은 지원하지 않습니다. 이 파일은 장비 실행용으로 승인된 NC가 아닙니다. 기종 확정 후 해당 장비의 post와 실제 컨트롤러 검증이 필요합니다. 휴디의 실행 명령은 계속 웹 재생만 수행합니다.


## STEP 예제가 멈춘 것처럼 보일 때

이 문서의 단계는 **실제 CAD·CAM → NC 경로 검토 화면** 기준입니다. `docs/ui/previews/UI-DESIGN-01.html`은 구조 검토 시제품으로 STEP를 읽지 않습니다. 시제품 상단의 실제 NC 화면 링크를 사용하세요.

실제 화면은 **STEP 예제**를 누르면 3D 커널 다운로드 → 초기화 → 형상 읽기를 표시합니다. 첫 준비는 최대90초, 이후 형상 읽기는30초입니다. 실패 메시지가 나왔다면 네트워크와 파일을 확인하고 STEP 예제를 다시 눌러 재시도합니다. STEP가 읽혔다고 정합이 완료되는 것은 아니며 치수/G54와 단일 상면 확인 후 소재 검토를 실행해야 합니다.

YC의 최적안 요청은 [정지 카드 비교·번호 선택 재생](/help/portal/hugh-d)으로 연결됩니다. 카드의 동일한 경로는 G4 대기만 바뀌는 현행 모델의 결과입니다.

## 작업 화면과 준비 단계

왼쪽 준비 단계를 선택하면 오른쪽에서 해당 조건을 편집합니다. 중앙은 실제 3D 경로와 제안 비교 영역이며, 원본 NC 행은 중앙 아래에서 펼쳐 확인합니다. 하단에서 재생·정지·속도·진행률을 사용하고 **가공 시간·소비 상세**를 펼쳐 계산값을 확인합니다.

최적안 요청 후 중앙에 정지 카드가 표시되고, 번호를 선택하면 해당 제안의 경로가 확대·재생됩니다. YC는 오른쪽에서 계속 사용할 수 있습니다. **전체 제안 보기**는 재생을 멈추고 비교로 돌아갑니다. **닫기/Esc**나 준비 단계 선택은 재생을 멈추고 설정 화면으로 돌아갑니다. 입력을 바꾸면 이전 결과가 무효화됩니다. 좁은 화면에서는 선택한 설정으로 이동하며 **작업 화면으로** 버튼으로 뷰포트에 돌아갑니다.
