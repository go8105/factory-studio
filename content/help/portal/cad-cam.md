# CAD·CAM 설계·가공 편집기

## 무엇을 할 수 있나요

2.5D 형상을 직접 설계하고 CNC 경로를 생성·검토하는 화면입니다. 3D 부품 편집과 기존 NC 파일 분석은 별도 화면입니다. 모든 기능을 갖춘 상용 CAD나 실제 장비 제어 프로그램은 아닙니다.

## 처음 사용하기

1. CAD·CAM에서 **설계·가공 편집기**를 엽니다.
2. 소재와 공구·깊이 조건을 정하고 윤곽이나 피처를 만듭니다. 자유 윤곽과 원호 등도 사용할 수 있습니다.
3. 스케치 편집에서는 선택·다중 선택·드래그·치수·변형을 사용합니다. trim/extend/offset은 지원되는 형상에만 적용됩니다.
4. 경로를 생성하고 가공 시뮬레이션을 확인합니다. 경로 제안은 기존 경로와 비교한 뒤 수동으로 적용합니다.
5. 설계 JSON을 내려받아 보관합니다. 브라우저 저장과 파일 다운로드는 다릅니다.

## 편집을 되돌리기

Mac은 **Command+Z**, Windows는 **Ctrl+Z**를 사용합니다. 입력창이나 모달에서는 해당 입력의 편집이 우선합니다. 변경 이력은 제한된 개수만 보관하므로 중요한 설계는 JSON으로 별도 저장하세요.

## 경로 제안 읽기

품질 보존을 먼저 확인하고 비절삭 이동 거리·시간을 비교합니다. 장비 전력 정보가 없는 설계 경로에서 전력 절감률을 실제 값으로 표시하지 않습니다. 입력을 바꾸면 기존 제안은 다시 계산해야 합니다.

## 저장과 제한

설계 저장은 현재 공간과 브라우저에 묶입니다. 다른 PC·브라우저에서 자동으로 이어지지 않습니다. 지원 밖 윤곽이나 공정은 오류 안내에 따라 수정해야 합니다. 생성된 경로가 실제 장비의 공구 보정·지그·안전을 검증해 주지는 않습니다.

## 진입과 권한

로그인 후 상단 **CAD·CAM → 설계·가공 편집기**에서 시작합니다. 게스트·회원은 같은 일반 편집 기능을 사용합니다. 총 관리자·회사 관리자·직원별 설계 공유·승인 기능은 없습니다. 비누 POC/연구노트는 플랫폼 관리자 회원만 보는 별도 비공개 시제품이며 회사 관리자 역할만으로 열리지 않습니다.

## 버튼과 입력의 역할

**새 설계**는 새 편집으로 전환하므로 먼저 JSON을 저장하세요. **열기**는 편집기 JSON을 읽고 **저장**은 JSON을 내려받습니다. **STL**은 형상 메시 출력입니다. **설계 이름**은 저장할 이름, **평면 스케치 / 3D 모델**은 보기 전환입니다.

처음이면 **먼저 연습 부품 살펴보기 →** 버튼으로 합성 설계를 엽니다. 직접 작업은 사각형·원을 그리거나 선 연결·3점 원호·슬롯을 만들고 오른쪽 속성에서 치수·높이를 정해 **돌출 만들기**를 누릅니다. 상면 홈은 새 윤곽과 깊이를 지정합니다. 선택한 작업의 치수 변경·복제·삭제는 형상을 바꿉니다. **02 가공 시뮬레이션**에서 공구 지름·깊이 간격으로 경로를 생성하고 재생/진행 막대로 제거를 봅니다.

전문 스케치 초안을 취소하면 확정 형상을 바꾸지 않습니다. 확정 작업 삭제의 복구는 되돌리기 또는 저장한 JSON으로 합니다. 서버 보관함은 없습니다. 자유 윤곽은 닫혀야 하고 교차·퇴화 형상은 거부됩니다. E1 JSON 100KB·꼭짓점 64개·홈 32개 등 제한이 있으며 단위는 mm입니다. 오류에 표시된 형상·공구·크기를 수정하세요.

## 확인 범위

합성 편집 화면과 경로 생성·관련 자동 검사를 확인합니다. 격자 소재 제거·경로 보존 검사는 실제 CNC 가공·표면 거칠기·치수 정확도·안전·실측 에너지 검증과 다릅니다. 자유 곡면·조립·기계용 NC 출력·회사 클라우드 저장은 현재 범위 밖입니다.
