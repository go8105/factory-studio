# 3D 부품 설계·직접 편집

## 이 화면의 범위

**3D 부품 설계**는 단일 부품을 스케치·피처로 편집하고 STL·STEP 파일로 내보내는 화면입니다. 조립 설계나 범용 3D CAM은 지원하지 않습니다.

## 기본 순서

1. 작업 평면에서 스케치를 만듭니다. 선·원호·치수·선택·변형을 사용합니다.
2. 지원되는 닫힌 윤곽을 피처로 바꾸고 3D 결과를 확인합니다. 내부 홀·섬도 지원되는 조건에서 사용할 수 있습니다.
3. 면이나 모서리를 선택해 지원되는 직접 편집을 적용합니다. 국소 필렛·모따기와 평면 참조는 일반적인 모든 위상에 적용되는 기능이 아닙니다.
4. 오류가 발생하면 해당 형상이나 값을 수정하고 결과를 다시 확인합니다.
5. 편집 이력을 유지할 설계는 JSON, 형상 전달은 STL·STEP으로 따로 저장합니다.

## 되돌리기와 파일

Command+Z / Ctrl+Z로 편집을 되돌립니다. JSON은 이 편집기의 설계 데이터이며 STL·STEP은 결과 형상입니다. 형상 파일을 받았다고 기존 스케치·피처 이력이 복원되는 것은 아닙니다. 브라우저 저장 외에 다운로드한 파일을 별도 보관하세요.

## 가공으로 넘어가기

[NC 경로 검토](/help/portal/nc-review)의 STEP 비교는 기존 NC와 목표 형상을 정합하는 기능입니다. STEP을 올리면 자동으로 완전한 CNC 가공 프로그램이 생성되는 기능은 아닙니다. 품질·지그·재료·공구 조건은 별도로 검토해야 합니다.

## 진입·입력·취소와 삭제

로그인 후 **CAD·CAM → 3D 부품 설계**를 선택합니다. 게스트·회원의 일반 기능은 같으며 회사 관리자/직원별 공동 저장 권한은 없습니다. 스케치 초안 취소는 확정 모델을 바꾸지 않습니다. 확정 피처 삭제는 되돌리기 또는 보관한 JSON으로 복구합니다. 서버 휴지통은 없습니다.

닫히지 않거나 교차한 윤곽, 지원하지 않는 면/모서리·치수는 오류를 수정한 뒤 적용합니다. 재계산 결과를 확인하고 중요한 수정 전 JSON을 내려받으세요. 브라우저 저장은 공간·세대와 브라우저에 묶이며 서버 동기화가 아닙니다. 제한된 합성 형상 검사는 실물 제작 정확도를 검증하지 않습니다.
