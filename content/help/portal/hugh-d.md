# 휴디 음성 NC 시연

## 준비

맥북 **Google Chrome**에서 NC 경로 검토를 엽니다. 인터넷과 Chrome·macOS 마이크 권한이 필요합니다. **음성 켜기**를 직접 눌러 권한을 허용한 뒤 사용하세요. 브라우저 음성 인식 서비스를 이용하므로 환경에 따라 동작하지 않을 수 있습니다. 실제 발화 리허설은 별도 확인해야 합니다.

## 말하는 순서

1. NC 경로·소재·시간/소비·품질 제안 분석을 먼저 완료합니다.
2. **“헤이 와이씨”** 또는 **“Hey YC”**로 호출합니다.
3. 응답 뒤 **“현재 가공 시뮬레이션에서 최적안 제안해줘”**라고 말합니다.
4. 현재 후보 번호를 확인하고 **“세 번째 시뮬레이션 실행해줘”**처럼 번호를 말합니다.
5. **“멈춰”**로 재생을 멈추거나 **“마이크 꺼”**로 음성을 종료합니다.

## 결과 확인

후보의 실행은 CNC 장비 제어가 아니라 화면 안 검토 재생입니다. 차단된 후보·없는 번호·부정 명령은 실행하지 않습니다. 입력을 바꾼 뒤에는 예전 번호를 사용하지 말고 분석과 제안을 다시 확인하세요. 명령 대기 시간은 응답 후 약 30초입니다. 탭을 숨기거나 화면을 나가면 음성과 재생이 멈춥니다.

## 발표용 합성 예제

NC 화면의 **휴디 발표 예제 NC**(합성)와 STEP·에너지·제안 예제 버튼은 발표 준비용 가정입니다. 순서대로 준비하고 결과 표에서 후보를 확인한 뒤 호출합니다. 예제의 절감 수치를 실제 설비 절감 실적으로 소개하지 않습니다.

## 음성이 안 될 때

권한·네트워크 안내를 확인하고 필요하면 음성을 다시 켭니다. 버튼으로 제안 확인·후보 선택·재생·정지를 진행할 수 있습니다. 텍스트 명령 시험은 명령 처리 확인용이며 실제 마이크 인식 성공을 검증하지 않습니다. 음성 녹취는 저장하지 않습니다.


## 카드 비교와 선택 재생

최적안 요청 후 현재 계산된 후보를 팝업 카드로 비교합니다. 카드는 **정지 상태**이며 실제 NC·소재의 3D 캡처와 예상 시간·kWh·G4 변경 근거를 표시합니다. 모든 후보는 같은 경로에서 대기만 다르며 표면조도 Ra·품질 향상률을 계산하지 않습니다.

**“3번 시뮬레이션 실행해줘”** 또는 카드 실행 버튼을 누르면 나머지 카드는 숨겨지고 3번 카드가 확대됩니다. 기존 3D 공구 경로와 실제 시간 모델이 재생되며 시간·누적 kWh·진행률을 확인할 수 있습니다. **시뮬레이션 멈춰**, **전체 제안 보기**, **닫기/Esc**로 정지하거나 비교 화면으로 돌아갑니다. 입력 변경 시 이전 카드와 재생은 무효화됩니다.

현재 화면의 이름/기본 호출어는 잠시 **YC·와이씨**로 표시합니다. 예전 **헤이 휴디/Hey Hugh-D**는 전환용 별칭으로 유지합니다. 실제 마이크는 Chrome/macOS 권한과 인식 서비스가 필요하며 텍스트 명령 테스트는 실음성 검증이 아닙니다.
