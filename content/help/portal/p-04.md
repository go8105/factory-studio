# 설명 카드 (QMS·WMS·BEMS·SCM)

## 이 화면에서 하는 일
현재 구축된 핵심 3개 솔루션(MES, ERP, FEMS) 외에, 설계 범위에서 의도적으로 구현을 제외한 4가지 주변 시스템(품질관리 QMS, 창고관리 WMS, 건물에너지 BEMS, 공급망관리 SCM)의 제외 사유와 연계 방안을 설명 카드로 열람하는 화면입니다.

## 주요 동작
- **시스템별 카드 탐색**: 품질관리(QMS), 창고관리(WMS), 건물에너지(BEMS), 공급망관리(SCM) 중 확인하고자 하는 시스템 카드를 선택하여 내용을 확인합니다.
- **카드의 3단 구조 열람**: 각 설명 카드는 '해당 시스템이 수행하는 핵심 업무', '이번 개발 범위에서 제외한 명확한 기술적·설계적 근거', '향후 도입 시 기존 솔루션들과 맞물리는 데이터 접합점'으로 일관되게 구성되어 있습니다.
- **전체 흐름 맵과의 연동**: 전체 업무 흐름(P-03) 화면에서 점선으로 표시된 제외 업무 노드를 클릭했을 때도 해당 설명 카드로 직접 연결되어 상세 내용을 조회할 수 있습니다.

## 관련 화면
- P-02 앱 런처 (홈)
- P-03 전체 업무 흐름
