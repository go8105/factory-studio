# 진입 (게스트·로그인)

## 이 화면에서 하는 일
Factory Studio 서비스를 시작하기 위한 첫 진입 화면입니다. 별도의 회원가입 절차 없이 게스트로 즉시 체험하거나, 등록된 사용자 계정으로 로그인하여 작업 공간에 접속할 수 있습니다.

## 주요 동작
- **게스트 즉시 체험**: 가입 없이 **별칭**(2~20자)만 입력하고 "가입 없이 둘러보기"를 누르면 임시 작업 공간과 예시 데이터가 만들어집니다. 별칭은 접속 기록 확인용으로 90일 보관하며, 실명·연락처는 적지 않습니다.
- **사용자 로그인**: "계정이 있다면 로그인"에서 아이디와 비밀번호로 로그인해 본인의 전용 작업 공간으로 접속합니다.
- **게스트 만료 안내**: 게스트 모드로 접속하는 경우 화면에 사용 만료 예정 시각이 사전에 안내됩니다.

## 이럴 때 막힙니다
- **별칭 없음·너무 짧거나 김**: 앞뒤 공백을 뺀 2~20자가 아니면 들어가지 않고 별칭 칸 아래에 이유가 보입니다.
- **예시 데이터 준비 지연 또는 실패**: 게스트 공간 생성 중 일시적인 오류로 데이터 준비에 실패하면 초기화 취소 후 재시도 버튼이 제공됩니다.
