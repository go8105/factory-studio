# 운영 기록 (관리자)

## 이 화면에서 하는 일
시스템 내부에서 처리된 작업 실행 내역과 중요 변경 감사 로그(수금·지급 소명 취소 이력 등)를 안전하게 확인하는 관리자 전용 이력 조회 화면입니다.

## 먼저 필요한 것
- 관리자 권한 계정 로그인

## 주요 동작
- **작업 실행 내역 열람**: 시스템 백그라운드에서 진행된 정기 작업 및 데이터 정리 작업의 실행 기록을 조회합니다.
- **감사 로그 확인**: ERP 수금 및 지급 등록 화면에서 취소된 소명 내역 등 업무상 중요한 이벤트의 발생 일시와 세부 기록을 추적합니다.
- **읽기 전용 조회**: 보존된 운영 기록과 감사 이력은 임의로 수정하거나 삭제할 수 없는 읽기 전용으로 제공됩니다.

## 이럴 때 막힙니다
- **관리자 권한 미보유**: 게스트 사용자나 일반 권한 사용자에게는 해당 메뉴가 표시되지 않으며, 화면 접근 권한이 제한됩니다.

## 관련 화면
- P-02 앱 런처 (홈)
- E-10 수금 등록·소명
- E-13 지급 등록·소명
