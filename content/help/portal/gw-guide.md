# GW 그룹웨어 · 공동 업무 체험 안내

## 목적과 사용 범위

앱 런처 → **GW 그룹웨어**에서 전자결재·게시판·조직·일정·댓글·알림·채팅의 공동 업무를 살펴봅니다. 현재 GW는 로그인한 공간 안의 **합성 담당자 역할 체험**입니다. 상단 담당자 선택은 실제 직원 인증이나 회사 관리자 권한 부여가 아닙니다. 회원·게스트 모두 자기 공간의 체험 자료를 사용합니다. 총 관리자·회사 관리자 계정도 이 합성 담당자 선택과 실제 회사의 접근권한을 동일하게 해석하면 안 됩니다.

실제 회사 계정으로 여러 직원이 GW를 공동 사용하는 인증 연결·공유 회사 공간은 현재 범위에 없습니다. 실제 회사 공동 저장이 구현된 [Factory Flow](/help/flow/f-02)와 [내 근무](/help/hr/h-16)는 별도 시스템입니다. Flow는 GW 내부 프로젝트 메뉴가 아닙니다.

## 기안에서 종결까지

1. **체험 담당자**와 **결재선 템플릿**에서 활성 담당자·결재·합의·참고 역할과 단계를 확인합니다. 한 단계의 필수 결재/합의가 모두 끝나야 다음 단계로 갑니다.
2. **기안함**에서 체험 담당자를 기안자로 선택하고 제목·본문·결재선을 채운 뒤 초안을 저장합니다. 금액·통화가 있는 일반 기안과 ERP 매입 원문 연결을 구분합니다. ERP 원문은 ERP를 먼저 열고 읽어오며 GW가 ERP 확정 상태를 바꾸지 않습니다.
3. 상세에서 **상신**합니다. 저장은 초안, 상신은 본문·원문·결재선·전결 규칙·당시 조직을 고정하는 동작입니다. 상신 후 원문을 직접 수정하지 않습니다.
4. 결재 담당자로 전환해 **결재함**의 현재 단계에서 승인/반려, 합의/합의 반대, 참고 의견을 처리합니다. 참고 의견은 승인 조건이 아니며 합의 반대는 반려로 종결됩니다.
5. 기안자는 진행 문서를 회수할 수 있습니다. 반려·회수 문서는 재상신 준비로 새 회차를 만들며 종전 처리 이력을 덮어쓰지 않습니다. **결재 기록**에서 종결 회차·이력·인쇄를 확인합니다. 인쇄/PDF는 브라우저 출력이며 전자서명 문서는 아닙니다.

## 전결·위임·조직

**전결 규칙**은 문서 종류·금액·통화·적용 월에 따라 이후 단계를 생략하며 상신 당시 선정 결과를 이력으로 남깁니다. **결재 위임**은 원 담당자가 지정한 기간·종류·한도 안에서 대리 처리하고 원 담당자와 대리 담당자를 함께 기록합니다. 실제 계정 권한·전자서명을 위임하는 기능이 아닙니다. 사용된 규칙·담당자는 삭제보다 비활성화/해제를 사용합니다.

**조직도**는 현재 HR 조직과 가져온 GW 조직을 구분합니다. 조회 새로고침은 가져오기가 아닙니다. **체험 담당자 → HR에서 가져오기 → 확인한 내용 가져오기**로 현재 조직과 선택한 사원을 명시적으로 반영합니다. 상신 당시 조직은 이후 이동으로 바뀌지 않습니다. HR 퇴직은 GW 자동 비활성화가 아니므로 진행 업무를 확인하고 직접 관리합니다.

## 공지부터 일정·알림·채팅까지

1. 게시판 운영 담당자로 **공지·자유 게시판**에서 새 글을 저장한 뒤 게시합니다. 공지는 전체 공간 또는 부서로 정합니다. 부서 공지는 작성자와 현재 소속 담당자만 봅니다. 게시 원문 변경은 정정 글 작성으로 후속 기록을 만들고 철회도 이력을 남깁니다.
2. 게시 글이나 상신 문서에서 의견 댓글을 작성합니다. 본인 댓글만 수정·삭제하며 삭제 표시와 수정 이력은 남습니다. 댓글은 원문이나 결재를 바꾸지 않습니다. 댓글 휴지통 복구 기능은 없습니다.
3. **일정**에서 제목·시작/끝·장소·참석자를 지정합니다. 개인 일정은 등록자/초대 참석자, 내 부서 일정은 해당 부서 담당자가 봅니다. 참석자는 참석/불참 응답을 합니다. 등록자는 수정/취소하며 수정 후 응답을 다시 받습니다.
4. **알림함**에서 결재·공지·댓글·일정을 열고 읽음 표시를 합니다. 현재 담당자의 알림이며 외부 이메일·모바일 푸시가 아닙니다.
5. **채팅**에서 새 대화와 고정 참여자를 구성해 텍스트를 보냅니다. 활성 화면은 3초마다 조회합니다. 오류 때 메시지 새로고침, 읽음은 여기까지 읽음 표시를 사용합니다. 나가면 과거 메시지도 열 수 없고 다시 참여·참여자 추가는 없습니다.

## 저장·취소와 막힐 때

체험 업무는 서버의 현재 공간·세대에 저장됩니다. 다른 회사의 실무 원장이나 실제 사원 인증 기록은 아닙니다. 공간 초기화는 새로운 체험 세대를 만들므로 업무 수정 취소나 한 건 복구 방법으로 사용하지 마세요. 일반 입력의 취소는 미저장 작성 창을 닫고, 상신 회수·글 철회·일정 취소·위임 해제는 각각 기록을 남기는 별도 동작입니다.

필수 담당자·연속 단계·금액/통화·일정 시작/끝을 오류 안내에 맞게 수정합니다. 버전 충돌은 **서버 상태 다시 확인** 후 최신 값을 기준으로 다시 진행합니다. 조회 불가인 HR·ERP는 해당 앱 활성화/최초 진입을 확인하세요. 원문 변경은 초안을 갱신하고 다시 검토합니다.

현재 연결 원문은 ERP 매입이며 ERP 발주·경비·PLM ECO는 원천 제공이 미구현입니다. 첨부, 실제 회사 GW 권한, 외부 메일/푸시, WebSocket/SSE 채팅은 없습니다. 기능별 입력 조건은 연결된 화면 도움말을 확인하세요. 합성 검증은 실제 회사 도입·전자서명 적합성을 입증하지 않습니다.
