# 로봇 연동 CNC 가공 셀

## 이 화면에서 하는 일

정밀 부품 가공 공장의 첫 설비에서 알루미늄 사각 소재 한 개를 가공합니다. 로봇이 소재를 운반하고 CNC가 포켓·구멍을 가공하는 브라우저 합성 시연입니다.

## 시작하기

1. 3D 공장에서 **01 CNC 가공**을 선택합니다.
2. **CNC 가까이 보기**로 내부 설비를 봅니다. 시연이 정지되어 있으면 시연 조작의 **시연 재생**을 누릅니다.
3. **CNC 1개 시작**을 누릅니다. 한 번의 시작은 한 개만 처리하며 중복 시작은 차단됩니다.
4. 로봇 집기 → 소재 투입 → 로봇 퇴피 → 소재 고정 → 문 닫기 → CNC 가공 → 주축 정지 → 문 열기 → 고정 해제 → 제품 꺼내기 → 검사 대기 위치로 배출 순서로 진행합니다.
5. 완료 후 원소재가 포켓·구멍이 있는 가공품으로 바뀌고 가공 완료 수가 1 증가합니다. 추가 소재는 시작 버튼을 다시 누릅니다.

## 정지와 오류 복구

- **CNC 일시정지 / CNC 재개:** 소재 위치와 진행 단계를 보존합니다.
- **모의 CNC 오류:** 주축과 진행을 멈추고 신규 시작을 차단합니다. **CNC 오류 해제** 후 **CNC 재개**를 눌러야 진행합니다.
- **CNC 종료·소재 보류:** 진행 소재를 보류 수량으로 옮기고 준비 상태로 돌아갑니다. 완료 수량은 증가하지 않습니다. 오류 상태에서는 먼저 오류를 해제해야 종료할 수 있습니다.
- **상단 시연 일시정지 / 외관 보기:** CNC 진행도 대기합니다. 내부 보기·시연 재생 상태로 돌아오면 이어집니다.
- **브라우저 탭 숨김:** CNC가 일시정지됩니다. 돌아온 뒤 CNC 재개를 누릅니다.

## 표시 값의 의미

- 가공 완료: 검사 대기 위치까지 배출을 마친 소재 수입니다. 양품 수나 출하 가능 재고가 아닙니다.
- 종료 후 보류: 사용자가 중간 종료한 소재 수입니다. 불량 수와 다릅니다.
- 모의 인터락: 문 닫힘·고정·로봇 퇴피가 확인된 가공 단계에서만 주축을 가동합니다. 실제 안전 제어가 아닙니다.
- 화면을 나가거나 새로고침하면 CNC 시연 상태와 수량이 초기화됩니다.

## 현재 범위

실제 PLC·로봇·CNC 통신, CAM/G-code, 절삭 물리, 실측 치수 검사는 포함하지 않습니다. 비전검사·C++ 검사실은 별도 시연이며 CNC 완료 수량을 검사 수량이나 MES·WMS 재고로 자동 반영하지 않습니다. 기존 MES의 전자부품 시드와도 별개입니다.
