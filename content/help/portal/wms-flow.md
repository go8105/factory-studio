# 입고부터 출고까지 · WMS와 3D 트럭 체험

## 체험할 수 있는 업무
구매 담당자는 입고 예정을 등록하고, 창고 담당자는 도착과 검수를 기록합니다. 불량 의심 자재는 격리하고, 출고 담당자는 정상 재고를 예약한 뒤 확정 출하와 연결합니다. 같은 원천을 다시 눌러도 재고가 두 번 반영되지 않는 것을 확인할 수 있습니다.

## 전체 흐름
**입고 예정 → 트럭 도착 → 검수 → 정상·격리 재고 → 예약 → ERP 출하 확정 → 출하 연결·소진 → 전표·원장 확인**

1. [WMS 입고 예정·검수](/wms/inbounds)에서 ‘예정’ 예시를 엽니다. 새 게스트 공간에는 예정·도착·검수완료·전량부족·취소 예시가 있습니다.
2. 3D 트럭 보기를 눌러 공장 외부로 이동하고 트럭 도착 시연을 실행합니다. 트럭이 정차한 뒤 서버가 도착을 확인합니다. **이때 재고는 늘지 않습니다.** 3D를 사용하지 않아도 W-08의 도착 처리로 같은 업무를 할 수 있습니다.
3. 검수 화면에서 합격95·격리3·부족2 KG 예시를 확인하거나 직접 입력합니다. 확정 후 전표와 현재고를 확인합니다.
4. [출고 예약](/wms/reservations)에서 정상 위치의 재고를 예약하고 가용 수량이 줄어드는 것을 확인합니다. ERP가 없어도 원자재 예약과 해제까지 가능합니다.
5. 완제품은 MES 입고를 W-03에 반영한 뒤 해당 LOT를 예약합니다. ERP의 확정 출하와 전량 일치하는 예약은 W-09에서 연결·소진할 수 있습니다. 참고 출하지시는 자동 소진을 예약하는 기능이 아닙니다.
6. [재고 원장](/wms/moves)에서 검수와 출고의 기록을 확인합니다. 입고 부족분은 원장에 나타나지 않으므로 검수 상세에서 확인합니다.

## 처음부터 다시 체험하기
새 게스트 공간 또는 내 공간의 초기화는 새 세대를 만듭니다. 이전 예약·검수 ID는 새 세대에서 사용할 수 없습니다. 템플릿 예시의 날짜와 참조 ID는 새 공간으로 이동하며, 각 게스트의 업무 기록은 분리됩니다.

## 직접 반영과 검수 경유
ERP 매입은 W-03 직접 반영 또는 W-08 검수 경유 중 한 경로로 원장을 만듭니다. 연결된 검수를 다시 반영하지 않습니다. 매입 취소는 실물 반품과 다르므로 검수 재고는 자동 취소되지 않습니다. 물건이 실제로 반품됐다면 사유가 있는 정정 전표를 사용합니다.

## 이 시연의 범위
차량은 합성 3D 모델이며 실제 GPS 배송 추적이나 물류사 API 연결이 아닙니다. 실장비·PLC·카메라를 제어하지 않습니다. CNC의 알루미늄 소재 시연 수량과 WMS 기존 품목은 자동 연결되지 않습니다. 예약·검수는 서버에 저장하지만 트럭 애니메이션 진행률은 저장하지 않습니다. 페이지를 벗어나면 서버 도착이 완료되지 않았을 수 있으므로 재진입해서 상태를 확인하세요.
