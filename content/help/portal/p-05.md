# 도움말

## 이 화면에서 하는 일
Factory Studio 내 모든 솔루션(포털, FEMS, ERP, MES)의 화면별 업무 안내와 공통 이용 규칙을 한곳에서 찾아볼 수 있는 도움말 허브 화면입니다.

## 주요 동작
- **솔루션별 도움말 목차 탐색**: 포털, 생산관리(MES), 경영관리(ERP), 에너지관리(FEMS)별로 분류된 화면별 도움말 목록을 둘러보고 필요한 업무 안내를 확인합니다.
- **화면별 직접 연계**: 각 업무 화면 우측 상단의 도움말 안내 버튼을 누르면 현재 작업 중인 화면의 맥락 도움말 페이지로 바로 이동합니다.
- **공통 이용 안내 열람**: 입력 오류 발생 시 대처법, 세션 만료, 네트워크 이상 대응 등 전 화면에 공통 적용되는 안내 사항을 열람할 수 있습니다.

## 관련 화면
- P-02 앱 런처 (홈)
- P-03 전체 업무 흐름
