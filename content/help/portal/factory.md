# 3D 공장 둘러보기

## 이 화면은 무엇인가요

로봇·CNC·비전검사·포장 공간을 보여주는 **합성 3D 시연**입니다. 실제 설비의 실시간 데이터나 PLC 제어 화면은 아닙니다.

## 보기와 이동

- **건물 외관 / 내부 펼쳐보기**로 건물 표시를 바꿉니다.
- **전체 / 1층 현장 / 2층 사무실**로 시점을 선택합니다.
- 조감도는 마우스 드래그로 회전, 휠로 확대·축소합니다. 터치 회전도 가능합니다.
- **걸어서 둘러보기**를 누른 뒤 3D 화면에 초점을 두고 WASD·방향키·이동 버튼으로 이동합니다. Esc는 조감도로 돌아갑니다.
- **시점 초기화**는 카메라 위치를 되돌립니다. **시연 일시정지 / 시연 재생**은 장면 시연을 제어합니다.

시연 재생·일시정지와 시점 초기화는 3D 화면 아래 **시연 조작** 영역에 있습니다.

## 설비와 체험

설비를 선택하면 해당 공정 설명이 열립니다. **01 CNC 가공**을 선택한 뒤 내부 보기와 시연 재생 조건을 확인하면 [CNC 셀 시연](/help/portal/cnc-cell)을 진행할 수 있습니다. 트럭 입고 패널은 외관에서 확인합니다.

**1인칭 비전검사 체험**에서는 드래그로 시선을 바꾸고 WASD·방향키로 이동합니다. 설비 클릭 또는 정면에서 E로 검사하며 Esc로 나갑니다. 별도 [합성 이미지 검사실](/help/portal/vision-lab)과 구분하세요.

## 그래픽과 결과의 한계

3D 준비 중이거나 그래픽 오류가 있으면 안내에 따라 기다리거나 다시 엽니다. 시연 수량은 실제 생산 실적·검사 합격 실적이 아니며 업무 데이터에 자동 반영되지 않습니다. CNC 셀 시연은 CAD·CAM의 NC 검토 파일을 실제 장비에 보내는 기능이 아닙니다.

## 진입과 권한

로그인 후 상단 **3D 공장**으로 들어갑니다. 게스트·회원 모두 합성 탐색·시연을 사용하며 총 관리자·회사 관리자·직원 역할이 실장비 제어 권한을 부여하지 않습니다. 트럭 입고 저장은 별도 WMS 업무 원장에 따릅니다.

## 비전 상태·휴디 설명·관련 화면

**02 비전검사**에서 정상·불합격 증가·정지 상황을 선택하면 현재 시연 누계가 초기화됩니다. **현재 시연 검사 수량**은 장면 누계이며 ‘직전/최근 10분’ 고정 자료와 다릅니다. 휴디 설명은 계산 근거·가능한 원인 안내이고 설비 제어가 아닙니다. 서버 AI가 미설정이거나 실패하면 준비된 데모 설명으로 출처를 표시합니다. 실제 AI 호출 성공은 별도 확인 범위입니다.

**합성 이미지 검사실 열기 →**는 단건·연속 검사·가상 PLC 화면으로 이동합니다. C++ 검사는 서버 코어 설정이 필요하며 미설정이면 오류를 표시합니다. [검사실 안내](/help/portal/vision-lab)를 따르세요. **이상 상황 시연 / 이상 해제**는 합성 상태 변경입니다. **MES에서 업무 확인 →**과 하단 MES·ERP·FEMS 링크는 업무 화면으로 이동하며 선택 설비의 실적 자동 연결이 아닙니다.

## 저장·복구와 확인 범위

시점 초기화·시연 정지는 저장·삭제가 아닙니다. CNC 일시정지/오류 해제/종료·소재 보류는 [셀 안내](/help/portal/cnc-cell)를 따릅니다. 브라우저 장면 상태·수량은 화면 이탈·새로고침 후 초기화되며 보관함 복구가 없습니다. 검사실 JSON 다운로드는 별도 파일 보관입니다.

외관의 트럭 도착은 WMS 서버 상태를 기록하는 예외입니다. 도착만으로 재고가 늘지 않으며 검수 후 재고 반영은 [WMS 입고 흐름](/help/portal/wms-flow)을 따릅니다. 문서 검증 중 실제 회사 입고 원장은 변경하지 않습니다.

합성 탐색·CNC 화면과 자동 검사를 확인하며 실설비 통신·센서·산업 안전·실물 검사 정확도는 미검증입니다. 실제 마이크 발화는 [휴디 안내](/help/portal/hugh-d)의 별도 검증 범위입니다.
