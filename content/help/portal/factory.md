# 3D 공장 둘러보기

## 이 화면은 무엇인가요

로봇·CNC·비전검사·포장 공간을 보여주는 **합성 3D 시연**입니다. 실제 설비의 실시간 데이터나 PLC 제어 화면은 아닙니다.

## 보기와 이동

- **건물 외관 / 내부 펼쳐보기**로 건물 표시를 바꿉니다.
- **전체 / 1층 현장 / 2층 사무실**로 시점을 선택합니다.
- 조감도는 마우스 드래그로 회전, 휠로 확대·축소합니다. 터치 회전도 가능합니다.
- **걸어서 둘러보기**를 누른 뒤 3D 화면에 초점을 두고 WASD·방향키·이동 버튼으로 이동합니다. Esc는 조감도로 돌아갑니다.
- **시점 초기화**는 카메라 위치를 되돌립니다. **시연 일시정지 / 시연 재생**은 장면 시연을 제어합니다.

시연 재생·일시정지와 시점 초기화는 3D 화면 아래 **시연 조작** 영역에 있습니다.

## 설비와 체험

설비를 선택하면 해당 공정 설명이 열립니다. **01 CNC 가공**을 선택한 뒤 내부 보기와 시연 재생 조건을 확인하면 [CNC 셀 시연](/help/portal/cnc-cell)을 진행할 수 있습니다. 트럭 입고 패널은 외관에서 확인합니다.

**1인칭 비전검사 체험**에서는 드래그로 시선을 바꾸고 WASD·방향키로 이동합니다. 설비 클릭 또는 정면에서 E로 검사하며 Esc로 나갑니다. 별도 [합성 이미지 검사실](/help/portal/vision-lab)과 구분하세요.

## 그래픽과 결과의 한계

3D 준비 중이거나 그래픽 오류가 있으면 안내에 따라 기다리거나 다시 엽니다. 시연 수량은 실제 생산 실적·검사 합격 실적이 아니며 업무 데이터에 자동 반영되지 않습니다. CNC 셀 시연은 CAD·CAM의 NC 검토 파일을 실제 장비에 보내는 기능이 아닙니다.
