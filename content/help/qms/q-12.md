# 4M 변경

## 이 화면에서 하는 일
사람·설비·자재·방법(4M) 변경을 신고하고, **초품 검사 합격**으로 확인을 닫습니다.

## 먼저 필요한 것
- 초품 검사를 만들려면 그 품목의 **게시한 검사 기준**(Q-02)이 있어야 합니다.

## 진행 순서
1. **신고**: 구분·품목·적용 예정일·변경 내용을 적습니다. 신청일은 오늘로 들어갑니다.
2. **승인 또는 반려**: 승인하면 초품 검사를 만들 수 있고, 반려하면 끝납니다. **반려에는 의견이 필요합니다.**
3. **초품 검사 만들기**: 품목의 게시 기준으로 검사 초안을 만듭니다. 값은 Q-04 검사 화면에서 적고 확정합니다.
4. **확인 완료**: 확정·합격한 초품 검사를 고르면 확인 완료가 됩니다.

## 이럴 때 막힙니다
- **결정한 신고 수정**: 승인·반려한 신고는 내용을 고칠 수 없습니다. 기록이기 때문입니다.
- **두 번 결정**: 한 번 결정한 신고는 다시 결정하지 않습니다.
- **승인 전 초품 검사**: 승인한 신고에만 초품 검사를 만듭니다.
- **게시 기준 없음**: 품목에 게시한 검사 기준이 없으면 초품 검사를 만들 수 없습니다. Q-02에서 먼저 게시하세요.
- **불합격 초품으로 확인**: 확정·합격한 초품 검사만 고를 수 있습니다. **불합격이면 승인 상태 그대로 두고 다시 검사합니다.**

## 아직 없는 것
- **PLM ECO 가져오기**: 설계 변경(ECO)을 4M 신고 후보로 끌어오는 기능은 PLM 솔루션이 생긴 뒤에 붙입니다. 지금은 직접 신고로 전 과정이 돕니다.

## 관련 화면

- Q-04 검사
- Q-11 계측기·교정
