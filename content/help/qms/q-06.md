# 불량 유형

## 이 화면에서 하는 일
검사 불합격 항목에 붙이는 불량 유형(코드·이름)을 관리하는 화면입니다. 대시보드의 불량 유형 집계 기준이 됩니다.

## 먼저 필요한 것
- 없음. 시드 공간에는 MES 불량 사유와 같은 코드(`MOLD_DAMAGE`·`SHORT_SHOT`·`PIN_MISALIGN`·`CONTACT_FAIL`)와 `APPEARANCE`·`DIMENSION`이 들어 있습니다. 코드가 같을 뿐 MES와 연결되어 있지는 않습니다.

## 주요 동작
- **등록·수정**: 코드는 영문 대문자로 시작하고 대문자·숫자·밑줄만 씁니다. 이름과 사용 여부를 바꿀 수 있습니다.
- **사용 안 함**: 사용 안 함으로 바꾸면 새 검사의 선택지에서 빠집니다. 이미 기록된 검사는 그대로입니다.
- **삭제**: 한 번도 쓰이지 않은 유형만 삭제합니다.

## 이럴 때 막힙니다
- **쓰인 유형 삭제**: 검사에 쓰인 유형은 삭제할 수 없고, 쓰인 건수가 안내됩니다. 사용 안 함으로 바꾸세요.
- **코드 중복·형식**: 이미 있는 코드이거나 형식에 맞지 않으면 코드 칸에 오류가 표시됩니다.
