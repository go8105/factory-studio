# 출하

## 이 화면에서 하는 일
출하지시된 내역을 확인하고 제품의 실제 출고 수량과 포장 정보를 입력하여 출하를 확정 처리하는 화면입니다.

## 먼저 필요한 것
- 등록된 출하지시 내역

## 주요 동작
- **출하 등록 및 수량 확인**: 출하지시를 기반으로 실제 출고되는 품목과 수량을 확인하여 등록합니다. 독립 솔루션이므로 생산관리(MES) 연동 없이 품목과 수량 입력만으로도 정상 출하가 가능합니다.
- **패킹 정보 입력**: 출하 명세에 포장 단위의 식별 정보가 필요한 경우 패킹 번호를 직접 수기로 입력합니다. 생산관리 시스템과 독립적으로 운영되므로 패킹 목록을 조회하여 선택하지 않고 직접 입력하며, 실제 운영 환경에서는 인터페이스 연계로 처리됩니다.
- **출하 확정 및 매출 연계**: 출하 처리를 최종 확정하면 수정이 불가능하도록 잠기며, 출하 완료와 동시에 매출 내역이 자동으로 생성됩니다.

## 이럴 때 막힙니다
- **출하지시 수량 초과**: 실제 출하 수량이 출하지시된 수량을 초과하는 경우 확정할 수 없습니다.
- **이미 확정된 출하 수정 시도**: 최종 출하 처리가 완료되어 잠긴 출하 건은 직접 수정할 수 없습니다.
