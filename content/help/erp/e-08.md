# 세금계산서

## 이 화면에서 하는 일
확정된 매출 내역을 바탕으로 세금계산서를 생성하고, 승인번호와 발급일자를 입력하여 발급 상태를 관리하는 화면입니다.

## 먼저 필요한 것
- 확정된 매출 내역

## 주요 동작
- **매출 건별 세금계산서 생성**: 매출 1건당 1건의 세금계산서를 생성하여 관리합니다(월합계 방식 미적용).
- **발급 정보 등록**: 국세청 전자세금계산서 직접 연동 없이, 승인번호와 발급일자를 사용자가 직접 수기로 입력하여 발급을 완료합니다. 실제 운영에서는 전자세금계산서 연동이 필요하며 1차 범위에서 제외되었음이 화면에 안내됩니다.
- **상태 관리**: 세금계산서는 '발급대기'와 '발급완료'의 2가지 상태로 관리됩니다. 금액은 매출에서 가져옵니다.
- **발급 기록**: 발급대기 계산서에 승인번호와 발급일을 입력하면 발급완료가 됩니다. 발급일은 매출일(한국 시간) 이후여야 하고, 승인번호는 중복될 수 없습니다. 수기 승인번호는 국세청 승인을 검증한 값이 아닙니다.

## 이럴 때 막힙니다
- **선발행 불가**: 매출 인식이 선행되지 않은 상태에서는 세금계산서를 먼저 생성할 수 없습니다.
- **발급취소 상태 미지원**: 발급완료 처리된 세금계산서는 수정·삭제할 수 없고, 그 매출도 취소할 수 없습니다.
- **취소된 매출**: 취소된 매출에는 만들 수 없습니다.
- **0원 매출**: 합계가 0원인 매출은 세금계산서를 발급하지 않습니다(0원 매출 자체는 허용).
- **한 매출에 한 건**: 이미 계산서가 있는 매출에는 다시 만들 수 없습니다.
