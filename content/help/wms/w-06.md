# 창고·위치

## 이 화면에서 하는 일
원자재 창고·완제품 창고와 창고 안 보관 위치를 관리하는 화면입니다. 원천 반영은 창고 용도에 맞는 창고의 기본 위치로 들어옵니다.

## 먼저 필요한 것
- 없음. 시드 공간에는 WH-RAW(원자재)·WH-FG(완제품) 창고와 각 기본·예비 위치가 들어 있습니다.

## 주요 동작
- **창고 등록**: 코드·이름·용도(원자재·완제품)를 입력합니다. 용도는 등록 뒤 바꾸지 않습니다.
- **위치 보기**: 창고 행의 "위치 N"을 누르면 위치 상세가 열립니다. 위치 추가·수정 폼을 닫으면 위치 상세로 돌아옵니다.
- **기본 위치**: 창고의 첫 위치는 자동으로 기본 위치가 됩니다. 다른 위치를 기본으로 지정하면 기존 기본 지정이 풀립니다.
- **사용 안 함**: 쓰이지 않게 할 창고·위치는 사용 안 함으로 바꿉니다.

## 이럴 때 막힙니다
- **같은 용도의 사용 중 창고가 이미 있음**: 원천 반영 창고가 겹쳐 등록·사용 전환이 거부됩니다.
- **기본 위치 삭제·사용 안 함**: 할 수 없습니다. 다른 위치를 먼저 기본으로 지정하세요.
- **이동이 있는 위치 삭제**: 할 수 없고 쓰인 건수가 안내됩니다. 사용 안 함으로 바꾸세요.
