# 입고 예정·검수

## 이 화면에서 하는 일
공급처에서 올 자재를 등록하고, 차량 도착과 실제 검수 결과를 따로 기록합니다. **도착만으로 재고는 증가하지 않습니다.** 검수를 확정하면 합격 수량은 정상 위치, 격리 수량은 격리 위치에 들어갑니다. 부족 수량은 재고에 들어가지 않습니다.

## 시작하기
1. 창고·위치(W-06)에서 정상 위치와 격리 위치를 준비합니다. 기존 체험 공간에는 R-Q01과 F-Q01이 있습니다.
2. 입고 예정 등록에서 중복되지 않는 업무 번호, 창고, 예정일, 품목·기본 단위 수량을 입력합니다. 완제품에는 LOT가 필요합니다.
3. 예정 상세에서 도착 처리하거나 **3D 트럭 보기 → 트럭 도착 시연**을 실행합니다. 같은 서버 상태를 변경합니다.
4. 도착한 예정에 합격·격리 수량을 입력합니다. 부족은 자동 계산됩니다. 격리 또는 부족이 있으면 사유를 적습니다.
5. 검수 결과 확인에서 품목별 요약을 보고 검수 확정합니다. 확정 뒤에는 수량을 수정할 수 없습니다.

## 100 KG가 올 예정이라면
합격 95 KG, 격리 3 KG를 입력하면 부족은 2 KG입니다. 전체 현재고는 98 KG 증가하지만 예약 대상인 정상 재고는 95 KG 증가합니다. KG와 EA는 합산하지 않습니다. 전량 부족이면 검수 이력만 남고 입고 전표는 만들지 않습니다.

## ERP 매입 연결
- **직접 반영:** W-03에서 ERP 확정 매입을 바로 원장에 반영합니다.
- **검수 경유:** W-08에서 아직 반영하지 않은 매입을 연결하고 검수합니다. 연결된 매입을 W-03에서 다시 반영해도 중복 입고되지 않습니다.
- **수동 검수 후 대사:** 검수 완료 상세에서 ERP 매입 대사 연결을 하면 예정 수량을 대조해 연결만 기록합니다. 재고를 다시 늘리지 않습니다.
- ERP가 꺼져 있으면 수동 입고·검수는 가능하지만 ERP 연결과 연결 건의 확정은 제한됩니다.

이미 직접 반영한 매입은 검수 경로에 연결할 수 없습니다. 원천 수량·환산이 바뀌면 연결 해제 후 재검토하세요. ERP 매입 취소는 실물 반품과 다릅니다. 검수 재고는 자동으로 사라지지 않으므로 실물을 확인하고 W-04의 조정·이동 전표로 정정합니다.

## 오류와 재시도
도착 뒤에는 예정 편집이 불가합니다. 취소와 연결 해제에는 사유가 필요합니다. 검수 실패 시 입력은 유지됩니다. 응답을 받지 못했다면 서버 상태 다시 확인을 누르세요. 같은 내용으로 재시도하면 중복 입고를 막습니다.
