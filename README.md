# Factory Studio

제조 업무 전체 흐름(판매계획 → 출하·매출)을 배우는 통합 업무 포털입니다. MES·FEMS·ERP를 하나의 앱 런처에서 진입합니다.

## 먼저 읽을 문서

1. **[현재 기획과 진행 현황](docs/현재기획_진행현황.md)** — 전체 요약. 여기부터 시작하세요
2. [개발 기준](docs/개발기획_설계_일정_최종기준.md)
3. [상세 일정 및 작업 운영](docs/상세개발일정_및_자율작업운영계획.md)
4. [진행 기록](docs/progress.md)

문서의 기준본은 이 저장소의 `docs/`입니다. 초기 16주 로드맵과 이전 설계 문서는 요구사항 추적용이며 최신 기준과 상세 일정이 우선합니다.

## 현재 상태

**설계 보완 중이며 제품 개발 착수 전입니다.** 아키텍처·DB 명세·개발 방식·화면 설계를 완료하고 사용자 확인 후 개발합니다. [설계 완료 기준·모듈별 시각화·UI 기준](docs/design/설계완료_승인기준_및_시각화.md)을 따릅니다.

[FS-007b 모듈별 DB 명세·ERD](docs/db/FS-007b_변경_검증.md)를 작성했습니다. FS-006b 보완 내용을 메타데이터·Excel에 반영했으며 이번 결과는 사용자 검토 대기입니다. 다음은 FS-008a 전체 흐름/UI 설계 개정입니다.
**실제 React/FastAPI 앱과 DB는 아직 구현하지 않았습니다.**

DB 설계는 54개 테이블·510컬럼·113외래키 기준이며 정적 검증을 통과했습니다. [설계서 안내](docs/db/README.md)를 참고하세요.
구현 모듈은 MES·FEMS·ERP이고 QMS·WMS·BEMS는 준비 중입니다.

최신 시제품은 `prototypes/fs-008-ui.html`이며 [화면 설계 및 검증 제한](docs/ui/화면설계_FS-008.md)을 함께 확인하세요. 실제 브라우저 표시 검증은 아직 미완료입니다.
`prototypes/factory-studio.html`은 가상 데이터 기반 이전 UI 시제품입니다. 최신 UI 방향은 독립 아이콘과 짧은 이름, 넓은 여백을 갖는 앱 홈이며 시제품의 테마를 최종안으로 고정하지 않습니다.

## 도구 실행

```
npm install            # exceljs (최초 1회)
npm run db:validate    # 정적 메타데이터 검증
npm run db:build       # Excel·미리보기 재생성
```

## 디렉터리

- frontend/: React·TypeScript 프론트엔드 예정
- backend/: FastAPI 및 DB 마이그레이션 예정
- seed/: 재현 가능한 합성 데이터 예정
- tests/: 단위·DB 통합·브라우저 검증 예정
- docs/: 기획, 일정, ERD, Excel DB 설계서, 운영·진행 기록
- prototypes/: UI 검토용 시제품

실행 명령은 실행 기반을 구현한 뒤 검증 결과와 함께 추가합니다. 기존 AI 비서 서비스와 DB는 별도로 유지합니다.
